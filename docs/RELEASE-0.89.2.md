# 0.89.2 — ещё пять пар нарядов, две трети серии

## Что сделано

- Пять новых полных пар: `hair-ponytail` (пересъёмка второго кадра),
  `hair-curls`, `glasses-sigma`, `pendant-heart`, `pendant-star`.
  Итого **25 из 38** нарядов с фото — две трети серии; все пары подключены
  к витрине.
- Кадры самостоятельные, без увеличенных кропов:
  - хвостик — подвешен на стойке, видно резинку и клипсу; второй кадр —
    раскладка S-волной на поверхности, крючок-клипса и край шиньона
    в фокусе (в прошлой версии стойка проходила сквозь хвост и делила его
    пополам — переснято);
  - кудри — ряд пружинок на Т-стойке, лента и клипсы; второй кадр — сзади:
    машинная строчка шиньона, изнанка клипс с пружинами, сложенная лента,
    объём слоёв;
  - очки «Сигма» — толстая чёрная оправа, угловатые ободы, фронт;
    второй кадр — честный профиль: обод ребром, шарнир с осью, широкая
    дужка и её ступенчатый кончик за линзами;
  - кулон-сердечко — цепочка на карточке, розовое золото; второй кадр —
    раскладка: открытый карабин, удлинитель с бусиной, оборот подвески
    с гравировкой контура;
  - кулон-звёздочка — светящаяся звезда на серебряной цепочке; второй
    кадр — раскладка: замок, удлинитель, огранка и толщина звезды.
- Студия одна на всю серию: нейтральный тёпло-серый задник, мягкий свет
  сверху-слева, 4:3, предмет целиком в кадре с полями, без надписей
  и логотипов.
- Сборка штатная: `node scripts/make-product-images.mjs` → 1200×900 WebP.
  В `public/products/` теперь 92 фото, в `public/products/gallery/` — 41.
- Все пять пар прописаны в `OUTFIT_PAIRS` (`src/ui/PhotoPair.tsx`): снимок
  в нише карточки и просмотр двух кадров в листе.

## Как проверено

- `npm run test:galleries` — 13/13, включая «каждая полная пара нарядов
  подключена к витрине».
- Пары просмотрены на контакт-листе до конвертации: один свет, один задник,
  один масштаб, разные ракурсы и стороны, ничего не обрезано рамкой.
- `npm run typecheck`, `npm run build`, `npm run release:check`.
