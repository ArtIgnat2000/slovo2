# 0.92.0 — «Карточки букв» и новая вкладка «Игры»

Первый шаг из предложения «Механики букв» (`docs/proposals/mekhaniki-bukv.md`,
принят владельцем 2026-11-10): вариант **A** (настоящая сборка слова из
карточек с переносом) и вариант **H** (отдельная рамка «Игры» для свободных
механик). Варианты B и C — в плане, ничего сверх A и H не выкатывается.

## Что изменилось для ребёнка

### Задание «Собери слово» — настоящее

Раньше в задании «Собери слово» буквы нажимались по очереди, а собранное слово
прокручивало вперёд, как клавиатура. Теперь это настоящий перенос карточек:

* буквы лежат в **лотке** (бумажный лоток с внутренней тенью), слово ждёт в
  **лунках** — пустые лунки пунктирные, чтобы палец видел цель;
* карточки **перетаскиваются** настоящим переносом (pointer events с захватом
  указателя): из лотка на пустую лунку, на занятую лунку (карточки меняются
  местами), из лунки в лунку (обмен), из лунки обратно в лоток;
* карточка **под пальцем** приподнимается и вращается, под целевой лункой
  появляется фиолетовое кольцо, лоток подсвечивается при наведении;
* **тап работает как раньше**: тап по букве ставит её в первую свободную
  лунку, тап по лунке возвращает букву в лоток — поэтому клавиатура и
  скринридер работают точно так же, как прежде;
* ошибки «проваливаются»: неверно собранное слово трясёт лунки, подсвечивает
  красным и через 900 мс возвращается в перемешанный вид — слово **не
  засчитывается**, попытка записывается как 0;
* подсказка ставит следующую букву на своё место (балл 3 вместо 5 — как и в
  прежние релизы); в режиме «полный контроль» подсказок по-прежнему нет.

### Вкладка «Игры» в нижнем меню

Внизу появились шесть вкладок: «Уроки · Слова · Игры · БУК · Рейтинг ·
Родителям». Внутри:

* **Свободная практика — «Собери слово»**: слова, которые ребёнок уже
  встречал в уроках (по состоянию SRS); первыми показываются освоенные
  (≥ 90 баллов, минимум 3 — иначе все встреченные). Чистый повтор:
  **ничего не сгорает, XP не начисляется, в SRS не пишется** — можно играть
  сколько угодно;
* та же доска, что и в уроке: тот же перенос, тот же тап, та же подсказка
  (в свободной игре подсказки бесплатны); после сборки — «✨ Слово собрано!»,
  слово с подсвеченной опасной буквой и кнопка «Ещё раз»;
* честный пустой экран: «Пока нечего собирать — сначала пройди пару
  уроков» + кнопка «К урокам»;
* раздел **«Скоро здесь»**: кроссворд дня и филворд — явно помечены
  «скоро — проверяем на детях»; они не выкатываются до проверки на детях.

## Как это устроено внутри

* `src/engine/word-board.ts` — чистый движок доски без DOM: лунки фиксированного
  размера слова, обмен-семантика между лотком и лункой (осознанно нет «вставки
  со сдвигом» — в отличие от римских «Собери число»; позиции слова от этого
  не расползаются), геометрия броска `dropSlotAt` с допуском ±18 px;
* `src/ui/WordTileBoard.tsx` — общий компонент для урока и свободной игры
  (режим `unscored`): указатель с захватом, приземление по ближайшей лунке,
  призрак буквы под пальцем; `setPointerCapture` необязателен (jsdom и часть
  вебвью его не реализуют);
* `src/ui/HintBits.tsx` — подсказки вынесены из `TaskView` в общий модуль
  (урок и игра используют одни и те же `HintBtn` / `HintCard` /
  `NoHintsContext`);
* `src/ui/screens/GamesScreen.tsx` — вкладка «Игры»: выбор слова чипами
  (60 максимум), правила рамки H закреплены в коде и в тестах;
* адаптивная обвязка тестов сохранена: урок по-прежнему проходит через
  `.slots.shake` / `.slot.bad`, буквы в лотке — `.letter`.

## Что честно не сделано

* B «Кроссворд дня» и C «Филворд» — не в этом релизе (решение владельца);
  визуальные заглушки помечены «скоро».
* E «Колесо букв», F «Собери фразу», G «Исчезающая буква», D «Слова в слове» —
  не утверждены.
* Озвучка — нет; решение принимается только по результатам прослушивания
  TTS-пробы (`docs/tts/tts-trial.html`), по умолчанию остаётся «не делаем».

## Для кого это

Ребёнку: та же «Собери слово», но с настоящими карточками и отдельным местом
для повторения без давления. Родителю: счётчик XP, экономика и прогресс
SRS не трогаются — «Игры» ничего не списывают и ничего не портят.

`npm run release:check` (0.91.1 → 0.92.0), `npm run typecheck`, `npm run test:smoke`
(все проверки пройдены, включая 14 новых: движок доски, вкладка «Игры»,

`npm run build`, `npm run test:content`, `npm run test:release`.

Инженерное замечание для ревью: смоук-тест сидирован (`Math.random` — mulberry32(1));
`currentWord()` научилась принимать корень запроса, потому что в документе может
быть открыто два экземпляра приложения (смоук и класс-тест) — запрос без корня
видел чужой открытый урок и подменял слово при проверке 1 класса. Попутно
исправлено: `tests/classes.test.ts` теперь читает слово урока внутри своего корня.

## Известные ограничения

* На тач-устройствах перетаскивание — по указателю; тап-вкладку можно ставить
  как раньше. Виртуальная «вставка между буквами» отсутствует намеренно.
* В свободной игре опасное место слова подсвечивается только после сборки — в
  баннере «Слово собрано!» — как и в уроке, проверяется именно написание.
* Пустой экран «Игры» до первого урока — намеренный: словечек нечего
  показывать, пока ребёнок ничего не встречал.
