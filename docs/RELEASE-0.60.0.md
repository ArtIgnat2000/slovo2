# 0.60.0 — ударения под защитой: снимок банка, словарь и «проверьте»

Прямой ответ на вопрос «проверка была по всем словам или только по моим?»:
**по моим трём**. Ударения 257 слов банка до этого не сторожились вообще —
`content:check` проверял только их валидность. Теперь закрыто с двух сторон.

## 1. Снимок всех 257 ударений — и тест, который его сторожит

`tests/stress-snapshot.ts` — 257 строк вида `'автомобиль': 9, // автомобИль`.
`tests/stress.test.ts` (входит в `npm run test:content`, то есть в CI) сверяет
контент со снимком и падает с читаемым сообщением при любом расхождении.

Проверил, что тест действительно ловит ошибку: сдвинул «берег» на одну
гласную — тест упал именно так, как нужно:

```
«берег»: ударение сдвинулось — ожидалось «бЕрег», в контенте «Берег»
```

Что теперь невозможно сделать молча:

* сдвинуть ударение на соседнюю гласную;
* переименовать слово, забыв про снимок (останется «лишнее слово»);
* добавить слово в банк без записи в снимок (тест скажет, какой строки нет);
* продублировать слово в снимке.

Как менять осознанно: нашлась ошибка → правится и контент, и снимок в одном
коммите, и диф показывает ровно изменённые слова.

## 2. Словарь известных ударений вырос с 3 до 40 слов

Свои слова из школьных списков приходят без разметки, поэтому ударение
ставит автополе. Теперь для типичных школьных слов оно приходит готовым
(`src/content/stress-dict.ts`):

* **части речи и разбор слова:** подлЕжащее, сказУемое, пристАвка, сУффикс,
  кОрень, окончАние, оснОва, глагОл, местоимЕние, нарЕчие, падЕж,
  склонЕние, спряжЕние, орфогрАмма;
* **школьные дела:** контрОльная, диктАнт, изложЕние, сочинЕние, чЕтверть,
  дневнИк, портфЕль, расписАние, перемЕна, звонОк, оцЕнка, отмЕтка, ошИбка,
  задАча, примЕр, отвЕт, вопрОс;
* **вежливые формы и частые слова диктантов:** прощАйте, красИвее, звонИт,
  каталОг, докумЕнт, договОр, тОрты, бАнты, шАрфы.

Индексы не считались вручную: слова записаны с заглавной ударной буквой
(`пристАвка`), а индексы из них вычислены скриптом с проверками — ровно одна
заглавная буква и она гласная. Тест словаря проверяет это же повторно.

## 3. Автогадание больше не выдаётся за факт

Если слова нет в словаре, ударение по-прежнему подставляется на последнюю
гласную, но теперь **честно помечено**:

* в предпросмотре списка вместо «новое слово — выберите ударение» пишется
  **«проверьте ударение:»** (оранжевым), рядом те же кнопки-слоги;
* в блоке «Свои слова» у такого слова стоит бейдж **«проверьте»**;
* как только родитель поставил ударение сам, пометка исчезает
  (`stressManual`), и словарь её больше не перебивает.

Пометка пересчитывается при каждом чтении профиля: если слово потом попадёт
в словарь, оно станет «проверенным» само.

## Проверки

* `npm run test:content` — 257 ударений сверены со снимком + корректность
  словаря (ключ в нижнем регистре, индекс на гласной, три школьных слова
  читаются как подлЕжащее / сказУемое / прощАйте);
* `npm run test:smoke` — +5 проверок про пометку «подставлено»:
  слово вне словаря помечается, слово из словаря — нет, ручной выбор снимает
  пометку, пометка пересчитывается при чтении, словарь исправляет старое
  значение;
* полный контур: `typecheck`, `test:smoke`, `test:guard`, `test:icons`,
  `test:content`, `test:adaptive`, `audit:storage`, `demo:check`,
  `content:check`, `images:report -- --strict` (257/257),
  `release:check` (0.59.1 → 0.60.0), `build`, `test:boot` — зелёные.

## Что это даёт дальше

* ударения 257 слов теперь **заморожены**: любая случайная правка контента
  падает в CI, а не уезжает к детям;
* новые школьные списки со словами вне банка приходят с готовым ударением,
  если слово есть в словаре, и с честной пометкой «проверьте», если нет;
* пришлёте слово с неверным ударением — это одна строка в словаре
  и одна проверка в тесте.
