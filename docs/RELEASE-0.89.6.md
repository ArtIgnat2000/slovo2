# 0.89.6 — настоящий знак НААШ на школьных вещах

## Зачем

На снимках школьных вещей стоял не знак школы, а «нечто условно похожее»:
треугольник над прямоугольником. Генератор сочинял его по описанию, потому что
канона ему не давали. Пользователь сказал прямо — на школьных вещах логотип
должен быть максимально точным.

## Что сделано

- **Канон знака теперь лежит в репозитории.** `scripts/make-naash-mark.py`
  вырезает знак с листа замков `docs/merch/img/mark-lockups.webp` (там он
  перерисован вектором по присланному логотипу) и сохраняет две версии
  с прозрачным фоном:
  - `docs/naash/mark-color.png` — красная Н, янтарная А, зелёная А, синяя Ш,
    синяя крыша с оконцем и линейка: для эмали и печати по светлому;
  - `docs/naash/mark-mono.png` — тот же контур одним кремовым #F4EFE4:
    вышивка и печать по синему (правило «знак всегда кремовый на синем»).
- **Три школьных снимка пересняты с каноном** (канон подан генератору вторым
  изображением, остальное в кадре не менялось):
  - `school-pin` — на кремовой эмали теперь знак целиком: крыша с оконцем,
    красная Н, янтарная А, зелёная А, синяя Ш и синяя линейка; стенки знака
    читаются как золотистый металл между эмалями;
  - `school-cap` — кремовая вышивка по канону на передней панели: крыша
    с оконцем, четыре буквы, линейка; стежки идут по изгибу панели;
  - `school-hoodie` — кремовая вышивка на груди, тот же контур, те же
    пропорции.
- **Знак в приложении перерисован по канону** (`SchoolMark` в
  `src/ui/MascotLook.tsx`): крыша двойным скатом с оконцем, Н, две «А»-домика,
  Ш и линейка. Раньше там стояло «упрощение до крыши и стеблей», которое на
  15–17 px читалось, но переставало быть знаком школы. Геометрия снята с
  канона в единицах, где высота букв = 100: ширина 194.2, высота 193.3,
  обводка букв 5.4, крыши 7, буква 28.5 с шагом 34.9, перекладина на 76 от
  верха, линейка на 16.1 ниже строки. Правило «без букв и цифр» осталось для
  набора иконок, но не для фирменного знака.
- **Шарф оставлен без знака — осознанно.** По описанию вещи он несёт *цвета*
  знака (полоса-триколор с бахромой), а не сам знак. На вязаном полотне
  генератор кладёт знак перекошенным (две попытки — брак), а вклеенный поверх
  выглядел бы подделкой. Канонный мерч-шарф с маленьким знаком — другой товар
  (`public/naash/scarf-stripes.webp`).

## Как проверено

- Каждый переснятый кадр смотрел на увеличении 2–3×: крыша с оконцем, четыре
  буквы и линейка читаются, знак не перекошен, пропорции совпадают с каноном.
  Брак в партии: 2 кадра шарфа (перекошенный знак) — в дело не пошли.
- `npm run test:galleries` — 13/13, `npm run test:smoke` — зелёный целиком.
- `npm run typecheck`, `npm run build`, `npm run release:check`.
