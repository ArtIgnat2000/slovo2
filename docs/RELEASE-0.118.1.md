# 0.118.1 — «Колесо букв»: буквы больше не идут по кругу по порядку

Замечание владельца по скриншоту: в «Колесе букв» слово **метель** стояло
по часовой стрелке ровно как М → е → т → е → л → ь. «В этой игре буквы не
должны идти по порядку. Так слишком просто».

## Что стало

* **Позиции на круге перемешаны.** `index` буквы остаётся её порядком в
  слове — по нему работает шаг «принимается только следующая буква», — а
  `angle` теперь случайная позиция на окружности. Первая буква больше не
  привязана к «12 часам».
* **Порядок не возвращается случайно.** Если перемешивание дало исходный
  порядок (или подменённый рандом всегда максимальный), позиции сдвигаются
  на одну. Даже на двух буквах круг не читается как слово.
* **Раскладка стабильна для слова.** Сид считается от `id` и текста, а не от
  глобального `Math.random`: один и тот же круг не переставляется на каждом
  рендере и не сдвигает детерминированные сценарии проверок. Другое слово —
  другой круг.
* **Подсказка-огонёк осталась.** Мягкий ореол показывает, где продолжается
  движение после отпускания пальца, но найти следующую букву на перемешанном
  круге всё равно нужно самому.

## Проверки

`tests/games-letter.test.ts` держит: по часовой стрелке буквы не образуют
слово, каждая позиция занята ровно один раз, «ленивый» рандом не оставляет
порядок, на двух буквах круг перевёрнут, раскладка слова стабильна.
`tests/games-letter-ui.test.tsx` проверяет, что `--ring-angle` в DOM идут не
