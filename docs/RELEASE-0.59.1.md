# 0.59.1 — правильное ударение в «подлежащее», «сказуемое», «прощайте»

Отклик: **«в словах подлежащее и сказуемое неправильно поставлено
ударение»**. Проверил — ошибка настоящая, и не только в этих двух словах.

## Что было не так

Автополе своего слова ставило ударение на **последнюю гласную**. Для
большинства коротких слов это подходит, но на школьных терминах ломается:

| слово | было | правильно |
|---|---|---|
| подлежащее | подлежащ**Е**е | подл**Е**жащее |
| сказуемое | сказуемо**Е** | сказ**У**емое |
| прощайте | прощайт**Е** | прощ**А**йте |

«Прощайте» тоже было с ошибкой — оно из того же списка, просто вы её ещё
не заметили.

## Что исправлено

### 1. Словарь известных ударений

`src/content/stress-dict.ts` — маленький словарь: слово → индекс ударной
буквы. Он применяется **везде**, где создаётся карточка своего слова:

* при добавлении готового списка одной кнопкой;
* при вставке списка текстом (и из буфера обмена);
* при чтении профиля — то есть **уже сохранённые списки починятся сами**,
  удалять и добавлять заново не нужно.

Правило проекта: не угадывать там, где ответ известен.

### 2. Ручной выбор родителя важнее словаря

Если ударение поставлено человеком (тап по слогу в «Списках»), карточка
получает флаг `stressManual`, и словарь больше его не перебивает. Раньше
поправка «врукопашную» могла бы затираться при каждом чтении профиля — теперь
нет.

### 3. Автополе осталось только для слов, которых нет в словаре

Для новых слов, которых мы не знаем, ударение по-прежнему ставится на
последнюю гласную, но в предпросмотре списка его видно и можно поправить
одним тапом. Если пришлёте ещё слова с неверным ударением — добавлю их
в словарь одной строкой, и они станут правильными для всех.

## Проверки

Восемь новых проверок в смоуке (по спискам теперь **54**):

* «подлежащее» → **подлежАщее**, «сказуемое» → **сказУемое**,
  «прощайте» → **прощАйте** — сверяется сама буква, а не только индекс;
* ударная буква **не попадает** в «опасные» (иначе задание спрашивало бы
  ровно то, что и так выделено);
* словарь покрывает все три школьных слова;
* **старое неверное значение исправляется при чтении профиля** (подставлено
  `stress: 9`, получено `4`);
* **ручной выбор родителя словарь не перебивает** (`stressManual`);
* пресет целиком приходит с верными ударениями.

Полный контур: `typecheck`, `test:smoke`, `test:guard`, `test:icons`,
`test:content`, `test:adaptive`, `audit:storage`, `demo:check`,
`content:check`, `images:report -- --strict` (257/257),
`release:check` (0.59.0 → 0.59.1), `build`, `test:boot` — зелёные.

## Что нужно от вас

Ничего. Обновите приложение (`?diag=1` → должно быть `v0.59.1`), откройте
«Родителям → 🏫 Списки → Свои слова» — там видно ударные буквы заглавными:
**подлежАщее**, **сказУемое**, **прощАйте**. Если какое-то слово всё ещё
с неверным ударением — напишите, какое: это одна строка в словаре.
