# Релиз 0.11.5 — квадратная картинка в карточке повторения

* Дата: **2026-10-07**
* Ветка: `arena/34ff5809-slovo2` → `main`
* Предыдущий релиз: [`0.11.4`](./RELEASE-0.11.4.md)
* Диагностика после деплоя: `?diag=1` должна показать **v0.11.5**

Патч-релиз по подтверждению пользователя: на актуальном v0.11.4 изображение
в карточке повторения по-прежнему выглядело маленьким.

## Диагноз

Карточка уже использовала широкую фоторамку, но её изображение было flex-элементом
колонки с `flex: 0 1 auto`. Когда по высоте не хватало места, flex сжимал только
высоту, оставляя ширину почти полной. Квадратная картинка с `object-fit: contain`
вписывалась в получившуюся низкую полосу и визуально становилась миниатюрой.
Одного `aspect-ratio: 1` недостаточно, чтобы запретить такое сжатие.

## Что изменилось

1. **Ширина и высота снимка теперь синхронны.** Общий токен
   `--art-lesson-size` ограничен шириной паспарту и `40svh`; на коротких экранах
   (до 680 px высотой) заранее уменьшается до `34svh`.
2. **Flex больше не сплющивает снимок.** `flex: 0 0 var(--art-lesson-size)`
   запрещает shrink, а одинаковые `width` и `height` сохраняют квадрат. На
   обычном iPhone размер доходит примерно до ширины паспарту (~330 px).
3. **Поправлен расчёт предельной ширины:** в токене учтена 2 px рамка карточки
   с каждой стороны. На узких экранах ширина дополнительно ограничивается
   фактической шириной внутренней области карточки.
4. Добавлены регрессионные проверки: единый размер обеих осей, отсутствие
   `flex-shrink` и отдельный размер снимка на коротком экране. Обычная карточка
   урока и напоминание в повторении используют одну композицию.

## Проверить после деплоя

1. Открыть `?diag=1` и убедиться в версии **v0.11.5**.
2. Запустить повторение через «Повтори N слов»: перед упражнением показать
   карточку с заметно крупным квадратным снимком и кнопкой «Вспомнил! 👍».
3. Проверить портретную и горизонтальную ориентации, включая короткий экран:
   снимок остаётся квадратным, слово и кнопки видны, вертикальная прокрутка
   не появляется.
4. Подтвердить вручную на телефоне: геометрию реального Safari/WebView
   автоматические тесты jsdom не рассчитывают.
