# 0.118.8 — Ещё две точечные замены в иллюстрациях 1–4 классов

Продолжен визуальный аудит по `docs/proposals/art-review-1-4.md`.

## Что изменилось

* `chernyy`: вместо плоской палитры — чёрный школьный рюкзак из предложения.
* `vokrug`: вместо пиктограммы дерева с орбитой — ребёнок в окружении сосен.
* `sever` и `vostok`: разные объёмные компасы; первые варианты с квадратным
  фоном отклонены, в пак попали только версии на ровном кремовом фоне.
* `metel` и `veter`: снежная ночная сцена и согнутое ветром дерево вместо
  плоских рисунков.
* `potom`, `vchera`, `segodnya`, `zavtra` и числовые кубики повторно проверены
  и оставлены: их ясные обучающие схемы лучше потенциальных ребусов.
* Отчёт аудита и арт-план обновлены; автоматической перерисовки набора нет.

Новые файлы — 256×256 WebP, каждый меньше 20 КБ.
