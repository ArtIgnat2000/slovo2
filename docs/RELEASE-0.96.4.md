# 0.96.4 — Кроссворд снова собирается, и обе игры меняют слова

Патч по скриншоту владельца: «Кроссворд сломался. В обоих играх так и не
работает смена слов». На снимке от решётки осталась горстка точек в центре
карточки, буквы лежали в пуле, а три вопроса («спокойный разговор», «живое
разумное существо», «аппарат для звонков») не менялись ни на одной новой
сетке.

## Что было сломано

**1. Решётка схлопнулась в точки.** В 0.96.1 у `.cw-grid` появился потолок
ширины (`max-width` от числа колонок), а `width: 100%` при этом потерялся.
Grid с `auto`-шириной и колонками `1fr` не получает свободного места —
колонки сжимаются до минимума (3 px зазора), поэтому клетки выглядели
пунктиром. Лечится возвратом `width: 100%`: `max-width` по-прежнему держит
потолок клетки.

**2. Смена слов не работала — в обеих играх.** Причина одна: доска забирала
весь пул целиком.
- Кроссворд брал `slice(0, maxWords)` (6 слов), а если слов было меньше —
  все; вдобавок «лестница» дотягивала в решётку слова, не поместившиеся в
  лимит. На пуле из трёх изученных слов (`беседа`, `человек`, `телефон`)
  каждая решётка состояла ровно из этих трёх.
- Филворд прятал до семи слов и на пуле из 6 изученных забирал все шесть.

Менять было нечего: `avoidIds` отсекал слова прошлой сетки, но свежих не
оставалось, и движок честно возвращал старые.

## Что изменено

- **Решётка кроссворда:** `width: 100%` вернулся, клетка остаётся в потолке
  42 px (38 на узком телефоне, 48 на планшете).
- **Доска берёт не весь пул, а его часть** (`BOARD_SHARE = 0.6` в обоих
  движках):
  - пул 3–5 слов → сетка берёт все (меньше трёх не собрать);
  - пул 6 → 4 слова (два остаются на следующий раз);
  - пул 9 → 5–6; пул 20+ → 5 (филворд) / 6 (кроссворд) — прежние пределы.
- **«Лестница» больше не добирает слова сверх лимита:** в решётку попадают
  только выбранные слова, остальные честно ждут следующей сетки.
- **Смена слов работает на любом пуле:** каждая новая сетка содержит хотя бы
  одно слово, которого не было в прошлой; на большом пуле повторов нет
  совсем. На пуле из 3–4 слов полностью новых наборов физически не бывает
  (3 из 4, 2 из 3) — это арифметика, а не баг: повтор возможен, но сетка
  никогда не повторяется один в один.

## Проверки

`npm run typecheck`, `npm run test:smoke`, `npm run build`, `npm run test:boot`,
`npm run release:check`.

Новые проверки:
- филворд: на пулах 4/6/9 слов сетки не повторяются один в один и в каждой
  есть новое слово; на пуле 40 слов — ноль повторов;
- кроссворд: то же для решётки + «сетка не забирает весь пул»;
- ранее добавленные: одно слово — одна позиция, дубликаты пула, уникальность
  чипов и слотов.
