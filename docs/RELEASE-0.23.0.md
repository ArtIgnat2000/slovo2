# Релиз 0.23.0 — «Морской флот»: взрослые корабли и отдельные полки

## Запрос

В обратной связи раздел кораблей назвали слишком детским. Попросили заменить
игрушечные кораблики на яхты, контейнеровозы, супертанкеры и военные корабли,
а также разделить «Авто» и «Корабли» для более удобного выбора.

## Что изменилось

* Внутри «Техника» появились самостоятельные вкладки «Авто», «Корабли» и
  «Телефоны». На экране показывается только выбранная полка; переходы «Авто» ↔
  «Корабли» доступны одним нажатием. Ближайшая покупка теперь выбирается из
  текущей полки, а не из другой категории.
* Корабельный каталог обновлён: **морская яхта, контейнеровоз, супертанкер и
  авианосец**. У каждого судна своя цветная карандашная иллюстрация в WebP с
  прозрачным фоном; тот же рисунок используется в карточке магазина и ангаре.
  Визуальный формат и обработка платного тюнинга соответствуют автомобильным
  рисункам.
* Существующие идентификаторы `ship-paper`, `ship-sail` и `ship-steam`
  сохранены, поэтому уже купленные суда, избранное и открытые оттенки остаются
  в профиле. Их отображение обновляется до яхты, контейнеровоза и супертанкера.
  Добавлен новый `ship-carrier` для авианосца.
* Полки в ангаре расположены рядом: авто → корабли → телефоны. Статическая
  демонстрация магазина обновлена вместе с основным экраном.
