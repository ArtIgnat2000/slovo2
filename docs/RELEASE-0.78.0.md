# 0.78.0 — фотореализм: питомцы, спорт, вкусняшки и самолёты

Продолжение 0.77.0: карточка уже показывает крупный снимок во всю ширину,
теперь в студии сняты все питомцы, спорт, вкусняшки и самолёты.

## Что изменилось

- **Питомцы переведены на фото целиком.** Добавлены сфинкс, мейн-кун и слонёнок
  к десяти снимкам из прошлой партии: у всех тринадцати зверей — настоящая
  шерсть, блики в глазах, мягкая тень под лапами. Векторных зверей на полке
  больше нет.
- **Спорт (4):** футбольный мяч с потёртой кожей и видимыми швами, скейт с
  натуральным клёном и оранжевыми колёсами, пара гантелей с металлическими
  бликами, ракетка с натянутой струнной сеткой и мячом.
- **Вкусняшки — все четыре:** пончик с глазурью и посыпкой, кулич с подтёками
  глазури, рожок с тремя шариками мороженого и трёхъярусный торт со свечками.
- **Самолёты — все шесть:** пассажирский джет, схемолёт с солнечными панелями,
  полярный исследователь на лыжном шасси, серебристый лунный самолёт, тяжёлый
  атомный дозор с бирюзовым контуром и стимпанк-биплан «Паролёт» с медными
  крыльями, латунными заклёпками и струйкой пара.
- **Скейт перегенерирован:** у прошлого кадра генератор нарисовал пять колёс.
  Новый снят сверху-сбоку, у него ровно две подвески и четыре колеса.
- Все снимки идут через один конвейер `scripts/make-product-images.mjs`
  (1200×900, WebP): широкий кадр режется по полям, вертикальный вписывается
  целиком на продолженный фон студии.

## Проверки

- Блок `tests/cards-ui.test.tsx` стал полко-зависимым: фото проверяются на
  каждой полке отдельно, «снимок вместо рисунка» — свойство товара, а не всей
  витрины. Добавлен **список ожидания**: товары, которые ещё рисуются
  вектором. На 0.78.0 список пуст: питомцы, спорт, вкусняшки и самолёты
  целиком в студии. Если кто-то вернёт рисунок на уже переехавшую полку,
  проверка упадёт.
- `npm run typecheck`, `npm run test:smoke` — все проверки пройдены.
