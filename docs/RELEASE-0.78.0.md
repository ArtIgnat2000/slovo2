# 0.78.0 — фотореализм: все питомцы, спорт и вкусняшки

Продолжение 0.77.0: карточка уже показывает крупный снимок во всю ширину,
теперь студия переехала ещё на две полки и полностью закрыла питомцев.

## Что изменилось

- **Питомцы переведены на фото целиком.** Добавлены сфинкс, мейн-кун и слонёнок
  к десяти снимкам из прошлой партии: у всех тринадцати зверей — настоящая
  шерсть, блики в глазах, мягкая тень под лапами. Векторных зверей на полке
  больше нет.
- **Спорт:** футбольный мяч с потёртой кожей и видимыми швами, скейт с
  натуральным клёном и оранжевыми колёсами, пара гантелей с металлическими
  бликами, ракетка с натянутой струнной сеткой и мячом.
- **Вкусняшки:** пончик с глазурью и посыпкой и кулич с подтёками глазури.
  Мороженое и торт остаются на следующую партию — генератор в этой партии
  не отдал кадр.
- Все снимки идут через один конвейер `scripts/make-product-images.mjs`
  (1200×900, WebP): широкий кадр режется по полям, вертикальный вписывается
  целиком на продолженный фон студии.

## Проверки

- Блок `tests/cards-ui.test.tsx` стал полко-зависимым: фото проверяются на
  каждой полке отдельно, «снимок вместо рисунка» — свойство товара, а не всей
  витрины. Добавлен **список ожидания**: товары, которые ещё рисуются
  вектором, перечислены явно (`food-icecream`, `food-cake`). Если кто-то
  вернёт рисунок на уже переехавшую полку, проверка упадёт.
- `npm run typecheck`, `npm run test:smoke` — все проверки пройдены.

## Дальше

11 позиций электроники и 4 базы. Подключение — дописывание id в
