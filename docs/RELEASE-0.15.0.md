# Релиз 0.15.0 — магазин «Витрина + Гардероб» (фаза 1)

**Статус (2026-10-17):** версия поднята до `0.15.0` (minor: новый экран,
движки не менялись). Концепция — `docs/shop-concept.md`, живой макет —
`/docs/shop-concept/shop-demo.html` (`npm run demo:check`).

## Что было не так

Магазин — 29 карточек в одной ленте (6 аксессуаров + 10 костюмов +
12 мелодий). Ребёнок видит всё сразу: купленное теряется среди
продаваемого, непонятно «что моё», музыка занимала половину экрана,
а палитра цветов раскрывалась прямо в ленте (верстка прыгала).
К новому контенту (звуки, фоны) такой экран не масштабируется.

## Состав релиза (фаза 1 — только IA, без новых правил)

1. **Два верхних уровня** — сегмент-контрол **Витрина / Гардероб**:
   «чего хочу» и «что моё» больше не смешаны в одной ленте.
   В гардеробе: примерочная (БУК в текущем наряде, ступень роста),
   мои наряды (группировка по слотам), мои костюмы, моя музыка
   (строки выбора + «Тишина»).
2. **Витрина режется чипами-полками по типу товара:** 🎩 Наряды /
   🧩 Костюмы / 🎵 Музыка. Раньше полки были по слотам совы —
   тип товара читался хуже, а новые разделы ломали макет.
   Чипы «🔊 Звуки · скоро» и «🖼 Фоны · скоро» показывают рост
   честно: раздел обещан, но не изображён как товар.
3. **Единый макет карточки** для всех типов товара: арт, название,
   состояние плашкой (Твоя ✓ / Надето ✓ / Собран ✓ / N/9 🧩 /
   ценник 💎) и ОДНО действие. Тап по карточке — подробности.
4. **Подробная карточка — sheet снизу:** крупная примерка, цена,
   действие и 🎨 палитра в одном месте. Палитра больше не
   раскрывается инлайн — верстка не прыгает. Sheet закрывается по
   фону и Escape, ConfirmDialog из sheet — поверх (z-index 40 < 50).
5. **Музыка — отдельная полка** (была половиной экрана): две
   тематические группы «🌿 Спокойный фон» и «🎉 Коллекция и
   награды», примерка ▶ и строка «для взрослых» — в sheet.
   Контракты лицензий (CC BY 4.0, Kevin MacLeod, «Авторы и
   лицензии») сохранены.
6. **Костюмы:** активный сбор — крупно сверху (совой, фрагменты,
   прогресс-полоса), остальные — сеткой с точками прогресса.

**Догматы продукта не менялись:** покупка — только через
ConfirmDialog, купленное сразу надевается, красить можно только
своё (1 💎 за новый оттенок, переключение между открытыми
бесплатно), нет лутбоксов и случайных цветов, музыка не в уроке,
корпус заработанного костюма не красится (только акцент).

**Что намеренно НЕ в релизе** (фаза 2, уже согласована): герой-секция
по `closestItem`, wishlist 🤍 и «Мечты».
