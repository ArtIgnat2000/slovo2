# 0.89.3 — ещё пять пар нарядов, тридцать из тридцати восьми

## Что сделано

- Пять новых полных пар: `bag-pink`, `bracelet-beads`, `bracelet-heart`,
  `dress-pink`, `dress-star`. Итого **30 из 38** нарядов с фото; все пары
  подключены к витрине.
- Кадры самостоятельные, без увеличенных кропов:
  - розовая сумочка — фронт три четверти с бантом и замком; второй кадр —
    сзади: панель, усиленная строчка у колец ручки, изнанка банта и
    задняя пластина замка;
  - браслет с бусинами — кольцо на подставке, порядок пастельных бусин
    и золотое сердечко; второй кадр — сверху: бусины раздвинуты, видно
    белую резинку с узелком, сердечко лежит рядом;
  - браслет с сердечком — цепочка на конусе, серебряное сердце; второй
    кадр — раскладка: открытое пружинное кольцо, удлинитель, сердце ребром;
  - розовое платье — плоская раскладка лицом: белый воротничок с фестонами,
    пышные рукава, сборка по талии; второй кадр — со спины: воротник,
    пуговица на горловине, средний шов, шов талии и подгиб;
  - платье со звёздами — лицом: синий хлопок, звёзды, поясок с бантом;
    второй кадр — со спины: разрез-капля с пуговицей, узел пояса, складки
    и подол.
- Студия одна на всю серию: нейтральный тёпло-серый задник, мягкий свет
  сверху-слева, 4:3, предмет целиком в кадре с полями, без надписей
  и логотипов. Платья — плоская раскладка, как требует стандарт серии
  (никаких человеческих манекенов).
- Сборка штатная: `node scripts/make-product-images.mjs` → 1200×900 WebP.
  В `public/products/` теперь 97 фото, в `public/products/gallery/` — 46.
- Все пять пар прописаны в `OUTFIT_PAIRS` (`src/ui/PhotoPair.tsx`): снимок
  в нише карточки и просмотр двух кадров в листе.
