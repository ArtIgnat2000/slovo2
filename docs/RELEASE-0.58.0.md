# 0.58.0 — списки слов к контрольной

Ваш список из школы уже работает: родитель вставляет текст, ребёнок тренирует
ровно эти слова. Решения, которые вы выбрали, реализованы буквально:
**создаём в «Родителям»**, **награда — только XP**, **свои слова живут только
внутри списка**, **ввод — текстом**.

## Что получилось на вашем списке

| | шт. | что происходит |
|---|---:|---|
| найдено в банке | **23** | берутся готовые карточки: картинка, предложение, мнемоника |
| **свои слова** | **3** | прощайте, подлежащее, сказуемое — приложение делает карточку само |
| повторов / мусора | 0 | убираются автоматически |

Сопоставление нечувствительно к регистру и «ё»: строка **«Береза»** из чата
класса находит в банке «берёза», а карточка остаётся с правильным написанием.
«До  свидания» с двойным пробелом — то же слово.

## Как это выглядит для родителя

«Родителям → **🏫 Списки** → + Новый список к контрольной»:

1. название («Контрольная 12 ноября»);
2. поле «Слова из школы» — вставить из чата, по одному в строке или через
   запятую;
3. **«Проверить список»** — предпросмотр разбора:
   `26 слов · из банка: 23 · своих: 3`;
4. для своих слов ударение ставится **одним тапом по слогу** (по умолчанию —
   последняя гласная, это правится здесь же, до сохранения);
5. «Сохранить список» — и ребёнок видит его на «Уроках».

Списки и свои слова хранятся в профиле ребёнка: у каждого ученика свои,
попадают в выгрузку и в сейф прогресса.

## Как это выглядит для ребёнка

Над полосой «Задания дня» появляется карточка:

```
🏫  Контрольная 12 ноября          Тренировать
    26 слов · тренировано 8
```

Одна кнопка — и открывается обычный урок: те же задания (знакомство, выбор
буквы, сборка, письмо), те же подсказки, та же полоса прогресса. В конце —
обычный экран результатов со звёздами.

## Что специально сделано иначе, чем в уроке

| | урок программы | тренировка списка |
|---|---|---|
| набор слов | слова урока | слова списка |
| «короны» урока | растут | **не меняются** |
| фрагмент пазла | +1 | **не выдаётся** |
| счётчик «уроков за день» | растёт (влияет на задания дня) | **не растёт** |
| награда | XP + недельные бонусы | **только XP** (без кристаллов) |
| прогресс по словам (SRS) | растёт | **растёт** — слова попадают в словарик и в дневной отчёт |

Так список не ломает программу класса, не ускоряет пазлы и не превращается
в источник кристаллов: перезапускать его ради валюты невыгодно.

## Список длиннее одного захода

26 слов не влезают в короткий урок (12–20 карточек), поэтому слова
сортируются по нужде: **сначала невиденные, потом самые слабые и просроченные**.
За несколько заходов список проходится целиком, а не крутит первые 12 слов.
В карточке видно, сколько слов уже тренировано.

## Свои слова: как считается карточка

* **слоги** — по школьному правилу переноса: `под-ле-жа-ще-е`, `я-бло-ня`
  нет — правильно `яб-ло-ня`, `у-че-ник`, `про-щай-те`;
* **ударение** — по умолчанию последняя гласная, правится тапом по слогу;
  ударная буква показывается заглавной (`подлЕжащее`);
* **«опасные» буквы** — безударные гласные, не больше трёх; от них зависят
  задания «выбери букву» и «исправь робота»;
* написание приводится к строчной, как в банке («Прощайте» → «прощайте»),
  кроме слов с заглавной внутри — там регистр часть написания.

## Проверки

Новый набор из **34 проверок** в смоуке (`tests/lists-ui.test.tsx`), главные:

* ваш список разбирается целиком: 26 слов, 23 из банка, 3 своих;
* «Береза» → «берёза», повторы убираются, текст режется по строкам и запятым;
* своё слово получает рабочую карточку, а без резолвера урок был бы **пустым** —
  это отдельная проверка, чтобы никто не «оптимизировал» её обратно;
* свои слова не попадают в банк и в программу класса;
* урок списка собирается с заданиями; ударение меняется через стор;
* список создаётся через настоящую форму в «Родителям» (тыкаем DOM, не API);
* карточка на «Уроках» открывает `list:<id>`;
* выгрузка и чтение возвращают список и свои слова, мусор из файла
  выбрасывается;
* удаление списка не стирает свои слова;
* в дневном отчёте родителя свои слова читаются словом («подлежащее»),
  а не внутренним id.
