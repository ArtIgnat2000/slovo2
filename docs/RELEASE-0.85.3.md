# 0.85.3 — единый стиль фотогалерей

Пересобран просмотр телефонов, кораблей и самолётов: детские рисунки и условные
SVG-сцены убраны из карточек техники. Все 19 моделей получили по два
самостоятельных вида в согласованной нейтральной студийной подаче. Восемь
телефонов получили вид спереди; дополнительные ракурсы добавлены для яхты,
«Стрижа», пяти самолётов научных баз и «Титаника». Для остальных кораблей
использованы ранее подготовленные фотореалистичные рендеры.

Галерея листается тапом, переход мягкий и отключается системной настройкой
уменьшения анимации. Рекомендации по распространению стандарта на остальные
товары описаны в [`docs/proposals/product-galleries.md`](./proposals/product-galleries.md).

## Проверки

Выполнены `npm run test:release`, `npm run typecheck`, `npm run content:check`,
`npm run test:adaptive`, `npm run test:smoke`, `npm run build`,
`npm run test:boot` и `npm run audit:storage`.
