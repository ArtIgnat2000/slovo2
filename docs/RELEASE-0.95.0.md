# 0.95.0 — «Кроссворд дня» в «Играх»

Буквенная механика proposal §5-B. Последняя «скоро»-карточка закрыта:
в «Играх» теперь три свободные игры — «Собери слово», «Филворд»,
«Кроссворд дня». Всё без XP и без SRS: чистое повторение класса.

## Что добавлено

- **Новая игра «Кроссворд дня»** (раздел «Игры»): школьная решётка из
  5–6 изученных слов класса (≤ 9 букв, фразы не берутся).
- **Генератор** `src/engine/crossword.ts`: 120 рестартов жадного размещения
  на полотне 31×31; якорь — самое длинное слово; правила решётки: торцы
  свободны, параллельные слова не касаются, перпендикулярное касание вне
  пересечения запрещено, параллельное наложение запрещено; лучшее поле
  ≤ 13×12; неразместимые слова уходят на «лестницу» (отдельные строки).
  Детерминировано (`seed`), ~20 мс на доску.
- **Подсказки-вопросики**: emoji + значение + «N букв» — обычные карточки
  банка. Слово проверяется **сразу по завершении**: верное зеленеет,
  неверное подсвечивается оранжевым (поправить — тапом по клетке, буква
  вернётся в пул).
- **Пул букв — точное мультимножество клеток решения** (пересечения один
  раз): лишних букв нет, решение единственно по построению.
- «Кроссворд собран!» — баннер победы и «🔄 Ещё кроссворд»; «🔄 Новая
  сетка» доступна всегда. Клетка-буква ≥ 40 px (цели), плитка пула 44×48 px,
  клавиатурная навигация по клеткам и плиткам.
- Поле ≤ 13×12; на 5 класс (длинные слова) размер поля вкладывается
  в телефон за счёт фильтра «только слова ≤ 9 букв».

## Что НЕ сделано (осознанно)

- «Ключевое слово урока выделено цветом» — в 0.95.0 нет честного критерия
  выбора (опасность буквы/длина); отложили.
- Проверка на детях — не проводилась: игра включена как свободная,
  «детей пока не спрашивали».
- Диагонали — только вне рамки; 5 класс идёт по горизонтали/вертикали.

## Известные ограничения

- Генератор жадный: «идеального» кроссворда не гарантирует, но гарантирует
  единственность решения и играбельность (пересечения ≥ 3 на типовом сиде,
  что проверено в смоук-тестах).
- Поле на маленьком телефоне (≤ 360 px) плотное: буквы читаемые, но места впритык.
- Уже распознанная особенность: заполняется «первый пустой» — игрок сам
  решает, с какого слова начать (удобно, потому что подсказки видны).
