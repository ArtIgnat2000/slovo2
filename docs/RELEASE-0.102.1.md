# 0.102.1 — плашка обновления называет установленную версию

Техническая правка без изменения поведения приложения и содержания уроков.
Жалоба владельца: после обновления приложение показывало **не актуальный
номер релиза, а чуть более ранний** — например, «Обновлено до v0.101.0»
сразу после установки 0.102.0.

## Что было не так

Цепочка была такой:

1. Приложение находит новую сборку и перед перезагрузкой вызывает
   `applyUpdateNow()` (`src/platform/pwa.ts`).
2. Перед перезагрузкой в `localStorage` писался ключ
   `slovo2-update-applied` со значением `import.meta.env.VITE_APP_VERSION`.
3. Но исполнялся-то **старый** бандл: `VITE_APP_VERSION` в нём — версия,
   которая уже стоит на устройстве. В ключ попадал прошлый номер.
4. После перезагрузки `takeAppliedVersion()` читал ключ, и `App.tsx`
   показывал тост «Обновлено до v<старое>».

То есть врала только плашка: сам номер версии в бандле, в
«Родителям → Приложение» и в `?diag=1` был верным — он подставляется из
`package.json` при сборке (`vite.config.ts:52`), а деплой идёт из `main`.
Отдельная ловушка: если обновиться с 0.102.0 до 0.102.1, номер совпал бы
случайно, и ошибка могла бы остаться незамеченной. Поэтому исправлено
источник значения, а не симптом.

## Что сделано

* `applyUpdate()` больше не пишет версию: перед перезагрузкой ставится только
  отметка «перезагружались ради обновления» (`'applied'`). Отметку ставит и
  сторож автообновлений (`applyUpdateNow()`), и обе кнопки «Обновить» — в
  меню и в «Родителям → Приложение», — поэтому плашка с верным номером
  появляется во всех трёх путях.
* `takeAppliedVersion()` возвращает `VITE_APP_VERSION` **работающей** сборки —
  то есть той, которая действительно сейчас запущена. Плашка «Обновлено до
  vX» теперь всегда называет установленный номер.
* Отметка по-прежнему показывается один раз: `takeAppliedVersion()` сразу
  стирает ключ, без отметки возвращает `null` (тост не появляется).

Поведение сторожа обновлений, 24-часовое принудительное обновление, схема
доступа, игры, SRS, контент и хранилище не менялись.

## Проверки

* `tests/update-check-ui.test.tsx` — тот же блок про сторож обновлений плюс
  две новые проверки-регрессии: перед перезагрузкой в ключ нарочно кладётся
  чужой номер (`0.0.1`), а плашка всё равно называет версию текущей сборки;
  без отметки плашки нет.
* `npm run typecheck`, `npm run test:smoke` — зелёные.

## Как убедиться на телефоне

1. Открыть установленное приложение на версии 0.102.0, «Родителям →
   Приложение» — там `Версия v0.102.0`.
2. Дождаться плашки «Доступно обновление» (или нажать «Проверить обновления»)
   и обновить.
3. После перезагрузки тост должен сказать **«Обновлено до v0.102.1»** — ровно
   то же, что написано в «Родителям → Приложение» и в `?diag=1`.
