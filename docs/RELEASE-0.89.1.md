# 0.89.1 — ещё четыре пары нарядов, уже на витрине

## Что сделано

- Четыре новые полные пары: `badge-cat` (пересъёмка после брака 0.88.5),
  `wings-butterfly`, `wings-dragon`, `hair-buns`. Итого **20 из 38** нарядов
  с фото, и все двадцать сразу подключены к витрине (0.89.0).
- Кадры самостоятельные, без увеличенных кропов:
  - значок с котиком — лицо эмали на подставке; второй кадр — оборот:
    латунная пластина, булавка с замком, закруглённое ребро и полоска
    голубой эмали по краю;
  - крылья бабочки — печатная сторона, градиент и точки; второй кадр —
    изнанка: подкладка, белая строчка по краю, серые жилки каркаса,
    стянутая ткань в центре и резинки;
  - крылья дракона — тёмно-зелёная кожа, шипы по кромке; второй кадр —
    замша с изнанки, швы в два прокола, люверсы шипов, стропа с резинками;
  - пучки с бантами — два пучка с мятными резинками и кремовыми бантами;
    второй кадр — сзади: защёлки-клипсы, собранная ткань резинок, изнанка
    бантов и низ пучков.
- Студия одна на всю серию: нейтральный тёпло-серый задник без бежевого
  оттенка, мягкий свет сверху-слева, 4:3, предмет целиком в кадре с полями,
  без надписей и логотипов.
- Сборка штатная: `node scripts/make-product-images.mjs` → 1200×900 WebP.
  В `public/products/` теперь 87 фото, в `public/products/gallery/` — 36.

## Забраковано

`hair-ponytail`: главный кадр нормальный, но на втором стойка проходит сквозь
хвост и делит его пополам — читается как брак съёмки, а не как ракурс. Пара
лежит в `images-src/products-pending/`, переснимаем вторым кадром в следующем
заходе.

## Как проверено

- `npm run test:galleries` — 13/13, в том числе «каждая полная пара нарядов
  подключена к витрине»: все четыре новые пары есть в `OUTFIT_PAIRS`, второй
  кадр ведёт на свой файл с подписью.
- Пары просмотрены на контакт-листе до конвертации: один свет, один задник,
  один масштаб, разные ракурсы и стороны, ничего не обрезано рамкой.
- `npm run typecheck`, `npm run build`, `npm run release:check`.
