# СЛОВО 2.0 — 0.14.3

## Светлая тема на Samsung Internet

Жалоба с реального устройства (Android, Samsung Internet, системная тема
светлая): в настройках выбрана «светлая», но весь экран оставался тёмным —
переключение на «тёмная» и обратно ничего не меняло.

Причина — собственный режим «Force dark mode for web content» Samsung
Internet (и части других Android-WebView). Он перекрашивает страницу поверх
её собственной палитры и ориентируется прежде всего на сам тег
`<meta name="color-scheme">`, а не на инлайн-стиль `document.documentElement`,
который приложение обновляло раньше. Из-за этого объявленная в 0.14.2 схема
`color-scheme: only light` применялась к документу, но статичный тег в
`index.html` (`content="light dark"`) так и оставался «поддерживаю обе» —
для части браузеров этого достаточно, чтобы включить собственное
перекрашивание.

Исправлено:

- При каждой смене темы приложение переписывает `<meta name="color-scheme">`
  тем же значением, что и `document.documentElement.style.colorScheme`.
- Обе схемы объявлены со словом `only` (`only light` / `only dark`) — это
  явный сигнал «палитру страницы не трогать», а не просто список
  поддерживаемых вариантов.
- Смоук-проверка `tests/share-ui.test.tsx` проверяет сам тег `<meta>`, а не
  только инлайн-стиль, на всех трёх значениях настройки темы.

Полностью отключить принудительное перекрашивание именно в Samsung Internet
веб-страница не может — это настройка браузера. Если на конкретном
устройстве проблема останется, родителю нужно отключить её вручную: Samsung
Internet → меню (☰) → Настройки → Темы вкладок/Просмотр страниц → «Тёмный
режим для веб-контента» (или Настройки → Lab → «Использовать тёмную тему
сайта») — выключить.
