# 0.69.1 — Упрощение раздела «Родителям» и мобильной навигации

## Что изменено

- В основной навигации родительского раздела четыре коротких пункта: «Обучение», «Списки», «Настройки» и «Ещё». Внутри «Ещё» отдельно открываются «Данные» и «Приложение».
- Сводка обучения стала короче: подробные пояснения скрыты до запроса, ошибки обозначены как накопленные за всё время, а для активного класса есть переход к словарику.
- Для основных элементов управления увеличена минимальная область касания до 48 px; сводка перестраивается на узких экранах.
- Проверки охватывают вложенную навигацию, клавиатурное управление, адаптивные правила и разделение отчёта и настроек.

## Ограничения

- Прогноз срока освоения словаря не добавлялся: приложение пока не хранит достаточную историю изменения прогресса слов.
- Проверка реального отображения на физических устройствах Samsung/Android остаётся отдельным ручным этапом.

## Проверки

- `npm run typecheck`
- `npm run build`
- `npm run test:contrast` — 140 сочетаний, WCAG AA
- `npm run test:smoke`
