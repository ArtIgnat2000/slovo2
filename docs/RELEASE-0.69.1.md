# 0.69.1 — анализ интересов учениц и варианты товаров для магазина

Запрос: **«Требуется проанализировать и предложить, какие товары необходимо
предлагать для учениц-девочек. Сейчас набор товаров явно отражает интересы
мальчиков. Изучи анализ интересов девочек начальной школы и предложи варианты»**.

Это релиз **без изменений в приложении**: только разбор и предложение.
Ни одна вещь не добавлена в каталог — сначала нужно «да» по открытым вопросам
(§10 документа).

## Что сделано

* [`docs/proposals/shop-girls-catalog.md`](./proposals/shop-girls-catalog.md) —
  аудит текущего каталога по коду, данные исследований об интересах девочек
  7–10 лет, принципы, три варианта пакетов товаров с ценами и оценкой работ,
  метрики проверки и риски.
* [`docs/proposals/shop-girls-board.html`](./proposals/shop-girls-board.html) —
  наглядный борд витрины: полки, карточки, цены, переключатель пакетов A/B/C.

## Главное в двух строках

Сейчас **21 из 27** товаров — техника (авто, телефоны, корабли), а все 10
костюмов — «боевая сага»; питомцев, дома, творчества и наклеек нет вообще.
Девочки 1–4 класса по данным двух независимых исследований выбирают
**питомцев** (30 % против 12 %), **раскраски** (27 % против 8 %) и
**обустройство своего мира** (симуляторы: 45 % против 15 %) — ни одного из
этих драйверов в магазине не представлено.

## Рекомендация

1. **A «Быстрый баланс»** (3–5 дней): 13 нарядов (включая новый слот `back`
   для крыльев), 4 «волшебных» костюма в пазл-пул, 3 фона, 2 облика сундука,
   интерес-пикер вместо вопроса о поле.
2. **B «Питомцы и дом»** (2–4 недели): полка 🐾 Питомцы и 🏠 Дом БУКа на
   переиспользовании сцены «Ангар».
3. **C «Творчество»** (3–6 недель): альбом наклеек за уроки, расширенные
   палитры, наклейки на стену в Доме.

Полок «для девочек» не появляется: только интересы, универсальные животные
и дом, никакого поля «пол» в профиле.

## Проверки

Изменений в коде нет, поэтому проверки — обычные для документации:
`npm run test:release`, `npm run release:check` (версия, lock и заметка
согласованы), остальные — без изменений.
