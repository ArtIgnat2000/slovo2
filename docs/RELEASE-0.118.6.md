# 0.118.6 — Проверка иллюстраций 1–4 классов и точечные замены

Проверены контактные листы всех 290 изображений 1–4 классов. Пак неоднороден:
рядом с тёплыми 3D-storybook-иллюстрациями остаются плоские пиктограммы и
схемы. Вместо тотальной перерисовки выбран постепенный подход: менять только
те изображения, которые явно уступают целевому визуальному уровню.

## Что изменилось

* Обновлены 13 WebP: `lisitsa`, `malchik`, `moskva`, `avtomobil`, `rossiya`,
  `shosse`, `bilet`, `gazeta`, `kalendar`, `pogoda`, `zarya`, `rasstoyanie`,
  `bereg`.
* Кандидаты `sever` и `vostok` отклонены из-за заметного квадратного фона.
* Добавлен визуальный аудит с выводами и приоритетным списком на следующие
  небольшие партии: `docs/proposals/art-review-1-4.md`.
* Арт-план дополнен результатами проверки и следующим направлением работы.

## Проверки

`node scripts/image-coverage.mjs` — покрытие классов 1–4 остаётся 100%.
`npm run content:check` — пройдено.
