# 0.87.5 — Компактное меню и быстрые действия

## Что сделано

- Вернули меню телефона к более компактному размеру: умеренные шрифты, меньше отступы и ниже строки.
- Добавили заметный, но добровольный пункт поддержки разработчика. Переход ведёт через экран для взрослых.
- Добавили в меню действие «Поделиться приложением» с QR-кодом и ссылкой.

## Как проверено

- `npm run typecheck`
- `npm run test:smoke`
- `npm run build`
- `npm run test:contrast`
