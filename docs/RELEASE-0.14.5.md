# СЛОВО 2.0 — 0.14.5

## Светлая тема в установленном приложении Android

Обратная связь по 0.14.4: QR-код читается, но светлая тема по-прежнему серая,
а разница при переключении на тёмную очень мала. В обычной вкладке **Samsung
Internet** на том же телефоне переключение работает; проблема проявляется при
запуске **с установленного ярлыка** (там нет адресной строки для `?diag=1`).

**Полевой результат на 0.14.4:** при выключении в Samsung Internet настройки
«Принудительный тёмный режим для веб-контента» и повторном запуске ярлыка
светлая тема стала светлой. При возврате тёмной системной темы Samsung Internet
снова включил этот пункт, и серый экран вернулся. После повторного выключения
**при тёмной теме телефона** светлая тема снова заработала. Это подтверждает
причину на данном устройстве — внешнюю принудительную перекраску; исправление
HTML ниже не было необходимо для этого результата. Не выдаём вычисленный
CSS-цвет за фактический цвет пикселей.

### Исправлено в приложении

- В 0.14.4 исходный `index.html` **всё ещё содержал**
  `<meta name="color-scheme" content="light dark">`. Скрипт менял его на
  `only light` только после прочтения браузером. Теперь первый тег уже
  `only light` **до исполнения скриптов**. Это штатный отказ от Chrome Auto
  Dark; скрипт по-прежнему выбирает сохранённую палитру до первого кадра.
  Если `localStorage` недоступен, скрипт всё равно учитывает системную тему.
- Для тёмной темы метатег теперь `dark` (допустимое значение HTML), а CSS
  остаётся `color-scheme: only dark`. При возврате к светлой оба значения
  переключаются обратно.
- Проверка цвета `canvas` из документации Chrome показывает **только признак
  Auto Dark**. Samsung Internet может перекрасить экран позже, не изменив
  `getComputedStyle`: прежнее «Перекраска браузером: нет» было ложным
  успокоением. Диагностика теперь сообщает о пределах проверки и называет
  вычисленный фон «Фон по CSS», а не «Фон на экране».
- **Диагностику можно открыть прямо из ярлыка:** «Родителям → Настройки → Вид
  → Светлая тема всё равно серая? → Проверить тему и браузер» или «Родителям
  → Приложение → Диагностика приложения». При закрытии взрослый возвращается
  в прежний раздел. Сводка содержит имя браузера, режим ярлыка и User-Agent,
  но не имена учеников; данные никуда не отправляются автоматически.
- Исправлена подсказка для Samsung Internet. В новых версиях нужно
  **выключить** «Принудительный тёмный режим для веб-контента» в настройках
  браузера; на проверенном устройстве после смены системной темы этот пункт
  снова включился — его нужно проверить в привычном режиме телефона. В старых
  версиях пункт Labs «Использовать тёмную тему сайта» нужно, наоборот,
  **включить**. В предыдущей заметке 0.14.4 для Labs была указана неверная
  сторона переключателя. Подсказка больше не советует
  безоговорочно перейти в Chrome: у другого браузера другое локальное
  хранилище, и прогресс туда сам не переносится.

**Ограничение:** если установленный ярлык работает через Samsung Internet с
принудительным затемнением сайтов, веб-страница не может гарантированно
отключить этот фильтр. Статичный метатег решает реальную проблему первого
кадра в поддерживающих его браузерах, но **не обещает** сделать Samsung
Internet светлым при включённой принудительной перекраске. Не удаляйте
ярлык и не очищайте данные браузера ради проверки темы: там находится
прогресс ребёнка.

### Проверка на телефоне после публикации

1. Убедиться в «Родителям → Приложение → Версия», что открыта **0.14.5**;
   при необходимости принять плашку «Доступно обновление», закрыть и снова
   открыть ярлык.
2. Выбрать «светлая». Если экран серый, открыть подсказку рядом с выбором
   темы и «Проверить тему и браузер». Записать/прислать **браузер**, **тему в
   настройках**, **выбранную палитру CSS**, **проверку Auto Dark** и **сборку**
   либо «Скопировать сводку». Отрицательная проверка на Samsung не означает
   отсутствие его фильтра.
3. Если браузер ярлыка — Samsung Internet: в самом Samsung Internet проверить
   «☰ → Настройки → Просмотр веб-страниц и прокрутка → Тёмный режим →
   Принудительный тёмный режим для веб-контента» (**выключить**). В старых
   версиях вместо него — «Настройки → Labs → Использовать тёмную тему сайта»
   (**включить**). Проверять при обычной (в данном случае тёмной) теме телефона:
   после её переключения Force Dark мог вернуться во «вкл». Закрыть ярлык из
   недавних приложений и открыть снова. Названия пунктов зависят от версии и
   языка браузера.
4. Если нужен другой браузер, сначала сохранить файл прогресса в «Родителям
   → Прогресс»; открытие той же ссылки в Chrome не перенесёт данные из
   Samsung Internet автоматически.

QR-код не менялся: исправление 0.14.4 подтверждено пользователем.

### Автоматические проверки

`tests/theme-ui.test.tsx` читает **настоящий** `index.html`: проверяет
статичный `only light` до скрипта, выполнение скрипта с сохранённой темой,
первый запуск и недоступный `localStorage`, синхронизацию CSS/HTML при смене
темы и осторожную формулировку результата для Samsung. UI-проверки открывают
диагностику из обеих вкладок родительского раздела и возвращаются обратно;
`tests/diagnostics-ui.test.tsx` проверяет сводку с браузером/режимом.

Автотесты не эмулируют фильтр Samsung Internet. На реальном Android уже
проверено, что отключение Force Dark возвращает светлую тему **в 0.14.4**;
саму новую сборку 0.14.5 в установленном ярлыке нужно проверить после её
публикации. До этого не называем HTML-правку доказанным решением на Samsung.
