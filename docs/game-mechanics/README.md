# Игровые механики «СЛОВО 2.0» — предложение (2026-10-08)

Документ-предложение: **12 новых игровых механик** для приложения «Слово 2.0»
и **играбельный прототип** пяти из них, который можно потыкать пальцем.

Статус: **идеи, не решения.** Ничего в `src/` этим документом не меняется,
прототип живёт отдельно в `docs/game-mechanics/prototype/` и в приложение не
включён. Большие изменения делаем только после выбора варианта (правило №8
`docs/PLAN.md`).

---

## 0. Куда именно мы встраиваем игру

В приложении уже есть игровой слой: короны за уроки, XP, кристаллы, ежедневные
задания, сундук БУКа, магазин, костюмные пазлы, недельные награды, растущий БУК.
Это **слой наград вокруг** учёбы. Новые механики ниже делятся на три группы:

| Группа | Что это | Зачем она нужна |
|---|---|---|
| **A. Рамка** | мета-слой поверх уроков: маршрут, коллекция, экспедиция | урок перестаёт быть «списком дел» и становится частью одной истории |
| **B. Задание** | новые типы упражнений внутри урока и повторения | тренировка ещё одного канала памяти (моторика, речь, проверка чужого текста) |
| **C. Жизнь** | то, что выходит за экран или привязано к дню | перенос орфограммы в реальную жизнь и «мягкие» удержание и возврат |

Методическая рамка не меняется: знакомство → проговаривание → закрепление →
извлечение из памяти → интерливинг (SRS) → отработка ошибок. Каждая механика
ниже обязана опираться хотя бы на один шаг этой цепочки, иначе она просто шум.

**Не делаем ни в одной механике** (принятые решения, не пересматриваем):
жизни/сердечки, стресс-таймеры, публичные лидерборды, случайные лутбоксы,
плату за базовое, наказание за ошибку, аудио и сетевые запросы.

## 2. Главный вопрос: рамка вместо списка уроков (варианты A/B/C)

Сейчас главный экран — список из 16 уроков с коронами. Он честный, но
«служебный»: ребёнок видит расписание, а не игру. Предлагаю выбрать **одну**
рамку (можно совместить с М2 и М3 позже как слои, но начинать надо с одной).

### Вариант A — «Путешествие БУКа» (карта)

*(играется в прототипе: `prototype/index.html` → «Путешествие БУКа»)*

16 станций-тем стоят вдоль маршрута: школа → птицы → звери → … → страна.
Станцию открывает пройденный урок; между станциями БУК идёт, а не «прыгает».
На каждой 4-й станции — привал: короткая сценка с выбором (куда идти дальше,
куда поставить палатку), который ни на что не влияет кроме картинки и
самоощущения. Финал маршрута — «полёт домой» (церемония на уже собранных
костюмах).

* **Плюсы:** превращает список в путешествие, даёт ощущение «я иду», видно
  пройденное и предстоящее; полностью на своём контенте (16 тем уже есть);
  привалы дают место для истории без новых систем.
* **Минусы:** самая объёмная переделка главного экрана; надо аккуратно
  сохранить быстрый доступ к «Повторению» и к ближайшему уроку (одна кнопка
  «Продолжить» должна остаться); риск, что ребёнок «играет в карту» вместо
  урока — лечится тем, что открыта только одна следующая станция.
* **Совместимость с текущими решениями:** статус короны остаётся на станции,
  «Повторение» — отдельная остановка внизу карты («тропинка БУКа»).

### Вариант B — «Книга слов» (коллекция)

Главный экран — альбом: страницы по темам, на каждой — места под слова.
Освоенное слово «вклеивается» наклейкой с картинкой и опасной буквой; не
освоенное — пустой контур с «?». Собранная страница получает обложку-тему.

* **Плюсы:** долгий видимый прогресс (94 слова = 94 наклейки), идеально
  объясняет родителю «что выучено», не требует новых экранов урока; мотивация
  «заполнить дырочку» работает без наказаний.
* **Минусы:** слабее «приключение», сильнее «работа»; если наклеек много,
  у ребёнка может возникнуть чувство долга («92 пустых места») — лечится
  тем, что видны только 2 страницы вокруг текущей, остальные «закрыты краем».
* **Родство:** пазлы костюмов уже дают «собери N фрагментов» — механика
  доказала, что коллекция на этом возрасте работает.

### Вариант C — «Экспедиция недели» (история на 7 дней)

Неделя = одна история. Понедельник — «собираемся в путь», день занятий
открывает следующую страницу, воскресенье — финал главы с артом. Заменяет
абстрактные пороги «3/5/7 дней» недельных наград на понятный сюжет.

* **Плюсы:** самая дешёвая по коду (текст + 7 картинок), хорошо работает на
  возврат, не трогает структуру уроков; можно выдавать вместе с текущими
  недельными кристаллами.
* **Минусы:** недельный сброс = «всё сначала», а сбросы в этом возрасте
  демотивируют; пропуск дня нельзя показывать печалью (только «у истории есть
  концовка, дальше — новая история»).
* **Важно:** если брать — то строго **без** «ты потерял день», как недельные
  награды сейчас.

### Рекомендация

**A как основной экран + B как отдельная вкладка-альбом** — они не спорят:
маршрут отвечает «куда я иду», альбом — «что я собрал». C даёт самый быстрый
эффект, но это украшение поверх недель, а не рамка: её логичнее добавить позже
как «страницу путешествия» (между привалами). М4 («Дом БУКа») я бы отложил:
три мета-слоя одновременно — много для 8 лет.

## 3. Механики подробно

### М1. «Путешествие БУКа» (карта маршрута)

**Как играется.** Вертикальная карта с «дорожкой»: станции = 16 уроков. Текущая
станция пульсирует, у пройденных — корона по уровню (есть в профиле: `level`),
следующая — закрыта облаком. БУК стоит рядом с текущей станцией. Тап по станции
открывает урок; после результата БУК «доходит» до неё с коротким шагом. Привалы:
после каждой 4-й станции — карточка-сценка с двумя вариантами («поставить
палатку у реки / на холме»), выбор рисует разный фон и оставляет след в профиле.

**Почему работает.** Прогресс становится пространственным: видно, сколько
пройдено и что впереди. Это ровно то, что делает Duolingo, но у нас уже есть
готовые 16 осмысленных эмодзи-тем и БУК, поэтому ассеты почти не нужны.

**Куда встраивается.** Новый экран `JourneyScreen` вместо списка в `HomeScreen`;
математика — чистая (`engine/journey.ts`): «пройдено → открыто», максимум одна
новая станция за урок, сценки-привалы — константа. Состояние в профиль не нужно:
всё выводится из `profile.lessons`.

**Риски и что не нарушаем.** Не заменяем кнопку «Продолжить» и «Повторение»;
никаких штрафов за «отошёл от маршрута»; закрытая станция не замотивирована
чувством вины — просто «облако, придёт время».

### М2. «Книга слов» (альбом-коллекция)

**Как играется.** Вкладка «Мои слова»: страницы по темам, на каждой 4–8 мест.
Слово попадает на страницу, когда ребёнок уверенно написал его (например,
`WordState.s ≥ 70` или 2 верных ответа подряд — порог обсуждаем). Наклейка
живая: картинка, под ней слово, опасная буква обведена лиловым. Собранная
страница закрывается обложкой темы и открывает «финальный разворот»
(пример: все слова темы в одном предложении-рассказе). Пустые места — только у
2–3 ближайших страниц, дальше страница-контур.

**Почему работает.** Коллекция — самая устойчивая мотивация этого возраста,
и она честная: наклейку нельзя купить или получить за кнопку, только за
реальную извлекаемую память. Родителю это ещё и понятный отчёт «что выучено».

**Куда встраивается.** `engine/album.ts` (правило «слово → на страницу»),
экран `AlbumScreen`. Снимок слова уже есть — переиспользуем `WordView` в
режиме компактной карточки.

**Риски.** Не превращать в «долг»: показывать закрытые страницы силуэтом и
никогда — «у тебя 92 пустых места». Слова не отбирать; «вернулось на страницу»
не бывает — наклейка, один раз вклеенная, не отклеивается (иначе коллекция
начнёт наказывать).

### М3. «Экспедиция недели» (7 дней — одна история)

**Как играется.** Понедельник открывает карточку «Собираем рюкзак», каждый
занятый день — следующую страницу (2–3 предложения текста + арт), в активные
дни недели пороги 3/5/7 дней выплачивают свои 💎 **внутри** страниц, воскресенье
— финальная страница с костюмным или фоновым артом. Если день пропущен — не
«сломано», а «история продолжится в следующий раз»; в конце недели — новая
история.

**Почему работает.** Даёт причину открыть приложение «просто посмотреть», не
трогая учебную часть, а недельные награды получают объяснение.

**Куда встраивается.** `engine/expedition.ts` + данные историй (7×N текстов).
Текущие `weekly-rewards` не переписываем: страницы становятся их оболочкой.
Суммы 💎 (5/10/15) — **временные, не утверждённые**, пока не решено отдельно.

**Риски.** Никакой печали за пропуск; тексты короткие (2–3 предложения), иначе
превращается в чтение вместо игры.

### М4. «Дом БУКа» (дачный участок) — отложить

**Как играется.** За каждые N уроков на полянке БУКа появляется предмет:
скворечник, фонарь, качели, грядка. Тап по предмету — маленькая сценка. Ничего
не пропадает, ничего не «засыхает», предметы не покупаются.

**Почему откладываю.** Это третий мета-слой (после A и B). Сам по себе хорош:
мягкий, необязательный, визуально «мой дом». Но если запускать три рамки сразу,
внимание ребёнка рассеивается, а мы теряем чистый сигнал в полевом тесте:
не понять, что именно сработало.

### М5. «Буквы-шпионы» (новый поворот в «Собери»)

**Как играется.** В задании «Собери» среди плиток есть 1–2 буквы, которых в
слове нет, — «шпионы». Если ребёнок ставит шпиона, плитка не встаёт: она
отпрыгивает с «пшик», а БУК комментирует («в слове `класс` нет третьей С»).
Ошибка не засчитывается как ошибка упражнения: это исследование.

**Почему работает.** Убирает главную слабость нынешнего «Собери»: слово можно
собрать, просто переставляя плитки до совпадения. Со шпионами приходится
вспоминать состав слова. Это чистый тренажёр «сколько и каких букв», то есть
удвоенные согласные, `Ь` и безударные гласные — наши самые частые ошибки.

**Куда встраивается.** `engine/scheduler.ts`: в `letters` добавляются лишние
плитки (детерминированно от слова и прогресса: шпионы — соседние по звучанию
буквы, например `о/а`, `с/сс`, `ь`). В `TaskView` — состояние «шпион отпрыгнул».

**Риски.** Шпион не должен выглядеть как «правильный ответ, который отобрали»:
нужна реакция и объяснение. На первых уроках шпионов нет вовсе.

### М6. «Слоговый барабан» (ритм + проговаривание)

**Как играется.** Перед заданием — экран со слогами-плитами. Плиты подсвечиваются
по очереди (метроном 1 удар/сек), ребёнок стучит по ним в такт, устройство
отвечает вибрацией (`haptics` уже есть) и звуком-кликом (можно отключить). Затем
слоги закрываются, и ребёнок пишет слово. За ритм отдельной награды нет — ритм
это способ запомнить, а не самоцель.

**Почему работает.** Это ядро методики словарных слов: слово проговаривается
по слогам («Мос-ква»), а моторика + вибрация дают второй канал памяти.
У нас уже размечены слоги у всех 94 слов, но нынешнее задание «Прочитай по
слогам» — пассивное (тап по плитам без ритма).

**Куда встраивается.** Расширение `syllables`-задания: `sm/**`, чтобы «стук»
совпадал с реальным проговариванием; вибрация — через `platform/haptics`.

**Риски.** Тактильность мы не можем проверить в песочнице: нужен телефон
(Android/iPhone) и отдельное решение «даём ли звук». Пока не проверено — держать
как вариант, не включать.

### М7. «Эхо-дуэль: ты — учитель»

**Как играется.** БУК пишет первую букву или слог слова (иногда **с ошибкой**:
«руский» вместо «русский»), ребёнок продолжает и должен поймать подвох. Версии:
(1) БУК пишет правильно, ребёнок продолжает; (2) БУК ошибается, ребёнок
исправляет и ставит «птичку» БУКу. Ошибочные варианты БУКа берём не случайные,
а из реальных ошибок ребёнка (`profile.errors`) — тогда упражнение работает
ровно на его пробелах.

**Почему работает.** Смена роли снимает страх ошибки (ошибается «учитель», а
не я) и заставляет применить правило проверки. Это самая дешёвая форма
«взаимного обучения», которая работает и соло.

**Куда встраивается.** Новый `TaskKind: 'teach'`; данные ошибок уже есть.

**Риски.** БУК не должен ошибаться слишком часто, иначе ребёнок перестанет
ему верить; баланс — не больше 1 ошибки на урок.

### М8. «Записка БУКа» (БУК-детектив)

**Как играется.** Раз в 2–3 дня на главной появляется конверт: короткая записка
от БУКа (3–5 предложений), в которой 1–2 слова написаны неверно. Ребёнок
нажимает на неверное слово, правит букву — записка продолжается, в конце
короткая разгадка и находка (наклейка в книгу М2 или фрагмент пазла). Одна
загадка = 3–4 письма.

**Почему работает.** Ошибка перестаёт быть «про меня» и становится «про
задачу». Плюс это единственная механика, где слово живёт в связном тексте, а не
в карточке, — а это и есть цель обучения (правильно писать в тексте).

**Куда встраивается.** `engine/notes.ts` (сценарий писем), компонент письма с
интерактивными словами. Ошибки внутри письма — из типовых, не из личных
(личные — в М7).

**Риски.** Тексты надо писать вручную 94 словами не обойтись; начинать с 1 серии
из 3 писем. Никаких таймеров: записка ждёт сколько нужно.

### М9. «Две двери» (ловушка выбора)

**Как играется.** Экран-коридор, две двери: за одной верное написание, за другой
— типовая ошибка (`корова/карова`). Ребёнок открывает дверь; ошибка — дверь
«не поддаётся», показываем правильную и почему (`корОва — два О`). Форма:
визуальный выбор вместо кнопок. Годится как «мостик» перед диктантом.

**Почему работает.** Активное различение двух вариантов эффективнее, чем
выбор одной буквы из строки: ребёнок удерживает два образа и сравнивает.

**Куда встраивается.** Подвид `gap` с двумя крупными дверьми. Контент: пары
«верно / типичная ошибка» уже частично есть в задании «Исправь робота».

### М10. «Опасная башня»

**Как играется.** Слово собирается снизу вверх, как башня; у этажа с опасной
буквой — замок. Ребёнок ставит буквы, замок загорается, когда опасная буква на
месте (до этого этаж «шатается»). В конце башня светится — визуальная опора
на «опасное место», которое до сих пор живёт только красным цветом на карточке.

**Почему работает.** Даёт телесную метафору орфограмме: «опасное место — это
замок, он держит башню». Мнемоника не заменяет правило, но даёт зацепку.

**Куда встраивается.** Скин для `build` + `danger`-подсветка. Самый дешёвый
вариант — не новый тип задания, а «тема» для существующего.

### М11. «Слово вокруг» (охота в реальной жизни)

**Как играется.** Раз в неделю — «охота»: список из 3 слов («найди, где живёт
слово `аптека`») + галочка «увидел в жизни». Никаких фото и камеры: подтверждает
взрослый или просто честное «да». Награда — бейдж «Сыщик слов» и небольшая
запись в родительский отчёт.

**Почему работает.** Главный методический результат 2 класса — ребёнок замечает
словарное слово вне тетради. Это единственная механика, которая специально
тренирует перенос.

**Куда встраивается.** Простейший чек-лист + бейдж; ничего не ломает.

**Риски.** Не превращать в слежку и в требования «принеси фото». Ошибка не
наказывается: просто «ещё не встретилось».

### М12. «Смелость» (челлендж без подсказки)

**Как играется.** Перед заданием есть кнопка «Отвечу сам, без подсказки»:
подсказка на это задание закрывается, а за верный ответ ребёнок получает не
только 10 XP, но и «звёздочку смелости» (косметическая валюта: банты/шарфы
для БУКа нового цвета). Открыть подсказку потом всё равно можно — режим
добровольный, наказания нет.

**Почему работает.** Сейчас подсказка просто «стоит 3 XP» — это пассивный
стимул. Активный выбор «я попробую сам» включает самоконтроль, а косметика даёт
повод вернуться к челленджу, не превращая его в обязанность.

**Куда встраивается.** Кнопка в шапке задания + счётчик в профиле + один слот
косметики. Полностью офлайн, без лутбоксов.

## 3.5. Три настоящие игры (играбельные в прототипе)

Механики выше — это **рамка и задания**: они делают учёбу приятнее, но сами
игрой не являются (нет цели на сессию, нет счёта, нечего «выиграть»). Ниже — три
вещи, которые ребёнок назвал бы игрой, а не уроком. Все три уже играются в
прототипе (`prototype/index.html`, раздел «🎮 Игры»).

Общие правила серии — из принятых решений, не пересматриваем:

* **проиграть нельзя.** Нет жизней, нет «game over», нет таймера на реакцию.
  Худшее, что случается, — «попробуй ещё», и игра продолжается с того же места;
* ошибка **не отнимает** ни прогресс, ни награду;
* у каждой игры есть **цель на сессию** (дойти, съесть, найти) и **экран победы**
  с кнопкой «ещё раз» — это и отличает игру от задания;
* сложность растёт от действия ребёнка, а не от часов;
* всё офлайн, без аудио, без сети, на настоящих 94 словах.

### Г1. «Бродилка БУКа» — игра с кубиком

> **Статус: реализована в приложении (2026-10-08, часть 29 `docs/PLAN.md`).**
> Карточка «🎲 Бродилка БУКа» на главной → отдельный режим: `src/engine/board.ts`
> и `src/ui/screens/GameScreen.tsx`; буквы-шпионы живут в задании «Собери»
> (`Task.spies` в `src/ui/TaskView.tsx`). Награды 5/1/2/10 💎 — предварительные,
> не утверждённые. Остальные игры ниже по-прежнему играются в прототипе.

**Правила.** Маршрут из 16 клеток: 12 станций и 4 привала. Ребёнок бросает
кубик (1–3 шага), БУК шагает по клеткам. Попал на станцию — она «ждёт»: надо
собрать слово темы, и тогда станция становится твоей (+5 💎, слово уходит в
книгу). Попал на привал — «отдохнули», +2 💎, кубик дальше. Дошёл до конца —
финиш, +10 💎 и экран победы.

**Почему это игра, а не задание.** Есть кубик (азарт и непредсказуемость), ход,
счёт по клеткам, события на клетках и финиш. Ребёнок не «выполняет упражнение»,
а **идёт по карте**, и учёба — цена шага, а не самоцель.

**Что важно.** Кубик никогда не отбрасывает назад; станция не закрывается, если
её пропустил (её возьмёшь на новом круге); закрыть задание и не решить слово —
не тупик, кубик просто возвращается. В приложении это **режим «поиграть»**
к карте из М1: сама карта остаётся навигацией, бродилка — игра на той же карте.

### Г2. «Буквоед» — змейка, которая ест буквы

**Правила.** Поле 7×9. Буквоед ползёт сам, ребёнок задаёт направление
(кнопки, стрелки на клавиатуре или свайп). На поле — **одна нужная буква** и
2–4 **шпиона** (буквы, которых в слове нет). Съел нужную — стал длиннее,
буква встала на своё место в слове сверху. Съел шпиона — «пшик», шпион убежал
на другое место. Собрал слово целиком — победа, слово в книгу слов, +5 💎.

**Почему это игра.** Классическая змейка с движением, ростом и охотой; время
идёт (змейка ползёт), но **ошибка не убивает** — стенки заворачивают на другую
сторону, шпионы не ядовиты. Это снимает главный конфликт «аркада против
доброты»: азарт есть, наказания нет.

**Что даёт по методике.** Состав слова и порядок букв — та самая орфограмма,
которую не проверить правилом (удвоенные согласные, «ь», безударные гласные).
Ребёнок не угадывает, а ищет конкретную следующую букву.

### Г3. «Сыщик слов» — охота за ошибками

**Правила.** Робот-двоечник написал слова на табличках и наделал ошибок.
Раунд 1: 6 слов, 2 с ошибкой; раунд 2: 8 слов, 3 с ошибкой; раунд 3: 8 слов,
3 ошибки, но ловушки тоньше (меняем второе «опасное место»). Нашёл и нажал
неправильное — табличка становится правильной и объясняет почему. Нажал верное
слово — «здесь всё верно», это **ложная тревога**, которая влияет только на
звёзды (3 — без промахов, 2 — до двух, 1 — в остальных случаях; ноль звёзд не
выдаём никогда). Три раунда — «смена закрыта».

**Почему это игра.** Есть охота и азарт «найти быстрее», есть счёт и смена
раундов, есть награда и звёзды за чистоту. Нет таймера: думать можно сколько
угодно — темп задаёт сам ребёнок.

**Что даёт.** Самая близкая тренировка к диктанту и самая честная: ошибки
робота построены на реальных орфограммах контент-пака (`makeWrong`: подмена
опасной гласной, потерянная двойная согласная, выпавший «ь»), и кривое слово
никогда не совпадает с настоящим словом из словаря — проверка это стережёт.

### Куда это ставить в приложении

Игры не заменяют урок: это отдельный вход «поиграть». Варианты, которые надо
выбрать: (а) раздел **V-labs** (он уже есть и не лезет во внешнюю навигацию);
(б) новая вкладка **«Игры»** рядом с «Повторением»; (в) точка входа с главной
(«Хочешь поиграть?»), но с ограничением по времени сессии. Мой выбор — (а) на
первый заход: меньше риска для основной воронки и честнее по отношению к
родителю («это отдельный игровой уголок»).

## 4. Что не берём (чтобы не спорить потом)

| Идея | Почему нет |
|---|---|
| Таймер на слово, «успей за 5 секунд» | стресс; прямая рекомендация родительских ревью — не делать |
| Жизни/сердечки, «закончились попытки» | ошибка должна быть возможностью научиться (решение №4) |
| Публичный рейтинг, «обгони друга» | социальное давление во 2 классе (решение №5) |
| Случайный сундук со шмотками за деньги | лутбокс-стресс и платная случайность |
| Озвучка привет-словом без обсуждения | отложено решением №6, аудио и сеть — только отдельно |
| «Брось БУКа с инерцией» и прочая физика | отдельный список «нельзя без согласования» |

## 5. Прототип: потыкать пальцем

`docs/game-mechanics/prototype/index.html` — отдельная страница (vanilla JS, без
сборки, без сети, без аудио) на **реальных данных** приложения
(`src/content/words.ts` → `prototype/data.js`, 94 слова и 16 тем) и в реальных
картинках (`public/words/*.webp`).

**🎮 Игры** (раздел «Игры» на главной прототипа) — те самые Г1–Г3:
кубик-бродилка, змейка-буквоед и охота за ошибками. Каждая — с целью, счётом и
экраном победы.

**🧩 Механики** (разбор, чтобы оценить рамку и задания):

1. **🗺️ Путешествие БУКа** — карта 16 станций, БУК идёт по маршруту, станцию
   открывает собранное слово темы (механика М1 + М5).
2. **📖 Книга слов** — альбом наклеек: освоенные слова вклеены, остальные —
   контуры с «?»; тап по наклейке открывает карточку слова (М2).
3. **🔨 Мастерская слова** — свободная сборка слова по картинке с буквами-шпионами
   без оценки и без «провала» (М5).
4. **🥁 Слоговый барабан** — ритм по слогам с вибрацией и закрытыми слогами,
   потом сборка слова из слогов (М6).
5. **✉️ Записка БУКа** — три письма с типовыми ошибками: найди и почини слово (М8).

Прогресс прототипа хранится в `localStorage` под своим ключом, к профилю
приложения не прикасается; есть кнопки «демо-прогресс» и «сброс».

```bash
npm run proto:serve     # http://localhost:8099/ → сразу страница прототипа
npm run proto:check     # 67 автопроверок прототипа в jsdom
```

Проверка не входит в общий контур релиза: поломка демонстрации не должна
блокировать выпуск приложения, но и незаметно гнить ей не даём.
