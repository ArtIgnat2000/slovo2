# 0.84.1 — наборы баз дешевле

Жалоба: цены на наборы неадекватно высокие. Набор (база + машина + самолёт +
костюм) стоил **втрое** дороже тех же вещей по отдельности
(`BASE_SET_PRICE_MULTIPLIER = 3`) — покупать его было заведомо невыгодно.

## Что изменилось

- Набор теперь выгодный пакет: **75% от суммы недостающих частей** (скидка 25%),
  результат округляется до целого. Если всё уже куплено — цена 0, как раньше.
- Подписи в магазине: «Цена — за недостающие части со скидкой 25%».
- Цены наборов с нуля: «Атом» 2100 → 525, «Импульс» 1352 → 338,
  «Полярный» 1560 → 390, «Луна» 1740 → 435, «Пар» 1696 → 424.

Цены отдельных предметов не менялись. Скидка — одна константа в
`src/engine/base-sets.ts`.
