# 0.87.6 — QR добровольной поддержки

## Что сделано

- После перехода к поддержке из меню и успешной взрослой проверки блок перевода автоматически раскрывается.
- Экран прокручивается к QR-коду; рядом остаётся ссылка для открытия на этом телефоне.
- Добавлена smoke-проверка полного сценария: меню → взрослая проверка → видимый QR.

## Как проверено

- `npm run typecheck`
- `npm run test:smoke`
- `npm run build`
- `git diff --check`
