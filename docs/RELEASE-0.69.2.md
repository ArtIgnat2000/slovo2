# 0.69.2 — обнуление кристаллов

## Что изменено

- В разделе **«Родителям → Ещё → Данные»** добавлена кнопка «Обнулить кристаллы». Она после подтверждения обнуляет баланс только выбранного ребёнка, сохраняя слова, опыт, серию и покупки; при нулевом балансе кнопка недоступна.
- Перед сбросом создаётся копия профиля в корзине (до пяти копий на срок до 30 дней). Её возврат требует подтверждения и восстанавливает профиль целиком.
- Полный сброс прогресса по-прежнему очищает и кристаллы. Исправлена гонка, при которой начатая до сброса синхронизация могла вернуть старый баланс.
- Отложенная проверка неудавшейся покупки больше не отменяет сброс, в том числе при обновлении из другой вкладки. Если сброшен только баланс, несохранившаяся покупка отменяется, а новые кристаллы не затрагиваются.

## Проверки

- `npm run test:release`, `npm run release:check`
- `npm run typecheck`, `npm run content:check`, `npm run test:content`
- `npm run test:adaptive`, `npm run test:guard`, `npm run test:smoke`
- `npm run build`, `npm run test:boot`, `npm run audit:storage`

Регрессионные проверки охватывают подтверждение и отмену сброса, изоляцию профилей, отображение и сохранение нулевого баланса, восстановление копии, синхронизацию и незавершённые покупки.
