# 0.100.0 — рекорды сеточных игр

- Филворд и кроссворд запоминают число завершённых сеток и максимальное число слов в завершённой сетке.
- Личный рекорд показан в финале; общий счётчик — во вкладке «Игры».
- «Родителям → Обучение» показывает статистику отдельно по двум играм. Это актуальное место отчёта: бывший раздел «Прогресс» теперь называется «Данные» и занят резервными копиями.
- Статистика начинается с этой версии, разделена по ID профиля, хранится локально (`slovo2-game-records:<id>`). Не входит в экспорт/восстановление учебного прогресса, не синхронизируется и пропадёт при очистке данных сайта. Рекорд — размер сетки, не оценка освоения слов.
- Повторная доставка результата текущей партии не увеличивает счётчик. Новая завершённая партия засчитывается и после исчерпания дневных наград.
- При недоступности localStorage игра и награды работают дальше; несохранённый рекорд не отображается как сохранённый.
- Сеточные игры перемонтируются при смене профиля, чтобы незавершённое поле не досталось другому ребёнку.

Учебный прогресс, SRS, экономика, доступ к играм, генераторы сеток и дизайн новых игр не изменены. «Собери слово» не считается завершённой сеткой.

Проверки добавлены в test:smoke: изоляция профилей и игр, максимум, повтор результата, чтение сохранённых данных, повреждённое хранилище, сбой записи, неверные размеры; запись и отображение рекордов в игровых UI.

Проверено в рабочей ветке: `typecheck`, `test:smoke`, `content:check`, `test:content`, `test:adaptive`, `audit:storage` (10 сценариев без подтверждённой потери), `build`, `test:boot`, `test:release`, `release:check` с точным заголовком. Живой прогон на телефоне не выполнялся.
