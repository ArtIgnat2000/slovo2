# 0.72.2 — iPhone 18: как настоящий, основной цвет — бордовый

По просьбе «сделай 18 айфон более похожим на настоящий и сделай основным цветом 18 линейки бордовый».

## Что изменено

- **Вся линейка iPhone 18 перегенерирована в фотореалистичном стиле настоящего флагмана**: стеклянные спинки с настоящими отражениями, полированные металлические рамки, крупные модули камер-плато в левом верхнем углу, вспышки и сенсоры — вместо прежних мультяшных 3D-спинок 0.72.1.
- **Основной цвет линейки — бордовый**, у каждой модели свой оттенок: iPhone 18 — глянцевый бордовый (две камеры), 18 Air — светло-бордовый, самый тонкий, с одной камерой в «пилюле», 18 Pro — матовый тёмный бордо-титан (три камеры), 18 Pro Max — самый тёмный винный (три камеры).
- **18 Pro Max дополнительно приближен к настоящему** (по открытым фотографиям и описаниям iPhone 17 Pro Max / утечкам 18 Pro Max): широкое плато камер на всю ширину спинки, три объектива треугольником слева, вспышка и LiDAR справа на плато, алюминиевый unibody-корпус и большое стеклянное «окошко» Ceramic Shield под плато.
- Диагональные исходники Air и Pro Max не выравнивались поворотом без потери «настоящести», поэтому Air и Pro Max сгенерированы заново сразу в вертикальной ориентации; силуэты всех четырёх спинок стоят вертикально (960×960, прозрачный фон, посадка как у остальных телефонов, маска перекраски работает).
- **Базовые палитры перекраски** линейки теперь бордовые («Бордовый», «Светло-бордовый», «Тёмный бордо», «Винный») — магазинный тюнинг по умолчанию красит в цвет картинки; описания моделей в каталоге обновлены под новый цвет. Прежние цвета остались доступны дополнительными оттенками палитр.

- `npm run test:release`, `npm run release:check` (0.72.1 → 0.72.2), `npm run build`, `npm run test:boot` — зелёные.
