# 0.118.4 — «Колесо букв»: крупная иллюстрация без паспарту, без подсказки

Владелец попросил увеличить колесо, убрать паспарту у рисунка и не показывать,
какая буква следующая: ореол на одной букве делал задание слишком лёгким.

## Что изменилось

* **Иллюстрация.** Рисунок стоит в центре колеса, увеличен и показывается без
  паспарту — без плиты, внутреннего поля, рамки и тени. Размер адаптируется
  к доступному диаметру; правило отдельной иллюстрации без паспарту внесено
  в `docs/PROJECT-RULES.md`.
* **Круг.** Максимальный диаметр вырос с 280 до 320 px и по-прежнему
  ограничивается шириной и высотой экрана.
* **Никакого указателя на следующую букву.** Убрано свечение верного кружка;
  сообщение об ошибке нейтральное и не говорит, куда нажать. Подписи для
  экранного диктора также не раскрывают порядковый номер буквы.
* **Буквы-дубликаты.** Как в предыдущем изменении колеса, любую ещё не
  выбранную букву с правильным символом можно взять независимо от её позиции.

## Проверки

`npm run typecheck`, `npm run build` и целевые engine/UI-проверки колеса
пройдены. UI-тесты проверяют иллюстрацию без паспарту, увеличенный размер,
отсутствие подсветки следующей и нейтральную реакцию на ошибку.
