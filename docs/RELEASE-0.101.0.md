# 0.101.0 — Мемори

Четвёртая игра в группе «Подумать». Открывается третьим ключом дня; родительская настройка «все открыты» работает как раньше.

- Шесть пар «слово ↔ картинка» для 1–4 классов, «слово ↔ значение» для 5 класса. Повторяющиеся картинки, значения и написания исключены. При маленьком пуле — от двух до пяти пар; меньше двух — честное пустое состояние, без неоднозначного добора эмодзи/числом букв.
- Слова выбираются по кругу с приоритетом трудных. Память круга разделена по профилю и классу. Повторный вход продолжает круг; перезагрузка не сохраняет незавершённую партию.
- Подсказка бесплатно показывает пару, не засчитывает её и не уменьшает награду. Несовпадение закрывается через секунду, третий тап блокируется. Новая партия и уход с экрана очищают таймеры.
- Завершение вызывает существующий `playGame` один раз: общие дневные лимиты наград и задания дня, без изменений SRS. Рекорды 0.100.0 остаются статистикой филворда и кроссворда; Мемори в их счётчик не включается.
- Системные шрифты, цветовые токены, местные картинки, общие звук/вибрация, 24 частицы конфетти; reduced-motion отключает переворот и конфетти. Карточки — кнопки, закрытый текст скрыт от диктора. В текстовом режиме две колонки на телефоне, четыре на планшете; длинные значения не обрезаются, сцена прокручивается.

## Адаптация дизайн-документа

Правила проекта имеют приоритет (подтверждение владельца). Не добавлены отдельные темы, возрастные уровни/замки, звёзды за ошибки, таймер игры, БУК, озвучка или музыкальные файлы. Из документа взяты рубашка, переворот, состояния найденной пары, мягкая обратная связь и доступность. Без штрафов и проигрыша.

## Проверки

В smoke добавлены движок всех пяти классов, коллизии подсказок, смена набора, запрет повторного и третьего тапа, полная победа; DOM-проверки закрытых карточек, подсказки, закрытия несовпадения, единственного начисления и новой партии. Проверка витрины обновлена для трёх игр в «Подумать».

Локально прошли: `typecheck`, `test:smoke` (включая четыре игры и третий ключ), `test:release`, `release:check` с точным заголовком, `content:check`, `test:content`, `test:adaptive`, `audit:storage` (10 сценариев без потери), `test:contrast` (16 тем / 288 пар), `build`, `test:boot`. Порядок импорта нового smoke-модуля сохранён после существующих модулей: преждевременная инициализация стора меняла детерминированную последовательность в тесте адаптивного урока. Сам тест урока и продуктовая логика не ослаблялись.

Пул Мемори не наследует ограничения длины буквенных сеток: доступны длинные слова и фразы класса. Визуальный прогон на реальных Android/iPad и проверка FPS ещё не выполнялись.
