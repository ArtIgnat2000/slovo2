# 0.118.5 — «Колесо букв»: центральная картинка-круг касается кнопок

Владелец попросил увеличить картинку в центре колеса и обрезать её кругом так,
чтобы край картинки касался буквенных кружков по касательной.

## Что изменилось

* Размер иллюстрации теперь вычисляется из геометрии круга: диаметр равен
  расстоянию между внутренними краями противоположных буквенных кнопок.
* Изображение обрезается круглой маской и заполняет её (`object-fit: cover`),
  без паспарту.
* UI-проверки фиксируют размерную формулу, круглую маску и кадрирование.

## Проверки

`npm run typecheck`, `npm run build` и целевые engine/UI-проверки «Колеса букв».
