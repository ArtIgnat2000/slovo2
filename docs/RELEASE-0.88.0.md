# 0.88.0 — цифровые обложки музыки и звуков

## Что сделано

- Новый компонент `src/ui/DigitalCover.tsx`: у 12 треков и 6 наборов звуков
  вместо эмодзи на градиенте — редакционная двусторонняя обложка.
- Лицевая сторона: номер в серии (`SLOVO–01…12`, `SIGNAL–01…06`), название,
  абстрактный спектр, посчитанный детерминированно от `id`; для полного
  размера — оригинальное название, автор, длительность и темп.
- Оборот трека: настоящие метаданные из `engine/music.ts` — оригинал, автор,
  длительность, темп, лицензия CC BY 4.0, ISRC.
- Оборот набора звуков: партитура реальных нот из `engine/sounds.ts` — сигналы
  верного ответа и ошибки, включая плавные съезды частоты (`glideTo`), и
  перечень тембров.
- Палитра не случайная: «Спокойный фон» — бирюза с янтарём, «Коллекция и
  награды» — терракота с прохладным акцентом, звуки — индиго с золотом.
- Обложки подключены на витрине, в листах товара, в «Моём мире» и в демо;
  крупный лист переключает стороны и показывает «1 / 2 → 2 / 2».
- Мультяшных сцен и поддельных фотографий цифровых товаров нет. Смена стороны
  мгновенная, `prefers-reduced-motion` отключает эквалайзер.

## Как проверено

- `npm run typecheck`
- `npm run test:smoke` (включая переключение сторон и коллекцию)
- `npm run test:adaptive`, `npm run test:contrast`
- `npm run test:galleries`
- `npm run build`
- `git diff --check`

`docs/proposals/product-galleries.md`.
