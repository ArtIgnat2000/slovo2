# СЛОВО 2.0 — 0.12.3

**Музыкальный магазин БУКа: больше звука, выбора и своего настроения.**

## Музыка для БУКа

В магазине появились 14 оригинальных коротких мелодий в разных стилях: электропоп,
лоу-фай, диско, чиптюн, тропический грув и другие. Две композиции доступны бесплатно;
остальные открываются за кристаллы. Перед покупкой трек можно послушать.

Тап по БУКу открывает музыкальную коллекцию: ребёнок выбирает уже купленную музыку
или выключает её. Выбор хранится отдельно в каждом профиле и сопровождает БУКа
в разных разделах приложения. Звук можно выключить в настройках.

Лупы синтезируются прямо в приложении средствами Web Audio — они не требуют сети,
аудиофайлов и не используют чужие песни.

## Проверки

Добавлены проверки каталога, цен, стартовой коллекции, покупки и выбора треков.
Пройдены `typecheck`, `test:adaptive`, `test:smoke` и `build`.
