# 0.86.0 — БУК живой: взгляд, моргание и навигатор-дуга

Итерация 1 ряда «БУК-компаньон» ([`docs/buk-companion-3d.md`](./buk-companion-3d.md),
§7): быстрые победы без сервера, озвучки и 3D — то, что можно сделать за один
проход и сразу проверить детьми. Порядок серии согласован с пользователем
2026-10-29: сначала живой SVG и навигатор, затем чат «Спроси БУКа» с памятью,
потом 3D-пайплайн; **голос в этой серии не делается**.

## Что изменилось

- **Живой взгляд.** Зрачки плавающего БУКа следят за пальцем/мышью, голова
  наклоняется на ±3.5°, веки моргают по CSS. Движения пишутся transform'ом
  напрямую в DOM по requestAnimationFrame — ре-рендера на каждое движение
  указателя нет (бюджеты `docs/perf-audit.md`). При `prefers-reduced-motion`
  взгляд и моргание выключаются; в магазине, церемонии и на карточках сова
  остаётся спокойной картинкой.
- **Навигатор-дуга «🧭 Куда полетим».** Новая кнопка рядом со «свернуть»
  открывает дугу из пяти дверей, направленную внутрь экрана: **📖 Урок**
  (правило героя главной — «Пора повторить» важнее нового урока),
  **🌍 Мой мир**, **🎁 Задания** (лист заданий на главной), **🎩 Наряды**,
  **🎵 Музыка** (витрина сразу на полке «Музыка»). Закрытие — Escape, тап по
  подложке и любой тап по самой сове; фокус при открытии уходит на первую
  дверь. Тап по сове без дуги остался «погладить» — контракт маскота не менялся.
- **Одна формула «что начать».** Новый движок `src/engine/next-start.ts`
  считает первый шаг дня; его же использует герой главной, поэтому кнопка
  «Начать» и дверь «📖 Урок» не разъезжаются.
