# 0.79.0 — фотореализм: корабли и базы

Продолжение 0.77–0.78: в студии уже были питомцы, спорт, вкусняшки и самолёты.
Теперь на фотореализм переведены корабли и базы.

## Что изменилось

- **Корабли — все пять.** Яхта, контейнеровоз, супертанкер, авианосец и «Титаник»
  сняты как детализированные модели на нейтральном фоне: настоящий тик палуб,
  ржавые подтёки по борту, контейнеры, самолёты на полётной палубе, четыре
  трубы у лайнера. Раньше у четырёх судов были карандашные рисунки, а
  «Титаник» — схема из SVG.
- **Базы — все пять.** Ядерная, электронная, арктическая, лунная и база
  паровозов получили фотореалистичные архитектурные рендеры: купол реактора с
  градирнями в пустыне, кампус лабораторий с солнечными панелями, станция на
  сваях среди льдов с северным сиянием, купольный городок на лунном реголите,
  кирпично-медное депо с паровозами и причалом дирижаблей.
- **Один рендер на все места.** `BuildingArt` сам отдаёт фото, если оно есть:
  витрина, карточка в «Моём мире», строка гардероба и первая точка экскурсии
  показывают одну и ту же базу — снаружи и внутри теперь одна стилистика.
- **У баз та же ниша 4:3,** что у остальных товаров: убраны старые правила,
  сжимавшие площадку базы до 132 px по высоте.

## Проверки

- `tests/cards-ui.test.tsx`: полка «Корабли» проверяется как остальные полки;
  добавлен блок баз — пять карточек, у каждой рендер из `public/products`,
  ниша помечена `shop-case-photo`.
- Список фото теперь сверяется и с `BUILDING_BY_ID`, а не только с `TOY_ITEMS`:
  опечатка в id базы больше не пройдёт незамеченной.
- Обновлены проверки смоука про корабли: у каждого судна свой снимок,
  «Титаник» снят фотографией, подробная карточка показывает крупный снимок.
- `npm run typecheck`, `npm run build`, `npm run test:smoke` — зелёные.
