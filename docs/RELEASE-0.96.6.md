# 0.96.6 — «Собери слово» помещается на Android

Замечание владельца со скриншотом телефона: «На андроиде не помещается игра.
Переделай дизайн». На фото видно главное: экран обрывался сразу после
«Другое слово →», а «🔄 Ещё раз» (и всё, что ниже) уходило под нижнее меню.

## Почему не помещалось

Экран «Игры» держит высоту окна, а сцена игры прокручивается — значит,
нехватка места проявляется не «сдвигом вниз», а обрезкой. Внутри карточки
«Собери слово» набиралось ~630 px:

| Блок | Было |
|---|---|
| лента слов | 40 px |
| подсказка: картинка 152 + пример 69 + строка «💡» 26 | **~214 px** |
| строка лунок | 62 px |
| лоток букв | 78 px |
| кнопка подсказки | 34 px |
| баннер «Слово собрано!» (добавлялся к собранной доске) | ~176 px |

Плюс шапка с сегментом (86), отступы экрана и запас под нижнее меню (76).
Итого ~830 px при доступных 650–700 px на телефоне из скриншота.

## Что изменено

1. **Подсказка стала строкой.** Картинка — иконка 64 px слева (72 на
   планшете, 56 на низком экране), справа пример и строка «💡 где мы живём ·
   Слово из 5 букв». 214 → **~64 px**. Это осознанное исключение из правила
   «картинка сверху» (`docs/word-cards-design.md`): там речь о карточках слов
   и подсказках заданий урока, где образ — главный объект. В свободной игре
   картинка — маркер слова, а главное — плитки. Правило для `.clue`/`.wcard`
   не изменилось, страж в `tests/lesson-art-ui.test.tsx` теперь явно исключает
   `.game-clue` и объясняет почему.
2. **После сборки пустой лоток убран.** Все буквы стоят в лунках, и «лоток»
   оставался серым прямоугольником с пунктирами — на скриншоте это и есть
   большое серое поле. −78 px, и именно на этом месте встаёт баннер.
   В уроке лоток остаётся: там он часть задания.
3. **Баннер — одна плотная карточка** (`.tileboard-banner-compact`): заголовок
   18 px, служебная строка 11,5 px, кнопки 44 px — 176 → **~124 px**. Кнопки
   «Другое слово →» и «🔄 Ещё раз» остаются на месте и без прокрутки.
4. **Плотность плиток:** потолок 62 → **56 px** (цель пальца Material — 48 dp,
   запас есть), зазор сетки 6 px. Плитка по-прежнему выводится из ширины
   карточки, так что длинные слова не ломают раскладку.

Итог по прикидке: 630 → **~400 px** внутри карточки, весь экран ~570 px —
влезает и на 640-пиксельных Android, и в ландшафте (там уже есть медиазапросы
`max-height: 700/560`).

## Проверки

`npm run typecheck`, `npm run test:smoke`, `npm run build`, `npm run test:boot`,
`npm run test:contrast`, `npm run release:check`.

Новые проверки в `tests/games-ui.test.tsx`:
- подсказка собрана строкой «иконка + текст», пример и объём слова на месте;
- после сборки пустого лотка нет — баннер занимает его место;
- пояснение «Оранжевым — та буква, которая тут хитрит» осталось;
- страж `lesson-art-ui` больше не срабатывает на `.game-clue`, но по-прежнему
  запрещает строку для `.clue*`/`.wcard*` урока.
