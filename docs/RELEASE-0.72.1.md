# 0.72.1 — Новые 3D-картинки новинок 0.72.0

По просьбе «перегенерируй картинки и замени их новыми с хорошим качеством и 3D-эффектом» (объём уточнён: только новинки прошлого релиза).

## Что изменено

- **Машины 0.72.0 — новые глянцевые 3D-рендеры** вместо перекрашенных старых рисунков: «Розовая машина», «Розовая звезда» (со звездой на капоте) и «Тесла» (синий электроседан). Белый фон генераций убран заливкой от краёв, мягкая тень под машиной сохранена полупрозрачной; у бликов внутри кузова прозрачность не пробивается. Формат прежний: 720×480 RGBA WebP на прозрачном фоне.
- **Линейка iPhone 18 — собственные спинки.** В 0.72.0 модели 18-й линейки переиспользовали рисунки старых телефонов; теперь у каждой своя сгенерированная 3D-спинка: iPhone 18 (голубой, две камеры), 18 Air (серебристый, одна камера), 18 Pro (титан с оранжевым кольцом камер — сгенерирована сразу вертикально), 18 Pro Max (глубокий синий, три камеры). Силуэты выровнены вертикально и вписаны, как существующие спинки: 400×800 в квадрате 960×960 с прозрачным фоном (маска перекраски продолжает работать).
- Палитры, названия, цены и порядок полок не меняются — заменены только картинки (`public/cars/*.webp`, `public/electronics/phone-18-*.webp`) и четыре строки в `ELECTRONICS_ART`.

## Проверки

- `npm run typecheck`, `npm run test:adaptive`, `npm run test:smoke` (18 машин, 11 телефонов, уникальность рисунков) — зелёные.
- `npm run test:release`, `npm run release:check` (0.72.0 → 0.72.1), `npm run build`, `npm run test:boot` — зелёные.
