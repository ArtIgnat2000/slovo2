# Релиз 0.24.0 — полки без общего текста + сдача товаров обратно (трейд-ин)

## Запрос

Пользователь: (1) «в разделах магазина убери общий текст, например
"Цветные карандашные рисунки настоящих машин…"»; (2) «проанализируй
возможность сдачи обратно купленных товаров по сниженной стоимости —
как трейд-ин или просто сдать купленный товар со скидкой 20–50%.
Это часть финансовой грамотности».

## Что изменилось

* **Общие подписи полок убраны.** Поле `note` удалено из `TOY_SHELVES`
  (авто / корабли / телефоны) в `engine/shop.ts` и из `MUSIC_SHELVES`
  (спокойный фон / коллекция) в `ShopScreen.tsx` — вместе с отрисовкой
  в магазине и демо-макете и мёртвыми CSS-правилами
  (`.shop-case-group-title + .tiny`, `.music-shelf-note`). Раздел
  начинается сразу с заголовка и товара. Полезные подсказки (как копить,
  что происходит после покупки, лицензии музыки) остались.
* **Сдача купленной вещи обратно (sell-back, «трейд-ин»).** Анализ —
  [`docs/proposals/trade-in.md`](./proposals/trade-in.md), вариант B
  принят пользователем 2026-10-20:
  * `engine/shop.ts`: ставки `SELL_RATE` (наряды 50%, техника 30% —
    гаджеты дешевеют быстрее, как в реальности) и чистая функция
    `sellPrice(item)`. Цена сдачи строго меньше цены покупки, поэтому
    цикл «купил → сдал» всегда теряет часть кристаллов: фарм невозможен
    по построению.
  * `state/store.ts`: экшен `sellItem(id)` — вещь уходит из гардероба
    навсегда, снимается с совы и с подиума ангара, её открытые краски
    обнуляются (допы не повышают цену сдачи), часть цены возвращается
    кристаллами. Сдать можно только купленное, один раз.
  * Магазин: в sheet купленной вещи — «Сдать обратно · +N 💎» с
    подтверждением (`ConfirmDialog`, как покупка); в sheet некупленной —
    строка «Если передумаешь — вернём N 💎 (50%)», чтобы цена ошибки
    была видна до покупки. Тост с вернувшейся суммой.
  * Макет `ShopDemo` синхронизирован.
  * **Не сдаются** музыка и звуки (цифровые товары не возвращают —
    тоже урок), костюмы-пазлы (не покупаются) и краски (обнуляются
    вместе с вещью). Старые профили не меняются — миграция не нужна.
