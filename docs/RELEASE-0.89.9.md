# 0.89.9 — картинка по названию, первой стороной, и костюм в плитке набора

Три правки к 0.89.8: все пришли с витрины и все — «сделано, но не то».

## 1. Иллюстрация музыки теперь про конкретную мелодию

**Что было не так.** Третья сторона обложки рисовала всем двенадцати трекам один
и тот же пейзаж: небо, солнце, холмы, воду. Красиво, но «Лимончик» без лимона и
«Утёнок» без утёнка ничего не объясняют — картинка не связана с названием.

**Что сделано.** У каждой мелодии свой предмет на переднем плане, в том же
плоском языке, что и пейзаж (`MUSIC_MOTIFS` и `TrackMotif` в
`src/ui/DigitalCover.tsx`):

| трек | предмет |
|---|---|
| Беззаботный день | воздушный змей с хвостом из бантиков |
| Счастливые деньки | радуга над холмом |
| Лимончик | два лимона и половинка с дольками |
| Тёплый дом | домик: крыша, светящиеся окна, труба с дымком |
| Тихий ритм | рулон обоев в ромбик |
| Весёлый жук | жук: панцирь в точку, голова, усики, лапки |
| Обезьянки | две обезьянки с круглыми ушами |
| Шаг на цыпочках | следы, поднимающиеся по склону |
| Утёнок | утёнок: клюв, крылышко, лапки |
| Весёлый переулок | два дома по сторонам и фонарь между ними |
| Добрый понедельник | календарь с отмеченной клеткой |
| Пикселяндия | пиксельный замок из блоков |

Небо, холмы, вода и время суток остались общими: серия должна читаться одной
рукой, а различать мелодии теперь можно по предмету, а не только по оттенку.
Знак-медальон с нотой убран — он стоял на месте, куда теперь встаёт предмет.

## 2. Картинка стала первой стороной

**Просьба.** «В карточке Музыки картинка должна быть основной и показываться
первой: именно по картинке дети будут ориентироваться при выборе музыки».

**Что сделано.** Порядок сторон у трека теперь `картинка → лицевая сторона →
оборот` со счётчиком «1 / 3 … 3 / 3». В карточке полки, в плитке коллекции и в
мелких превью показывается именно картинка; типографика с номером в серии и
спектром осталась второй стороной крупного листа, метаданные — третьей. У
набора звуков порядок прежний: его «картинка» — партитура на обороте.

Кадр иллюстрации смещён к низу (`preserveAspectRatio="xMidYMax"`): в широкой
карточке срезается небо, а не земля с предметом, поэтому змей, утёнок или
календарь остаются в кадре при любой пропорции плитки.

## 3. Костюм в составе набора перестал быть пустым

**Что было не так.** Плитка костюма в «упаковочном листе» набора выглядела
пустой. Причина: БУК — плавающий виджет, у `.mascot` базовое правило
`position: fixed`, и в лист товара он улетал в угол экрана. В карточках магазина
это уже лечили сбросом позиции, а в новом компоненте сброса не было.

**Что сделано.** В плитке `position`, `inset`, `z-index` и анимация сняты
(`.set-part-art .mascot` в `app.css`), сова встала внутрь плитки и показывает
именно тот костюм, который входит в набор.
