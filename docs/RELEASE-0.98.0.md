# 0.98.0 — «Чувство победы»: игры заканчиваются событием

Первый игровой релиз по плану [`proposals/games-development.md`](./proposals/games-development.md)
§11, согласованному с владельцем 2026-11-12. Меняется только финал свободных
игр — правила наград, движки сеток, контент и хранилище не тронуты.

## Что было не так

Победа в «Филворде» и «Кроссворде» была **статичной зелёной плашкой**:

* `sfx.finish()` и `haptic.finish()` — те самые фанфары, которыми
  заканчивается урок, — не вызывались ни в одной игре;
* компонент `Confetti` в проекте **уже был** (`ui/Bits.tsx`), но игры его
  не показывали;
* в кроссворде звучал только `sfx.tap()` на букву: момент «слово сошлось»
  проходил в полной тишине, хотя он здесь главный;
* `gameAwardHint()` — честная строка «на сегодня кристаллов и опыта из игр
  хватит» — была написана ещё в 0.96.7 и **не выводилась нигде**, кроме
  тестов. Ребёнок видел «+1 💎 +2 ⚡» и не понимал, почему дальше не капает.

Итог: самая частая и самая дешёвая доработка раздела давала больше, чем
пятая механика. Поэтому она идёт первой.

## Что сделано

### «Филворд» (`ui/WordSearchGame.tsx`)

* на последнем найденном слове — `sfx.finish(3)` + `haptic.finish()`
  (ровно те же фанфары и вибрация, что на результатах урока);
* один раз на сетку — `Confetti` (24 частицы, компонент из `ui/Bits.tsx`),
  гаснет через 2,6 с; при `prefers-reduced-motion` не показывается вовсе;
* плашка победы получила класс `.ws-win-party` — один короткий «подпрыг»
  (`@keyframes game-win-pop`), при «меньше движения» остаётся статичной;
* под наградой — строка из `gameAwardHint()`: «За игру сегодня: +2 ⚡» или
  «На сегодня кристаллов и опыта из игр хватит — приходи завтра».

### «Кроссворд» (`ui/CrosswordGame.tsx`)

* **звук на собранное слово:** `sfx.correct()` из выбранного набора «Звуков»
  и `haptic.correct()` звучат только на **новых** верных словах — считаем
  переходы статусов слотов, иначе при каждом тапе по клетке играл бы весь
  уже собранный кроссворд;
* тот же финал сетки, что в филворде: `sfx.finish(3)`, вибрация, конфетти,
  праздничная плашка и честная строка о наградах.

### Стили (`styles/app.css`)

* `.ws-win-hint` — мелкая строка честной подписи;
* `.ws-win-party` + `@keyframes game-win-pop` — один жест на победу,
  с `@media (prefers-reduced-motion: reduce) { animation: none }`;
* новых цветов нет: только существующие токены (`--green-soft`, `--ink-2`),
  поэтому 16 тем и `test:contrast` не затронуты.

## Тесты

* `tests/games-ui.test.tsx` — четыре новые проверки: праздничная плашка и
  честная подпись в финале филворда и кроссворда;
* остальные 370+ проверок смоука прошли без изменений: награды
  (`tests/game-awards.test.ts`) не тронуты.

## Что НЕ меняется

- **Награды:** `GAME_XP_FIRST = 2`, `GAME_XP_NEXT = 1`, потолок
  `GAME_XP_CAP = 6`, `GAME_DAY_GEMS = 1`, вес 0.5 в заданиях дня — ни строки.
- **SRS:** игра по-прежнему не меняет расписание повторений.
- **Движки** `word-search.ts`, `crossword.ts`, курсор круга
  (`slovo2-game-cursor`) и пулы слов — без изменений.
- **Контент, профиль, хранилище:** нет новых полей, миграций и сетевых
  запросов; `audit:storage` зелёный.
- **Доступ к играм** (§8 плана) — не в этом релизе: он идёт следующим,
  0.99.0, вместе с двумя группами навигации.
