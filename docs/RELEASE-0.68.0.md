# 0.68.0 — «вау-алмаз»: свечение, объём и мерцающие искры

Отклик: **«детям не зашёл внешний вид алмаза, не впечатлил — видимо, они видят
лучше в мультиках. Требуется сделать вау-алмаз»**.

## Что показали варианты

Собрал четыре картинки в реальных размерах приложения (18 / 22 / 26 / 40 px,
светлый и тёмный фон) — `docs/proposals/ui-icons/crystal-wow.html`
и картинка `crystal-wow-options.png`. Варианты:

* **A — гранёный**: пять граней с разным тоном, блик, одна звезда;
* **B — сияние**: мягкий ореол вокруг камня, градиент по всему камню,
  зеркальный блик и **две мерцающие искры**;
* **C — мультяшный ледяной**: толстый синий контур и скруглённый низ;
* для сравнения — текущий (0.56.0).

Выбран **B («сияние»)**.

## Что изменилось в кристалле

| Было (0.56.0) | Стало (0.68.0) |
|---|---|
| плоские грани одним тоном | **градиент по камню** (`#f6feff → #8fe0fb → #1167a6`) — камень «объёмный» |
| ничего вокруг | **мягкий ореол** (`radialGradient`) — камень будто светится, особенно в тёмной теме |
| один короткий штрих-блик | **зеркальный блик** по левому скату + светлая площадка сверху |
| без искр | **две искры**: большая золотая и маленькая белая, обе мерцают |

Мерцание — `@keyframes icSpark` в `app.css`, с задержкой у второй искры;
при `prefers-reduced-motion: reduce` анимация **полностью выключается**.

## Как это сделано технически

* в `Icon.tsx` появился `DEFS`: градиенты описываются отдельно от путей,
  пути ссылаются на них как `url(#{uid}-body)`;
* `{uid}` подставляется **на каждый экземпляр свой** — через `useId()`.
  Это важно: на главной, в шапке и в ценах одновременно живут 4–6 кристаллов,
  и общий id заставил бы браузер искать «первый подходящий» градиент, а после
  удаления любого из них ссылки стали бы битыми;
* у `Part` появились `o` (прозрачность заливки — для бликов) и `c` (класс —
  для мерцания): набор остаётся данными, а не разметкой;
* 11 мест в `docs/proposals/ui-icons/preview.html` перерисованы новым
  кристаллом (у каждого свой uid), заголовок — 0.68.0.

## Проверки

`npm run test:icons` — 28 проверок, из них **7 новых**:

* есть и свечение (`radialGradient`), и объём (`linearGradient`);
* камень залит **градиентом**, а не плоским цветом;
* мерцают ровно **две** искры (класс `ic-spark`);
* блик — полупрозрачная белая грань;
* у трёх кристаллов на одной странице **шесть разных** id градиентов;
* все ссылки `url(#…)` ведут в свой же `svg` (нет битых);
* мерцание задано в `app.css` и выключается при `prefers-reduced-motion`.

Старые стражи тоже зелёные: кристалл занимает почти всю сетку, контур не
чёрный и тоньше 1,6, набор ≤ 32 КБ, палитра ≤ 48 цветов.

Контур целиком: `typecheck`, `test:contrast`, `test:smoke` (864), `test:guard`,
`test:icons`, `test:content`, `test:adaptive`, `audit:storage`, `demo:check`,
`content:check`, `images:report -- --strict`, `release:check`, `build`,
`test:boot`, `test:release`.
