# 0.76.0 — экскурсии внутри баз и база паровозов

**Просьба:** «Для товаров типа база нужно 5–7 доп. картинок. В стиле ультрареализма.
Картинки появляются по тапу и закольцованы. Должны увлекать детей и быть
познавательными — на них должны быть интерьеры баз. Ещё нужна новая база
паровозов, стимпанк, ультрареализм».

## Что изменилось

- **У каждой базы — экскурсия из пяти комнат.** Фасад остаётся первым кадром,
  дальше по тапу открываются интерьеры: реакторный зал, оранжерея, серверная,
  лаборатория льда, депо паровозов и так далее. После последней комнаты кольцо
  возвращается к фасаду — листать можно бесконечно, «конец» не наступает.
- **Каждая комната — карточка «факт + найди».** `fact` объясняет одно настоящее
  явление одной фразой, понятной младшему школьнику (атом греет воду → пар
  крутит турбину; микросхема похожа на город; на Луне тяжесть в шесть раз
  меньше). `find` просит отыскать деталь на картинке — из-за этого интерьер
  разглядывают, а не пролистывают.
- **Вход в экскурсию — из двух мест:** подробная карточка базы в магазине и
  крупная карточка базы в «Моём мире». Точки под картинкой прыгают в любую
  комнату сразу (на телефоне это быстрее, чем листать).
- **Новая база — «База паровозов» (стимпанк, ультрареализм):** медные котлы,
  шестерёнки, депо с поворотным кругом и причал дирижаблей. К ней — паровоз
  «Огнедышащий», биплан «Паролёт», костюм «Машинист пара» и набор «Пар».
  У паровоза своя экскурсия по кабине в карточке техники (CarTour).
- **Все 25 интерьеров нарисованы** (5 комнат × 5 баз) и сложены в WebP
  1000×667, ~100–160 КБ каждый.
- **Картинки интерьеров — вне precache PWA.** 25 фотореалистичных кадров
  (~100 КБ каждый) кладутся в кэш `slovo2-base-tours` при первом просмотре,
  как плитки школы НААШ: офлайн-набор ребёнка не раздувается, а после первого
  визита комнаты открываются без сети.
- **Битая картинка не ломает кольцо:** если кадр не догрузился, на его месте
  появляется табличка комнаты «Комната ещё строится — загляни позже».

## Где что лежит

| Что | Файл |
|---|---|
| Данные экскурсий (факты, задания) | `src/engine/base-tours.ts` |
| Компонент «фасад → комнаты по кругу» | `src/ui/BaseTour.tsx` |
| Стили и анимация кадра | `src/styles/app.css`, блок «Экскурсия по базе» |
| Картинки комнат | `public/base-tours/<baseId>-<1..5>.webp` |
| Сборка картинок из исходников | `scripts/process-base-tours.mjs` |
| Кэш интерьеров в PWA | `vite.config.ts`, `slovo2-base-tours` |
| Новая база, техника, костюм, набор | `src/engine/buildings.ts`, `shop.ts`, `puzzles.ts`, `tints.ts`, `base-sets.ts` |
| Проверки данных и файлов | `tests/base-tours.test.ts` |

## Проверки

- `npm run typecheck`, `npm run build`
- `npm run test:adaptive` (в нём же `tests/base-tours.test.ts`: 5 комнат у каждой
  базы, факт и «найди» в каждой, файл под каждую комнату)
- `npm run test:smoke` (полка «Авто» — 19 машин, у паровоза свой рисунок)
- `npm run test:release`, `npm run release:check`

## Попутные починки смоука

Три проверки падали ещё до этой ветки (проверено на `main` через стэш) — теперь
зелёные:

1. `pricesAscending` считал прогресс костюма («0/9 🧩») ценой 0, поэтому полка
   «Наряды» всегда выглядела неотсортированной;
2. проверка вкладок «Техники» ждала «Питомцев», «Спорт» и «Вкусняшки» внутри
   ряда вкладок — они давно живут отдельными полками витрины;
3. блок пазлов кликал по чипу «Костюмы», которого в витрине нет: костюмы стоят
   на полке «Наряды» (добавлен помощник `openCostumeShelf()`).
