# 0.58.1 — «Контрольную» стало видно: вход в списки и диагностика

Отклик после 0.58.0: **«не нашёл в уроках Контрольную»**.

## Что проверил

Воспроизвёл весь путь на чистом профиле (создал профиль → создал список →
вернулся на «Уроки»):

```
карточек на главной ДО списка: 0
создано: { ok: true, bank: 2, custom: 2, words: 4 }
карточек на главной ПОСЛЕ: 1
текст карточки: 🏫 Контрольная 12.11 · 4 слов · Тренировать
после перезагрузки: 1
```

Механика работает: карточка появляется и переживает перезагрузку. Значит
дело не в поломке, а в **находимости**: пока списка нет, на «Уроках» ничего
не показывается (так и было задумано — «лишних обещаний на главной»), а
входа в «Списки» из «Обзора» не было. Родитель шёл в уроки и не находил
там «Контрольную», потому что её сначала надо создать.

## Что исправлено

### 1. Вход в списки виден из «Обзора»

Первой карточкой в «Родителям → Обзор» теперь:

> **Списки к контрольной**
> Слова, которые задали в школе: вставляете текст — ребёнок тренирует именно их.
> *Пока нет ни одного списка — поэтому на «Уроках» карточки «Контрольная» нет.*
> **[ + Добавить список к контрольной ]**

Когда списки есть — карточка показывает «Списков: 2 · 46 слов всего» и кнопку
«Открыть списки». Пустое состояние больше не молчит.

### 2. Ряд вкладок в «Родителям» не сжимается

С 0.58.0 вкладок стало пять (Обзор, Списки, Прогресс, Настройки,
Приложение). На узком экране они ужимались в один ряд: «Приложение»
ломалось на три строки, «Списки» терялся среди них. Теперь на экранах
до 560 px — **две строки по три вкладки**, все подписи целиком.

### 3. Диагностика отвечает на вопрос «почему нет карточки»

`?diag=1` → «Скопировать сводку» теперь содержит строку:

```
Списки к контрольной: нет (карточка на «Уроках» не показывается)
```

или

```
Списки к контрольной: 1 · своих слов: 3
  «Контрольная 12 ноября»: слов 26, тренировали 24.10.2026
```

Имя ребёнка в сводку **не попадает** — её копируют и пересылают; это
поймал существующий тест приватности, и строка была переписана.

## Как добавить список (если ещё не создан)

1. **Родителям** (нижнее меню) → решить пример-замок;
2. вкладка **🏫 Списки** (или карточка в «Обзоре» → «+ Добавить список»);
3. название → вставить слова из чата → **«Проверить список»**;
4. проверить ударения у своих слов (тап по слогу) → **«Сохранить список»**;
5. **Уроки** → над «Заданиями дня» появится «🏫 Контрольная · N слов».

## Проверки

Четыре новых проверки в смоуке (всего по спискам — **39**):

* вход «Списки к контрольной» есть в «Обзоре» и ведёт во вкладку списков;
* «Обзор» честно объясняет пустое состояние;
* диагностика показывает число списков **и не содержит имени ребёнка**;
* в CSS есть правило для пяти вкладок на узком экране.

Полный контур: `typecheck`, `test:smoke`, `test:guard`, `test:icons`,
`test:content`, `test:adaptive`, `audit:storage`, `content:check`,
`images:report -- --strict`, `release:check` (0.58.0 → 0.58.1), `build`,
`test:boot` — зелёные.

## Если карточки всё равно нет

Откройте `?diag=1` и пришлите две строки: версию (`СЛОВО 2.0 · v…`) и
строку «Списки к контрольной: …». Если там «нет» — список не сохранился
(например, создавали на другом профиле); если «1 · своих слов: 3», а
карточки нет — это уже ошибка отображения, и по строке будет видно, что
чинить.
