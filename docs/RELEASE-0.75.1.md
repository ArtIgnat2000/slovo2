# 0.75.1 — компактный словарик и интерактивное кольцо

## Что изменилось

- Убрана лента тем уроков в верхней части словарика: слова сразу показаны по всему выбранному классу.
- Выбор класса перенесён в компактный раскрывающийся список рядом с заголовком. Смена класса в словарике не меняет учебную программу профиля.
- Кольцевая диаграмма показывает количество слов в группе при наведении или фокусе; нажатие на сектор оставляет слова этой группы, повторное возвращает все группы. Легенда синхронизирована с диаграммой, для клавиатуры доступны Enter и пробел.
- Обновлены UI-проверки словарика.

## Проверки

- `npm run typecheck`, `npm run build`, `npm run test:smoke`
- `npm run test:release`, `PR_TITLE='v0.75.1 — компактный словарик и интерактивная диаграмма' npm run release:check -- origin/main`
