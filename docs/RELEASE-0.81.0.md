# 0.81.0 — фотореализм: вторая десятка авто, ноутбук и кроп без обрезки

Продолжение 0.80.0 (она в этом же PR). Теперь на студийные снимки переведены
ещё шесть машин, а раздел электроники открыт первым кадром.

## Что изменилось

- **Ещё шесть машин снято в студии.** Тесла с поднятой задней дверью, розовый
  кабриолет с кремовым салоном, «Квант» с голубым энергоядром в решётке,
  «Импульс» со светящимися дорожками схем, «Полярник» на двух широких
  гусеницах с мачтой датчиков и «Огнедышащий» — медный паровоз с настоящим
  паром из трубы. Всего снимков в магазине 54.
- **Электроника пошла.** Первым снят «Невесомый Air» — тонкий алюминиевый
  ноутбук на глянцевом полу. Фото в `ToyArt` стоит раньше 3D-арта, поэтому
  снимок сам вытесняет прежнюю иллюстрацию и в витрине, и в подробной
  карточке, и в гардеробе.
- **Телефон с фотографией не притворяется поворотным.** `isRotatingPhone`
  теперь возвращает `false`, если у модели есть снимок: кадр один, крутить
  нечего — и подсказка «нажми, он повернётся» больше не врёт.

## Исправлено

- **Кроп фото товаров.** Сборщик резал любой широкий кадр (1408×768) до 4:3
  по центру, то есть терял по 14 % ширины с каждой стороны. У машин корпус
  идёт почти во всю ширину кадра, и в витрине срезало то передний бампер, то
  корму — ровно та жалоба, с которой всё началось. Теперь кроп — не правило,
  а исключение: он применяется только к снимкам из списка `CROP`, где предмет
  заведомо компактнее окна (`car-arctic-base`, `laptop-air`). Все остальные
  кадры вписываются целиком на продолженный студийный задник, поэтому новый
  снимок не может потерять бампер по недосмотру.
- Побочный плюс: пересобранные кадры первой десятки тоже перестали обрезаться.

## Проверки

- `tests/electronics-art.test.tsx`: для моделей со снимком проверяется
  `img.product-photo` и `products/<id>.webp`, а 3D-арт остаётся запасным
  вариантом в `public/electronics`; для остальных — прежние проверки арта.
  Отдельно проверяется, что телефон с фотографией не вращается.
- `tests/smoke.test.tsx`: полка электроники считается как «арт + фото = 11»,
  чтобы каждая новая фотография не ломала чек.
- `npm run typecheck`, `npm run build`, `npm run test:smoke`, `test:boot`,
  `test:guard`, `test:contrast` — зелёные.
