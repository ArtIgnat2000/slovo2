# Релиз 0.15.1 — сервисный: package-lock.json синхронизирован с версией

**Статус (2026-10-18):** исправление процесса, функциональность не менялась.

## Что произошло

В 0.15.0 версию подняли в `package.json`, но `package-lock.json`
(поля `version` и `packages[""].version`) остался на `0.14.5`.
Гейт CI «Release checks» → `npm run release:check` это ловит
(«Версии package.json и package-lock.json должны совпадать») —
проверка на PR #57 упала именно на этом шаге; сам мерж и деплой
прошли, сборка от рассинхрона не ломается.

## Состав

* `package-lock.json`: `0.14.5` → `0.15.1` (оба поля);
  зависимости не менялись, diff — только версия
* `package.json`: `0.15.0` → `0.15.1`

## Урок

Bump версии — через `npm version <версия> --no-git-tag-version`
(или ручную правку lock), а не только `package.json`; перед мержом
прогонять `npm run release:check` локально.
