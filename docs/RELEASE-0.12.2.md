Разбор, круглый стол и отвергнутые варианты — в

## 1. Первый экран — только учёба

На вкладке «Уроки» остаются:

* шапка: аватар, имя, серия 🔥, кристаллы 💎 и **🎁**;
* герой **«Сегодня»** с одной кнопкой **«Начать ▶»** — текущий урок пути либо
  «Пора повторить», если у слов истёк срок SRS;
* **Мой путь**: все 16 тем на месте, громкая только текущая.

С дома сняты (из продукта не удалялись): кольцо цели дня, задания, сундук,
неделя, повтор-дубль, достижения и карточка V-labs. Цель дня по-прежнему на
результатах урока; достижения и V-labs — в «Родителям».

## 2. Награды — лист по 🎁

Иконка 🎁 в шапке открывает нижний лист, аналог вкладки Quests у Duolingo
без пятой нижней вкладки:

* три задания дня (тап по строке запускает урок или повторение, «Забрать» на месте);
* сундук БУКа, «разбуди», одна ссылка «Облик:»;
* награды недели (полоса и отметки 3/5/7; суммы 💎 не менялись и не утверждались).

Если есть что забрать или сундук готов — на 🎁 оранжевая точка.

## 3. Движок не трогали

SRS, квесты, сундук, «разбуди», облики, короны и недельные пороги работают
как раньше. Изменилась только упаковка на доме.

## 4. Проверки

Смоук, boot, typecheck, content и adaptive — зелёные. Тесты главной открывают
лист наград там, где раньше искали задания на самом экране.

Живая проверка: `npm run preview:build && npm run preview:show` — на первом
экране телефона видна кнопка «Начать» без прокрутки, 🎁 справа в шапке.
