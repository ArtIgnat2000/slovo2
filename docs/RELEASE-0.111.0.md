# 0.111.0 — «Тропа слов»: 16 остановок, «Найти» и альбом

«Тропа слов» выходит из прототипа: 2 класс проходит всю программу — 16
остановок по четыре слова, 64 слова. В цикле остановки теперь четыре действия:
**починить** опасную букву, **пройти** слово по плитам, **найти** картинку и
**собрать** слоги. Буквёнок стал SVG-героем с тремя состояниями, а открытки
переехали в отдельный альбом-карту. 1/3/4 классы остаются превью из двух
остановок, 5 класс скрыт до текстового режима.

Версия включает и запланированные правки 0.110.1: прогресс привязан к классу,
а у 5 класса тропа не показывается, пока у слов нет картинок.

## 1. Шестнадцать остановок 2 класса

`trailStopsFor(2)` собирает остановки из всех 16 уроков программы в порядке
уроков: «Школа», «В школе», «Птицы», «Звери», «Еда», «Сад и ягоды», «Город»,
«Наша страна», «Дом и вещи», «Труд», «Зима», «Природа», «Календарь»,
«Вежливые слова», «Люди», «Как и когда».

В каждой остановке ровно четыре слова и ровно четыре разных действия:

| Место | Действие | Что делает ребёнок |
|---|---|---|
| 1 | `letters` | чинит одну опасную букву, потом ведёт героя |
| 2 | `walk` | проходит уже целое слово по плитам |
| 3 | `find` | находит картинку к слову, потом ведёт героя |
| 4 | `syllables` | собирает мост из слогов |

Слова не выдуманы: только `LESSONS_BY_GRADE[2]`, фильтр `trailFits` — без
пробелов и дефисов, 3–17 букв, есть `danger` или 2+ слога. Все 64 слова имеют
картинку — «Найти» не превращается в угадайку по эмодзи.

Прежние две остановки «Школа» и «Птицы» остались в `trailStops(2)` как
короткий маршрут для проверок и будущих превью; игра 2 класса идёт по всем 16.

## 2. «Найти»: четыре картинки, ошибка не отнимает

Третье слово остановки показывает слово-дорогу и четыре картинки. Верная —
среди них; три соседа берутся сначала из той же темы, потом из класса. Все
варианты — одиночные слова с картинкой: никаких фраз, дефисов и пустых рамок.

* неверная карточка приглушается и больше не нажимается, но прогресс не
  теряется и попытки не кончаются;
* первая ошибка открывает предложение с пропуском, вторая — подсвечивает
  верную картинку;
* после верной карточки дорога открывается, и герой идёт по слову.

Награда та же, что была: открытка за остановку и малый XP через
`playGame(1, { gems: false })`. Кристаллов тропа не печатает и не забирает
«первую сетку дня» у других игр.

## 3. Альбом-карта

Кнопка «🎴 0/16» в шапке открывает альбом. Это одновременно коллекция и карта:

* закрытая остановка показывает картинку первого слова, само слово, подсказку
  и опасную букву;
* незакрытая — эмодзи остановки и «Сейчас на тропе» или «Впереди»;
* карточек ровно 16, по две в ряд; на 360 px сетка остаётся двухколоночной;
* альбом ничего не покупает и не обменивает: источник — уже сохранённые
  `profile.trail.words` и `cards`.

## 4. Буквёнок

Эмодзи-плейсхолдер 🚶 заменён инлайн-SVG. Три состояния:

* `idle` — стоит на старте, пока слово чинится или ищется картинка;
* `walk` — шагает по плитам: ноги и руки двигаются, плита не дёргается;
* `cheer` — радуется на «Слово пройдено» и открытке, над головой звезда.

Герой наследует токены темы (`--green`, `--orange`, `--ink`, `--card`), не
тянет сеть и не требует новых цветов. В `prefers-reduced-motion` анимации
выключаются, позы остаются читаемыми.

## 5. Класс-владелец прогресса и 5 класс

`profile.trail` поднят до `v: 2` и получил `grade`:

* прогресс 2 класса не продолжается в 3-м: при чтении чужой книги
  `normalizeTrail(raw, grade)` отдаёт чистый лист, а профиль не меняется до
  первого пройденного слова — переход туда-обратно без игры возвращает прежнюю
  книгу;
* старый `v: 1` без класса считается прогрессом 2 класса: у второклассников
  уже пройденное не теряется;
* слова фильтруются по классу и карточкам текущих остановок; мусор, повторы и
  отрицательный `stop` отбрасываются, как раньше.

Почему 5 класс скрыт: в его первых двух остановках картинка есть только у 2
слов из 15. «Найти» там стало бы выбором эмодзи, а не узнаванием слова. Баннер
не показывается, а прямой вход объясняет, что тропа сейчас для 1–4 классов.
1/3/4 классы получают по две остановки-превью: игра на них ещё не проверялась.

## 6. Проверки

* `npm run test:content` — движок: 16 остановок, цикл действий, четыре
  картинки, санитайзер, сброс чужого класса.
* `npm run test:smoke` — живой сценарий: баннер «0 из 16», дорога, «Найти»,
  слоги, открытка «Школы», альбом на 16 карточек, переход во «В школе»,
  возврат на то же слово, отсутствие баннера у 5 класса и сброс книги 2 класса
  в 3-м.
* `npm run test:content` включает CSS-стражи: 44 px у плиты и кнопки альбома,
  карточка поиска не меньше 96 px, альбом 2×N, reduced motion, без `url(`.
* `npm run test:contrast` — 16 тем, 288 пар, все не ниже AA.
* `npm run test:guard`, `npm run test:adaptive`, `npm run content:check`,
  `npm run test:icons`, `npm run test:boot` — зелёные.
* `npm run build` — сборка и precache проходят.

## 7. Метрики на проверке с детьми

Аналитики нет, поэтому смотрим локально и глазами:

* `trailWordsPerSession` — 4–6 слов; меньше 3 — цикл скучный;
* `trailReturnNextDay` — вернулся ли на следующий день (цель ≥ 40 %);
* `trailHintRate` — 20–40 % слов с подсказкой; выше — слово слишком трудное;
* `trailStopComplete` — ≥ 70 % начатых остановок доведены до конца;
* главный качественный: просит ли ребёнок «ещё одну остановку?».

Если игра начнёт вытеснять уроки, меняем награду, а не наказываем: тропа даёт
открытки и маленький XP, но не должна закрывать задания дня выгоднее урока.
