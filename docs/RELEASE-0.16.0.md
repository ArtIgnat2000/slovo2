# Релиз 0.16.0 — пять оформлений приложения в полке «Фоны»

**Статус (2026-10-18):** минорный релиз с новой возможностью оформления. Цветовая схема и стиль приложения остаются независимыми настройками.

## Состав релиза

1. **Полка «Фоны» активна в магазине.** В ней можно выбрать один из пяти бесплатных стилей: классический, неоновую аркаду, космос, лесную сказку или океан. Для каждого показано превью светлого и тёмного варианта.
2. **Стиль не подменяет цветовую схему.** Выбранный дизайн работает с `auto`, `light` и `dark`; смена оформления не меняет настройку светлой/тёмной схемы.
3. **Выбор сохраняется и применяется при запуске.** Стиль хранится в настройках, а зеркало в `localStorage` позволяет оформить первый кадр до загрузки IndexedDB. Цвет системной панели следует выбранному стилю.
4. **Настройки стали понятнее.** В родительском разделе остаётся выбор цветовой схемы, а выбор оформления находится в «Магазин → Витрина → Фоны». Обновлены диагностика и живой макет магазина.
5. **Новые палитры доступны и в тёмном режиме.** Добавлены цветовые токены, фоновые мотивы и контрастный текст на ярких кнопках.

Цены не задавались, поэтому все пять стилей пока бесплатны; кристаллы за выбор не списываются. Раздел «Звуки» остаётся помечен как «скоро».

## Проверки

`npm run test:release`, `npm run release:check`, `npm run typecheck`, `npm run test:adaptive`, `npm run test:smoke`, `npm run build`, `npm run test:boot`, `npm run content:check`, `npm run audit:storage`, `npm run demo:check`, `npm run audio:check`.

## Основные файлы

* `src/engine/theme-styles.ts` — каталог стилей и палитры превью.
* `src/ui/BackgroundThemeCard.tsx`, `src/ui/screens/ShopScreen.tsx` — карточки и активная полка «Фоны».
* `src/platform/theme.ts`, `src/state/store.ts`, `index.html` — сохранение, раннее применение и системная панель.
* `src/styles/tokens.css`, `src/styles/app.css` — цветовые палитры и фоновые мотивы.
* `src/ui/parent/SettingsTab.tsx`, `src/ui/DiagnosticsScreen.tsx` — разделение настроек и диагностика.
* `tests/theme-ui.test.tsx`, `tests/smoke.test.tsx`, `tests/parent-ui.test.tsx` — проверки первого кадра, выбора стиля и независимости цветовой схемы.
