# СЛОВО 2.0 — 0.16.0

## Темы оформления: классика, неон, космос, море

В настройках «Родителям → Настройки → Вид» теперь выбирается **тема-стиль** —
как выглядит приложение. Раньше была одна классическая палитра (тёплый крем и
сирень), теперь их четыре:

* **Классическая** — как было, вид не меняется (по умолчанию у всех, у кого уже
  есть прогресс, — ничего не перекрашивается само);
* **Неоновая** — неон-аркада: тёмный фон, магента и циан, светящиеся заголовки,
  сетка 40 px (по мотивам неон-страницы «Луи Брайль»);
* **Космос** — ночное небо: индиго, фиолетовое свечение, звёзды на фоне;
* **Морская** — бирюза, волны и морской бриз.

У каждой темы есть свой **светлый и тёмный вариант**. Выбор яркости
(«как в телефоне» / светлая / тёмная) сохранён, теперь он называется
**«Яркость»** и действует на любую тему: два независимых выбора складываются
в восемь сочетаний.

### Как это устроено

* Оформление — два независимых слоя: яркость (`data-theme`) и тема-стиль
  (`data-palette`). Классика живёт в `:root`/`[data-theme='dark']`
  (`src/styles/tokens.css`), остальные темы — блоками `[data-palette='…']`
  со светлым и тёмным набором цветов.
* У тем появились два декоративных токена: `--title-glow` (свечение заголовков)
  и `--page-grid` (фоновый узор `.app`: сетка неона, звёзды космоса, волны
  моря). Размер узора зашит в сами `repeating-*`-градиенты, поэтому число
  фоновых слоёв не «съезжает». Кнопки и выбранные пункты получили токены
  `--primary-deep` / `--green-deep` / `--on-primary`: у неона текст на магенте
  тёмный (как в исходной неон-странице), и контраст держится в любой теме.
* Выбор темы живёт в настройках (IndexedDB) и дублируется в localStorage
  (`slovo2-palette`) — как зеркало яркости. Инлайн-скрипт `index.html`
  ставит `data-theme` и `data-palette` **до первого кадра**, вместе с цветом
  системной панели из таблицы `PALETTES` (`src/platform/theme.ts`).
* Старые выгрузки прогресса и профили без поля получают классическую тему:
  миграция не нужна, ничего не перекрашивается.
* **Как добавить новую тему:** id в `PaletteId`/`PALETTES`
  (`src/platform/theme.ts`), два блока цветов в `src/styles/tokens.css`
  (светлый и тёмный), id в проверку и таблицу `panelColors` инлайн-скрипта
  `index.html`. Настройки, зеркала и метатеги читают `PALETTES` сами.
