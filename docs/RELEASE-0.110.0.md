# 0.110.0 — «Тропа слов»: исследование и первый прототип

Новая игра про слово как дорогу: ребёнок **чинит** слово (опасная буква или
порядок слогов), а потом **идёт** по нему — буквы становятся плитами, слоги
мостами, маленький герой Буквёнок шагает к остановке. Ошибка ничего не
отнимает, таймера и жизней нет.

Релиз состоит из двух частей:

1. исследование рынка и четыре концепции — `docs/proposals/new-game-concepts.md`;
2. играбельный прототип «Тропы» — новая вкладка-баннер, движок, сцена,
   сохранение в профиль и проверки.

## 1. Почему именно «Тропа»

Исследование (§2 документа) показало разрыв: в проекте есть упражнения и
награды, но между ними нет места, где слово становится миром. Wordscapes
держится на коротких уровнях и новом пейзаже как награде; Teach Your Monster
To Read — на карте с короткими остановками и ротацией знакомых механик;
Prodigy English — антипример, где деревня интереснее работы со словом.
РФ-конкуренты («Словарные слова», SlonUм, child-class) остаются карточками и
тестами.

«Тропа слов» получила самый высокий вес в §4: **4,40** против 3,40 у «Лабиринта» и
«Дневника», 3,10 у «Города Слов». Ключевое: убрать слово — исчезнет дорога.
Это не метафора, а геометрия уровня: длина слова = длина пути, слог = секция
моста, опасная буква = шатающаяся плита.

## 2. Вход: баннер, а не девятая карточка

Баннер «Тропа слов» стоит над витриной игр (`src/ui/screens/GamesScreen.tsx`).
В массив `GAMES` игру **не добавляли**: девятая карточка сдвинула бы индексы
`GAME_GATE_KEYS` и сломала бы доступ к остальным играм. Баннер:

* всегда открыт — «Тропа» не участвует в шкале ключей дня;
* показывает текущую остановку и счётчик «1 из 2»;
* открывает отдельный экран, а не подменяет сцену выбранной игры;
* возвращает к витрине кнопкой «← Игры», прогресс при этом уже сохранён.

## 3. Что уже играется

### 3.1. Две остановки 2 класса

`trailStops(2)` собирает «Школу» и «Птицы» из уроков `school` и `birds`.
В каждой — четыре слова: первое с опасной буквой, второе слоговое, дальше
остальные. Слова не выдуманы: только `LESSON_BY_GRADE[2]`, фильтр
`trailFits` — без пробелов и дефисов, 3–17 букв, есть `danger` или 2+ слога.

Почему не «В школе» вторым уроком: в программе порядок «Школа → В школе →
Птицы», но для тропы выбраны две тематически разные остановки — школьные
предметы и птицы. Порядок уроков в контенте не тронут.

### 3.2. Два режима починки

* **Буквы.** Одна опасная буква закрыта, четыре варианта. Верный выбор —
  дорога открывается. Ошибка добавляет ступень подсказки:
  `mnemonic → sentence → открытая буква`. Попытки не кончаются.
* **Слоги.** Слоги перемешаны в лотке; ребёнок выкладывает их по порядку.
  Каждый верный слог становится плитой моста, герой переходит. Неверный
  слог не сгорает: после второй ошибки следующий слог подсвечивается.

### 3.3. Дорога и герой

Сцена — только CSS и токены темы: небо, солнце, два холма, плиты дороги,
домик в начале и эмодзи остановки в конце. Плита — 44 px (цель для пальца);
на 360 px в среднюю колонку помещается четыре плиты, слово из восьми букв
идёт в два ряда. Пройденные плиты залиты мягким акцентом, текущая — акцентом
с героем в углу. В `prefers-reduced-motion` анимации героя и шатающейся плиты
выключаются.

### 3.4. Прогресс и награда

`profile.trail = { v: 1, stop, words, cards }`:

* слово сохраняется сразу после прохождения — уйти можно в любой момент;
* открытка остановки выдаётся в момент закрытия, а не по кнопке;
* `normalizeTrail` чистит мусор, повторы и отрицательный `stop`; в
  `normalizeProfile` строка стоит **после** `...raw`, как у `shop.world`;
* награда — открытка и малый XP через `playGame(1, { gems: false })`:
  задания дня двигаются, но кристаллов тропа не печатает и не забирает
  «первую сетку дня» у филворда/кроссворда.

## 4. Что не входит в прототип

Честно, чтобы не обещать лишнего:

* «Найти» (выбор из четырёх картинок) — следующий шаг; ядро «слово = дорога»
  уже играется, и третий глагол стоит добавлять после проверки на детях;
* отдельный альбом открыток — открытка показывается на экране остановки;
* лабиринт, история на две строки, все 16 остановок, 5 класс;
* кастомный SVG-герой с тремя состояниями — в прототипе стоит эмодзи-плейсхолдер
  🚶, чтобы сначала проверить цикл, а не рисовать персонажа.

## 5. Проверки

* `npm run test:content` — движок тропы: остановки, фильтр слов, дорога из
  букв, мост из слогов, шаг, санитайзер, продолжение; плюс прежний контент.
* `npm run test:smoke` — живой сценарий: баннер, продолжение с сохранённого
  слова, починка буквы, шаг по плитам, открытка «Школы», переход на «Птицы»,
  слоговый мост, возврат к витрине и возврат на то же слово.
* `npm run test:contrast` — 16 тем, 288 пар, все не ниже AA.
* `npm run test:guard`, `npm run test:adaptive`, `npm run content:check` —
  зелёные.
* `npm run build` — сборка и precache проходят.

Живая проверка на Android 360×640 остаётся за владельцем: jsdom проверяет
поток и разметку, но не реальную геометрию экрана. Если на телефоне карточка
ремонта окажется тесной, уменьшаем подсказку, а не плиты: 44 px — цель для
пальца.
