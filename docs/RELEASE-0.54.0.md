# 0.54.0 — UI-иконки: вариант B «линия + акцент» в интерфейсе

Решение пользователя от 2026-10-24: **вариант B**. Разбор — 
[`docs/proposals/ui-icons.md`](./proposals/ui-icons.md), живое превью —
[`docs/proposals/ui-icons/preview.html`](./ui-icons/preview.html).

Эмодзи в интерфейсе больше не зависят от шрифта устройства и наследуют
цвет темы. Контентные эмодзи (слова, темы уроков, интонация тостов) не тронуты.

## Что сделано

### 1. Набор `src/ui/Icon.tsx`

20 иконок по сетке 24×24, штрих 2, `round` caps/joins, штрих —
`currentColor`, акцентная деталь — класс `.ico-acc` с заливкой из токена:

```tsx
<Icon name="crystal" size={18} />
<Icon name="bulb" title="Подсказка" />   // role="img" + aria-label
<Gem value={128} />                      // [◆] 128 — кристалл и число
```

* по умолчанию иконка **декоративная** (`aria-hidden`): смысл несёт текст
  рядом, скринридер не читает «камень» вместо «кристаллы»;
* `title` превращает иконку в самостоятельный смысл (`role="img"`);
* `Gem` — самая частая связка: иконка + число одной группой с
  `font-variant-numeric: tabular-nums`, чтобы цифры не «плясали».

### 2. Токен темы

`--icon-accent: var(--primary)` в `:root`, в `[data-theme='dark']` —
`var(--primary-2)` (на тёмной подложке тёмная заливка «проваливается»).
Иконки автоматически живут в неоне, космосе, лесе, океане и тёмной схеме —
без отдельных палитр.

### 3. Шесть самых частых мест (80 % показов)

| Где | Было | Стало |
|---|---|---|
| шапка главной | `💎 128` | `<Gem value={gems} />` |
| шапка главной | `☰` | `<Icon name="menu" />` |
| меню: расшифровка счётчиков | `💎`, `🔥` | `crystal`, `flame` |
| урок: подсказка и мнемоника | `💡` (3 места) | `bulb` |
| главная: полоска заданий | `🎁` | `chest` |
| задания дня: награда и «получено» | `💎N`, `✓` | `Gem`, `check` |
| магазин: заголовок, счётчик, цены карточек, чипы полок | `БУК 🎩`, `💎 N`, `🎩/🧩/🔊` | `hat`, `Gem`, иконки полок |

У кнопки подсказки появился стабильный хук `data-hint` — тесты больше не
ищут её по эмодзи в тексте.

### 4. Новый стенд `npm run test:icons` (в CI)

`scripts/icons-check.mjs` + `tests/icons.test.tsx` — 21 проверка:

* в наборе ровно 20 иконок и имена совпадают с разбором;
* у всех `viewBox 0 0 24 24`, штрих 2, `round`, `stroke="currentColor"`;
* акцент есть у 16 из 20 и не задан хардкодом в SVG;
* декоративные — `aria-hidden`, с `title` — `role="img"` + `aria-label`;
* набор ≤ 25 КБ, без `#hex`/`rgb` и без `<text>` внутри;
* в четырёх заменённых местах не осталось функциональных эмодзи
  (комментарии не считаются — проверяется только разметка);
* контентные эмодзи слов на месте (`🦊`, `📅`, `🌾`);
* `--icon-accent` есть в токенах, светлее в тёмной теме, а `.ico-acc`
  берёт заливку из токена.

Стенд добавлен в `.github/workflows/check.yml` рядом с `test:guard`.

## Что осталось эмодзи — осознанно

* «Техника» (`🚗`), «Музыка» (`🎵`), «Фоны» (`🖼️`) в чипах магазина —
  для них в наборе 20 пока нет иконок (шаг 3b в разборе);
* цены в кнопках подробных карточек («Купить за 💎8») и фразы в тостах
  («нужен ещё 1 💎») — это текст в предложении, партия 2;
* эмодзи в контенте: слова, темы уроков, «Молодец! 🎉».
