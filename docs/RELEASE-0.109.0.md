# 0.109.0 — «Цветок слова»: нарисованный цветок

Запрос владельца: «в игре цветок слова доработай дизайн цветка, то есть
сгенерируй картинку на уровне с Pixar». 0.108.0 сделала сцену, но она была
нарисована CSS-фигурами: круглый центр, лепестки-«капли» из градиентов. Теперь
лепесток, серединка, лист и поляна — **сгенерированные растровые кадры**, как и
просил владелец.

## Что нарисовано

| Ассет | Размер | Вес | Что это |
|---|---|---|---|
| `public/flower/petal.webp` | 256×256, прозрачный | 4.8 КБ | коралловый лепесток, матовая бархатистая поверхность, волнистый край |
| `public/flower/center.webp` | 256×256, прозрачный | 18.1 КБ | жёлтая серединка из семечек с бликом |
| `public/flower/leaf.webp` | 256×256, прозрачный | 5.8 КБ | лист с прожилками (в сцене зеркалится на два) |
| `public/flower/backplate.webp` | 640×420 | 6.2 КБ | размытая солнечная поляна в боке |

Всего **35 КБ**, все четыре файла попадают в precache (`dist/sw.js`), сетевых
запросов в игре нет — офлайн работает как раньше.

## Что осталось на CSS и почему

* **Стебель** — он обязан менять высоту по прогрессу (это и есть «рост»).
  Рисованный стебель пришлось бы масштабировать, и он «толстел» бы на длинных
  словах; CSS-стебель с градиентом и сужением книзу честно тянется.
* **Тень у корня** вместо горки земли: горшок посреди поляны смотрелся мебелью.
* **Пыльца, светлячки, пыльца-«чих»** — частицы, им рисунок не нужен.

## Как это работает в игре

1. **Растение собрано снизу вверх**: тень у корня → стебель → листья → соцветие.
   Соцветие лежит **выше** стебля (`z-index`), поэтому нижний лепесток ложится
   на стебель, а не перечёркивается им — первая сборка именно так и ломалась.
2. **Закрытый лепесток — бутон**: 62 % размера, чуть темнее и приглушён, но
   остаётся коралловым. Серая заливка делала цветок больным, а не закрытым.
3. **Буква всегда стоит прямо.** Лепесток повёрнут на свой угол, буква —
   на встречный, поэтому слово читается с любого лепестка.
4. **Размер лепестков зависит от длины слова.** Окружность при радиусе 46 px
   всего ~290 px: на 4 буквах лепестки крупные (54 px), на 7–8 — 40 px, на
   9 и больше — 34 px, иначе они наезжали друг на друга. Высота стебля тоже
   своя: 4 буквы — 44→100 px, 5–6 — 48→112, 7+ — 54→126.
5. **Слово под цветком не прыгает**: у сцены фиксированная `min-height`,
   поэтому при росте стебля вниз ничего не съезжает.
6. **Тёмная тема**: поляна притемняется (`opacity: 0.58` +
   `brightness(0.68)`), чтобы светлый луг не светил фонарём. Тема читается по
   `data-theme="dark"` — так, как её ставит `platform/theme.ts`; старый селектор
   `data-theme='night'` в проекте не существует и удалён.

## Контраст букв

Буква на лепестке — `#43190d` на коралле: **5.1–6.7 : 1** по WCAG, то есть
выше AA для крупного и обычного текста. Проверено на всех трёх оттенках
лепестка (тень, центр, блик).

## Пайплайн ассетов

`node scripts/make-flower-art.mjs` — исходные кадры из `images-src/flower/`
(в git не входят) → прозрачность → trim → квадрат → WebP:

```
convert <src> -alpha on -fuzz 8% -transparent white -trim +repage \
  -resize 256x256> -gravity center -background none -extent 256x256 -strip -quality 82 <out>
```

`-fuzz 8%` обязателен: без него `-transparent white` выедал светлые блики
внутри лепестка. Скрипт падает, если файл тяжелее 60 КБ, — чтобы сцена не
расползлась по весу.

## Как посмотреть руками

В песочнице нет браузера, поэтому сцена вынесена в отдельный прототип:

```
npm run flower:proto                  # preview/flower/index.html
npm run preview:show                  # http://localhost:8080/flower/
```

Прототип склеивает **те же** `tokens.css` + `app.css` и те же WebP, поэтому
показывает ровно то, что будет в игре: можно нажимать буквы, увидеть распуск,
промах с пыльцой и качанием, цветение; переключить слово (3/6/9/10 букв),
тёмную тему и узкую карточку 340 px. В git прототип не попадает — `preview/`
уже в `.gitignore`, собирается командой.
