# СЛОВО 2.0 — 0.14.2

## Оформление на Android и контраст QR

- Светлая тема явно объявляет `color-scheme: only light`, чтобы браузер не перекрашивал её автоматически при тёмной системной теме. Тёмная тема объявляет собственную схему.
- Режим «как в телефоне» отслеживает смену системной темы без перезапуска приложения; подписка снимается при смене настройки.
- QR-код во всех темах и размерах рисуется строго чёрным на белом. Сохранена тихая зона в четыре модуля, отключена принудительная подмена цветов для SVG.

Добавлены smoke-проверки выбора темы при тёмной системе и цветов обычного и увеличенного QR. Реальное устройство Android ещё требует визуальной проверки.
