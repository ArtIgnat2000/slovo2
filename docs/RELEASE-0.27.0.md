# Релиз 0.27.0 — класс на выбор: 1 и 2

## Что изменилось

**Класс теперь — свойство профиля, а слова — общий банк.** В профиле появилось
поле `activeClass` (1–4), главная, «Мой путь», словарик и «Родителям → Обзор»
показывают программу выбранного класса. Сейчас наполнены **1 и 2 классы**;
3 и 4 добавляются следующими релизами (см. `docs/proposals/classes-1-4.md`).

**Смена класса ничего не сбрасывает.** Меняются только `activeClass` и
адаптивное окно (`adaptiveGood`), которое набиралось на другой программе.
Опыт, кристаллы, серия, заморозки, достижения, дни, история занятий, уровни
уроков, покупки, тюнинг, музыка, звуки, мечты, пазлы, облик сундука,
дневные и недельные награды остаются. Старые профили и старые выгрузки без
поля продолжают открываться во 2 классе.

## Что видит ребёнок

* **Пилюля класса над героем** — «2 класс · 94 слова ▾». Тап открывает лист
  «Какой класс учим?»: у каждого класса число слов и «пройдено N из M».
  После переключения — тост, что опыт, кристаллы и покупки на месте.
* **«Мой путь» — только активный класс:** 5 уроков в 1 классе, 16 во 2.
  Герой «Сегодня» ведёт на текущий урок своего класса.
* **Класс пройден:** если все уроки класса закрыты, герой говорит
  «Класс пройден!» и предлагает следующий класс (или повторение, если
  дальше программы пока нет).
* **Словарик:** ряд классов → ряд уроков. Фильтр слов теперь идёт по составу
  урока (`wordIds`), а не по теме слова: раньше он совпадал с темой случайно.

## Что видит родитель

* **«Настройки» → «Класс»** — первая настройка раздела, с честным
  объяснением: «меняется только набор слов». Работает через тот же `Choice`,
  что и цель дня.
* **«Обзор» → «Слова · N класс»** — «освоено» и «программа пройдена на N%»
  считаются по классу, а общее число за 1–4 показано рядом в подсказке.
* **«Профили»** — класс выбирается при создании ученика (без предвыбора:
  кнопка «Начать учиться» ждёт выбора) и меняется при редактировании;
  в списке у каждого ученика бейдж «N класс».

## Контент

* 1 класс — **30 слов** словарика учебника, 5 уроков. Из них 28 уже были в
  пакете 2 класса, новые карточки — «лисица» и «мальчик» (пока с эмодзи).
* 2 класс — те же **94 слова и 16 уроков**, `id` уроков и слов не менялись:
  прогресс всех, кто уже учится, читается как раньше.
* У слова появился `grades: ClassId[]` — список классов, в словариках которых
  оно встречается. `GRADES_OF` хранится картой, а не 11-м полем `RAW`:
  94 проверенные строки пака не правятся вовсе.

## Модель и совместимость

* `Word.grades`, `GradeLesson.grade`, `Profile.activeClass`; `Lesson` для
  «Повторения» не изменился.
* `id` слов: если слово входит в программу 2 класса — исторический префикс
  `g2_`; иначе первый класс, где оно появляется (`g1_лисица`). Новые уроки —
  `g1_school` и т. д., исторические `id` 2 класса не тронуты.
* `normalizeProfile` валидирует класс (1–4), всё остальное → 2; версия
  сохранения не поднималась, отдельная миграция не нужна.
* Класс, которого нет в сборке (например, импорт профиля из будущей версии),
  для отрисовки заменяется ближайшим доступным, но сохранённое значение
  не перезаписывается.
* Повторение остаётся по **всем** изученным словам 1–4: иначе при переходе
  2 → 3 слова 2 класса перестали бы приходить, а задание дня «Повтори N»
  стало бы невыполнимым.

## Проверки

* `npm run test:content` (новый, есть в CI) — связность контента: уникальные
  `id` и тексты, объёмы классов (30 / 94), каждый урок входит в свой класс,
  каждое слово класса — ровно в одном уроке, префиксы `id`, доступные классы,
  тема новых слов.
* `tests/classes.test.ts` (входит в `npm run test:smoke`) — «богатый» профиль
  (опыт, кристаллы, серия, достижения, дни, покупки, тюнинг, пазл, облик
  сундука, награды) до и после переключения 2 → 1 → 2: разрешены только
  `activeClass` и `adaptiveGood`; старый профиль без поля; `setProfileClass`
  не трогает чужой профиль; выгрузка → импорт (класс и прогресс приезжают из
  файла, JSON-путь как у настоящей выгрузки); файл из будущей версии с классом
  4 сохраняет класс и не перезаписывается; файл 0.26.0 без поля открывается
  во 2 классе; UI — пилюля, лист, путь 1 и 2 класса, урок 1 класса показывает
  слово 1 класса.
* `tests/adaptive.test.ts` больше не требует «ровно 94 слова»: объём класса
  проверяет `test:content`, а аудит орфограмм идёт по всем словам банка.
* Тексты приложения: «1–4 класс» в `share.ts`, `index.html`, манифесте PWA и
  `package.json`.
