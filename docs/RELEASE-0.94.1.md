# 0.94.1 — «Игры» помещаются на телефоне и планшете

Патч по скриншоту владельца (iPhone, вкладка «Игры»): текст не влезал по
ширине (и мог быть частично закрыт плавающим Буком), внизу — длинный список
чипов-слов, на планшете экран занимал лишнюю высоту.

## Что изменено

- **Минимум текста.** Вступление к «Играм»: «Играй сколько хочешь: ничего не
  сгорает и ничего не считается.» Описание «Собери слово» сокращено до
  «Выложи слово из карточек.» Подпись филворда: «Веди по буквам: найди все
  слова. Опасные буквы — оранжевым.» Баннер победы филворда убран «излишек»
  («Или собери новую сетку.»).
- **Чипы слов** (60 штук) на телефоне ограничены высотой 128 px с внутренней
  прокруткой — экран больше не «бесконечный»; на ≥ 760 px — 168 px, базово —
  140 px.
- **Телефон (≤ 480 px):** игра-карточки поуже (12 px поля), заголовок 17 px,
  emoji 32 px, пады чипов и поля филворда меньше.
- **Планшет (≥ 760 px):** «Игры» шире (980 px) и идут в **две колонки** —
  «Собери слово» и «Филворд» рядом, `align-items: start`.
- Тёмная тема, рамки `1.5px var(--line)`, минимальная высота целей ≥ 40 px —
  без изменений (инварианты сохранены).

## Что НЕ трогали

- Механика «Собери слово», филворд, кнопки, SRS/XP — без изменений.
- Плавающий Бук остаётся на месте: он прячется при прокрутке; минимум текста —
  чтобы закрывать было меньше.

## Проверки

`npm run release:check` (0.94.0 → 0.94.1), `npm run typecheck`,
`npm run test:smoke` — все проверки пройдены (в т.ч. «игры:» и «филворд:»).
