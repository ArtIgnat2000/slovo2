# 0.88.1 — маршрут фотосерий и контракт «пара или ничего»

## Что сделано

- Новый документ `docs/proposals/photo-series-plan.md`: стандарт кадра,
  именование файлов, правило «пара или ничего», порядок запуска и брифы
  второго кадра на все 38 нарядов и 24 товара с одиночным кадром.
- Очередь нарядов зафиксирована: `crown`, `glasses-heart`, `choker` первыми,
  затем девять вещей прошлой серии, затем остальные 26.
- Для питомцев отдельно записано ограничение: второй кадр — только
  референсной правкой или реальной съёмкой, генерация «с нуля» даёт другое
  животное.
- Новый тест `tests/photo-plan.test.mjs` (входит в `npm run test:galleries`):
  таблицы документа сверяются с `shop.ts`, бриф второго кадра не может быть
  кропом, у наряда не бывает главного кадра без второго, второй кадр не может
  быть копией главного, в `public/products/gallery` не остаётся файлов без
  ссылки из галереи или плана.
- `scripts/make-product-images.mjs` теперь кладёт кадры `<id>-alt`,
  `<id>-front` и `<id>-detail` в `public/products/gallery/` — туда, где их
  ищут галереи.
- `docs/proposals/product-galleries.md`: раздел «Следующие шаги» обновлён,
  цифровые обложки отмечены сделанными, добавлена зависимость — общий
  двухкадровый просмотр для не-техники.
