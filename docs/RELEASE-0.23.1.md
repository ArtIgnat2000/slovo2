# Релиз 0.23.1 — подробная карточка техники показывает товар

## Запрос

По кнопке «Посмотреть» у ближайшей покупки открывается подробная карточка, но
вместо товара крупным планом стоит БУК. Для техники это бессмысленно: сову не
надевают на телефон. Попросили показывать в просмотре сам товар, без БУКа.

## Что изменилось

* В подробной карточке техники (`ShopScreen`) рисуется сам товар крупным
  планом: машины и суда — карандашные листы (`CarArt` / `ShipArt`), телефоны —
  крупный SVG (`ToyArt`). БУК остался только в карточках нарядов и костюмов,
  где он и правда служит примеркой.
* `ToyArt` получил необязательный `alt`: в подробном просмотре у рисунка есть
  подпись для скринридера, на витрине рисунок по-прежнему декоративный, потому
  что карточка уже названа.
* CSS: крупный рисунок в арке подробной карточки (`shop-bigart-toy-art`).
* Статическая демонстрация магазина (`ShopDemo`) обновлена вместе с экраном.

## Проверки

* `npm run typecheck`
* `npm run test:smoke`

В smoke-тест добавлена проверка подробной карточки телефона: крупный SVG с
подписью и отсутствие БУКа в просмотре.
