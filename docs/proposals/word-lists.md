# Списки слов к контрольной: разбор и варианты

**Дата:** 2026-10-24 · **Статус:** ✅ **вариант B реализован в 0.58.0** ·
**Задача:** «в школе дали список слов к контрольной — нужно тренировать
именно эти слова; дальше такие списки будут ещё».

---

## 1. Ваш список: что уже есть в приложении

В банке **257 слов**, и почти весь список совпал:

| | шт. | что |
|---|---:|---|
| есть в банке (с картинкой и предложением) | **23** | хорошо, ученик, ученица, учитель, петух, заяц, воробей, ворона, весело, спасибо, прощай, город, родина, ветер, скоро, быстро, яблоко, яблоня, берёза, лопата, ягода, осина, до свидания |
| **нет в банке** | **3** | **прощайте**, **подлежащее**, **сказуемое** |

По классам: 23 слова из 2 класса, 9 из них входят и в словарик 1 класса.

Вывод: технически задача решается «в два слоя» — научиться **собирать
произвольный список и тренировать его** и научиться **принимать слова,
которых нет в банке** (иначе «подлежащее» и «сказуемое» не потренировать).

## 2. Что уже готово в движке (не придётся изобретать)

* **Урок — это просто список id.** `buildLesson({ lesson })` берёт
  `lesson.wordIds` и строит знакомство → закрепление → второй круг.
  «Повторение» (`REVIEW`) уже работает с пустым `wordIds` и своими словами —
  значит режим «урок по произвольному набору» архитектурно существует.
* **Прогресс по слову** (`WordState`: score, due, интервал) привязан к `id`,
  поэтому тренировка списка будет честно двигать SRS и дневную статистику.
* **Экран урока** один: он не знает, откуда взялся набор, — знает только
  `lessonId`. Значит новый источник слов = новый тип `lessonId`.

## 3. Чего не хватает

| Что | Почему важно |
|---|---|
| Хранилище списков | список — это данные, а не код: `profile.lists` в профиле, попадает в выгрузку и сейф |
| Создание списка | родитель вставляет текст из чата класса, слова матчатся с банком |
| Слова вне банка | нужен резолвер: `WORD_BY_ID` сейчас статический и не знает про «подлежащее» |
| Вход в тренировку | ребёнок должен видеть «Контрольная: 26 слов» и одну кнопку |
| Автозаполнение полей | у слова вне банка нет ударения, слогов, «опасных» букв, предложения |

## 4. Три варианта

### Вариант A. «Списки только из банка»

Список = набор существующих слов. Родитель вставляет текст, приложение
показывает «прощайте, подлежащее, сказуемое — нет в словаре», их можно
добавить в пак отдельной партией.

| | |
|---|---|
| Плюсы | 1–1,5 дня; движок не трогаем; SRS, награды, дневной отчёт — бесплатно |
| Минусы | «подлежащее» и «сказуемое» не потренировать, пока их нет в паке; **каждый новый список со «своими» словами = запрос к разработчику** — а вы говорите, что списки будут ещё |
| Итог | решает сегодняшнюю задачу частично (23 из 26) |

### Вариант B. «Свои слова в списке» — **рекомендую**

Список может содержать слова из банка **и** свои. Для своих слов приложение
делает карточку автоматически, а родитель может поправить два поля.

| | |
|---|---|
| Плюсы | списки самодостаточны: дальше вы добавляете их сами, без разработчика; «подлежащее»/«сказуемое» работают; слова из списка можно дополнить картинкой позже |
| Минусы | 3–4 дня; нужно аккуратно заменить статический `WORD_BY_ID` на резолвер (6–8 мест) и покрыть тестами; у своих слов нет картинки (эмодзи-плита) |
| Итог | закрывает задачу целиком и на будущее |

### Вариант C. «B + режим контрольной»

Плюс к B: отдельная **проверка** — проход по всем словам списка **без
подсказок**, в конце отчёт «24 из 26, ошибки: подлежащее, осина», родителю
видно результат. Без таймера и без «жизней» (стоп-лист проекта).

| | |
|---|---|
| Плюсы | то, что реально просят к контрольной: «проверься, как в школе» |
| Минусы | +1–1,5 дня; два режима надо объяснить ребёнку |
| Итог | логичный **этап 2** после B |

## 5. Как я предлагаю сделать вариант B

### Данные (профиль)

```ts
lists?: PracticeList[];          // списки к контрольным, сколько угодно
customWords?: Record<string, Word>; // слова вне банка, только свои
```

`PracticeList = { id, title, words: string[], createdAt, lastRunAt? }`.
Списки — **в профиле ребёнка** (не общие): у двух детей могут быть разные
классы и разные контрольные. Всё попадает в выгрузку и в сейф прогресса.

### Создание списка (родительский раздел)

«Родителям → Программы» → «+ Список к контрольной»:

1. название (по умолчанию «Контрольная 12.11»);
2. поле «Вставьте слова из чата» — по одному в строке или через запятую;
3. предпросмотр: ✅ найдено в банке (23) · ➕ добавим как своё (3) ·
   ⚠️ дубликаты/пустые строки убираются;
4. для своих слов — маленькая карточка: слово, **ударение** (тап по слогу),
   «опасные буквы» (тап по буквам, по умолчанию все безударные гласные),
   подсказка-значение в один клик.

Автозаполнение для своих слов: слоги — по гласным; ударение — последний
слог (правится одним тапом); «опасные» — безударные гласные + парные
согласные; эмодзи 📖; предложение не требуется, вместо него задание
«напиши по памяти».

### Тренировка (ребёнок)

На «Уроках» над путём тем — узкая карточка **«Контрольная · 26 слов»**
(как полоска заданий, 64 px, одна кнопка «Тренировать»). Тап открывает
обычный экран урока, но:

* набор = слова списка;
* задания те же (`intro`, `choice`, `build`, `write`, …);
* прогресс пишется в те же `WordState` и дневную статистику;
* «короны» уроков класса не меняются, адаптивный размер не участвует;
* в конце — обычный экран результатов.

### Награды

Предлагаю **обычные XP, но без кристаллов за «контрольную»** и с пометкой
«тренировка списка» в дневном отчёте: кристаллы остаются наградой за
программу, иначе список можно перезапускать бесконечно.

## 7. Риски и как их снимаем

| Риск | Решение |
|---|---|
| свои слова «портят» словарик и уроки классов | они живут **только в своём списке**, в программу класса не попадают |
| ошибка в ударении/опасных буквах у своего слова | их видно и правится в предпросмотре; тест на автополя |
| бесконечный фарм кристаллов | за «контрольную» — XP без кристаллов |
| список становится «мусоркой» | в карточке видно «26 слов · из них 3 своих», в родительском разделе — удаление |
| ребёнок не понимает, что это | подпись «Слова из школы» и эмодзи 🏫, без соревновательности |
| старые профили | поля опциональные, нормализация при чтении, выгрузка без них читается как раньше |

## 8. Решения пользователя (2026-10-24)

| Вопрос | Ответ |
|---|---|
| Где создавать списки | **только в «Родителям»** |
| Награды за тренировку | **только XP**, без кристаллов |
| Свои слова | **только внутри списка**, в словарик и программу класса не попадают |
| Формат ввода | **текстом** — вставка списка из чата класса |

Отличия от плана (в лучшую сторону):
* нормализация переехала в движок (`normalizeLists`, `normalizeCustomWords`),
  чтобы её можно было проверить тестом без поднятия всего стора;
* порядок слов в заходе сортируется по нужде (невиденные → слабые →
  просроченные), поэтому список длиннее урока проходится целиком, а карточка
  показывает «тренировано N»;
* у своих слов в предпросмотре ударение ставится **до** сохранения — родитель
  видит результат сразу.
