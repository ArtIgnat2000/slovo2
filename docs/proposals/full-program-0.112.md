# Полная программа «Тропы слов» — 0.112.0

Статус: **реализовано в 0.112.0** (движок, UI, тексты). Документ фиксирует
объём, числа и то, что осталось за границей релиза.

## 1. Что значит «полная программа»

До 0.111.0 игра знала два режима объёма: 2 класс — все 16 уроков, 1/3/4 —
по две остановки-превью, 5 — закрыт. 0.112.0 убирает превью как отдельное
состояние: **каждый урок класса становится остановкой**, а число остановок
равно числу уроков.

| Класс | Уроков = остановок | Слов в тропе | Из них с картинкой | Режим |
|---|---:|---:|---:|---|
| 1 | 5 | 20 | 20 | картинки |
| 2 | 16 | 64 | 64 | картинки |
| 3 | 13 | 52 | 52 | картинки |
| 4 | 15 | 60 | 60 | картинки |
| 5 | 22 | 88 | часть; остальные — эмодзи | текстовый |
| **Всего** | **71** | **284** | | |

В банке 367 слов: 284 слова попадают в тропу, остальные отсеивает
`trailFits` (короче 3 букв, фразы, дефисы, нечего чинить и не из чего
собирать слоги). Это не потеря контента: те же слова живут в уроках, играх и
карточках.

## 2. Почему у 5 класса текстовый режим

У 5 класса 127 слов, картинки есть у единиц; рисовать 100+ новых картинок
до релиза — отдельный арт-проект (см. `art-plan-pixar.md`). Если оставить
`find` только для `word.image`, третьи слова остановок 5 класса превращались
бы в пустую рамку или в «дорогу» без задания.

Решение: **«найти» работает по визуальному якорю** — картинке **или** эмодзи.
Для 5 класса карточка показывает крупное эмодзи и слово; для 1–4 классов —
прежнюю картинку. Верная карточка всегда среди четырёх, ошибка ничего не
отнимает, подсказка после двух ошибок та же. Это не отдельный режим с
другой механикой, а тот же `find` с другим носителем образа.

Правило на будущее: если у класса меньше 50 % слов с картинками, тропа
класса идёт текстовым режимом; смешивать картинки и текст в одной сетке
нельзя — ребёнок сравнивает несравнимое.

## 3. Лабиринт — редкая остановка, а не девятая игра

Вердикт §3.3 `new-game-concepts.md` принят без изменений: лабиринт живёт
**внутри** тропы и появляется на третьем слове каждого четвёртого отрезка
(`stopIndex % 4 === 3`): 4-я, 8-я, 12-я, 16-я, 20-я остановки. За программу —
16 лабиринтов (1 + 4 + 3 + 3 + 5 по классам).

* Ветки — четыре буквы: верная и три соседки из `trickyOptions`, то есть
  тот же источник, что у «Хитрой буквы». Отдельного банка вариантов нет.
* Верная буква открывает следующую плиту; неверная показывает «тупик»,
  не отнимает прогресс и не включает таймер.
* `walked` — и курсор лабиринта, и число открытых плит: сцена показывает
  только пройденные буквы, герой стоит на последней. Слово целиком
  открывается после последней верной буквы.
* Лабиринт не пишет отдельного прогресса и не даёт отдельной награды:
  закрытие слова идёт через общий `finishWord` → `playGame(1, { gems: false })`.

Это сохраняет правило «новая игра — только по решению владельца»: в `GAMES`
по-прежнему восемь карточек, баннер тропы — над витриной.

## 4. История на две строки

После закрытия остановки открытка показывает две строки:

1. сцену места («В школьном дворе пахнет мелом и яблоками.»);
2. что осталось у героя («На стене — новая открытка «Школа».»).

Для 16 остановок 2 класса тексты авторские. Для остальных классов —
тёплая формула с названием остановки и следующей остановки; она не выглядит
заглушкой и заменяется построчно без изменения UI. Истории не озвучиваются,
не требуют тапа и не удлиняют экран: это два `<p>` внутри открытки.

## 6. Метрики приёмки (те же, §5.5)

* 4–6 слов за сеанс;
* возврат на следующий день ≥ 40 %;
* подсказки у 20–40 % слов;
* завершение остановки ≥ 70 %.

Лабиринт считается удачным, если на нём не падает завершение слова и не
растёт доля подсказок относительно `find`. Истории — если дети остаются на
открытке дольше, чем на кнопке «Дальше» (наблюдение, не телеметрия).
