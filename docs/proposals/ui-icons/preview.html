UI-иконки 0.68.0 — «вау-алмаз»

История: в 0.54.0 набор был линейным — дети его не приняли. В 0.55.0 стал цветным, но следующий отклик: «алмаз слишком маленького размера — плохо видно, выглядит неубедительно». В 0.56.0 кристалл стал крупным и плоским — но дети сказали «не впечатлил, в мультиках лучше». В 0.68.0 — «вау-версия»: мягкий ореол-свечение, объёмный градиент по камню, зеркальный блик и две мерцающие искры (вариант B из crystal-wow.html).

Правила набора

  • сетка 24×24; главный значок занимает почти всю клетку (≤ 1,6 поля);
  • плотная заливка + тонкий контур своего тёмного оттенка (1–1,2 px), чёрный контур запрещён;
  • монохромные знаки (menu, check, close, arrow) — currentColor;
  • <Gem> по умолчанию 1.15em — иконка чуть крупнее цифр; в шапке 26 px;
  • проверяет npm run test:icons (23 проверки) в CI.
