UI-иконки 0.56.0 — крупный кристалл

История: в 0.54.0 набор был линейным — дети его не приняли. В 0.55.0 стал цветным, но следующий отклик: «алмаз слишком маленького размера — плохо видно, выглядит неубедительно». В 0.56.0 кристалл перерисован третий раз: классический бриллиант на всю сетку (87 % высоты) с чередованием светлых и тёмных граней; в шапке и ценах он крупнее цифр.

Правила набора

  • сетка 24×24; главный значок занимает почти всю клетку (≤ 1,6 поля);
  • плотная заливка + тонкий контур своего тёмного оттенка (1–1,2 px), чёрный контур запрещён;
  • монохромные знаки (menu, check, close, arrow) — currentColor;
  • <Gem> по умолчанию 1.15em — иконка чуть крупнее цифр; в шапке 26 px;
  • проверяет npm run test:icons (23 проверки) в CI.
