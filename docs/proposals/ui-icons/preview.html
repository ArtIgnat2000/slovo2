UI-иконки 0.55.0 — цветной набор

В 0.54.0 был линейный набор «линия + акцент». Детям он не понравился, особенно алмаз: в 16–24 px тёмный контур превращал его в стрелку с фиолетовыми щелями. Новый язык — тот же, что у картинок к словам: плотная цветная заливка, тонкий контур своего оттенка, мягкий блик. Ниже — реальные размеры, тёмная тема и построчное сравнение «было / стало».

Правила набора

  • сетка 24×24, заливка + контур 1–1,2 своего тёмного оттенка; чёрный контур запрещён;
  • монохромные знаки (menu, check, close, arrow) — currentColor;
  • ≤ 48 цветов на набор, ≤ 32 КБ, ни одной буквы внутри;
  • aria-hidden по умолчанию, title — когда иконка без подписи;
  • проверяет npm run test:icons в CI.
