# Цифровые обложки: редакционные конверты для музыки и звуков

Статус: 30.10.2026 — две стороны; 0.89.8 — третья сторона у трека
(иллюстрация музыки). Компонент —
`src/ui/DigitalCover.tsx`, стили — блок «Цифровые обложки» в
`src/styles/app.css`.

## Задача

Музыкальные треки и наборы звуков — цифровые товары: у них нет физического
предмета, который можно снять в студии. До этого на витрине у них была
эмодзи-картинка на градиенте: она не объясняла, что покупает ребёнок, и
выбивалась из фотореалистичного каталога. Сгенерированное «фото» трека было бы
обманом — на витрине появился бы предмет, которого не существует.

Решение — **редакционная обложка**, как у настоящего цифрового издания:
типографика, абстрактная графика и оборот с проверяемыми данными.

## Что на обложке

Лицевая сторона:

- серия и номер: `SLOVO–01…12` для треков, `SIGNAL–01…06` для звуков;
- название для ребёнка крупной типографикой;
- абстрактный спектр, посчитанный детерминированно от `id` (один и тот же
  трек всегда выглядит одинаково — в магазине, «Моём мире» и демо);
- для полного размера — оригинальное название, автор, длительность и темп.

Третья сторона (0.89.8, только у треков) — **иллюстрация музыки**. Пользователь
попросил картинку, которая объясняет мелодию детям: типографика и спектр им
ничего не говорят. Это «внутренняя страница буклета», а не фотография товара:

- сцена настроения — небо, солнце, облака, холмы, вода, деревья, кусты и травы;
  у «Спокойного фона» тихое утро со звёздами, у «Коллекции» тёплый вечер
  с флажками и конфетти;
- **предмет мелодии по названию** (0.89.9): первая версия рисовала всем трекам
  один и тот же пейзаж, и картинка не соответствовала названию. Теперь у
  каждой мелодии свой мотив на переднем плане — `MUSIC_MOTIFS`
  в `DigitalCover.tsx`: «Беззаботный день» — воздушный змей, «Счастливые
  деньки» — радуга, «Лимончик» — лимоны, «Тёплый дом» — домик с дымком,
  «Тихий ритм» — рулон обоев, «Весёлый жук» — жук, «Обезьянки» — две
  обезьянки, «Шаг на цыпочках» — следы, «Утёнок» — утёнок, «Весёлый
  переулок» — два дома и фонарь, «Добрый понедельник» — календарь,
  «Пикселяндия» — пиксельный замок;
- ноты и знак мелодии нарисованы вектором (не шрифтом и не эмодзи): шрифт
  с эмодзи есть не везде, а пустой кружок вместо символа выглядел бы браком;
- всё детерминировано от `id`, поэтому у одного трека картинка всегда одна и
  та же, а новый трек получает иллюстрацию сразу, без съёмки;
- порядок сторон: лицо → иллюстрация → оборот, счётчик «1 / 3 … 3 / 3».
  У набора звуков сторон по-прежнему две: его «картинка» — партитура нот.

Оборот:

- **трек** — настоящие метаданные из `src/engine/music.ts`: оригинальное
  название, автор, длительность, темп, лицензия (CC BY 4.0), ISRC. Ни одного
  выдуманного факта; полный текст лицензии по-прежнему в «Авторах и лицензиях»;
- **набор звуков** — партитура реальных нот из `src/engine/sounds.ts`:
  «пиано-ролл» по времени и высоте тона для сигнала верного ответа и для
  ошибки, включая плавные съезды частоты (`glideTo`), плюс перечень тембров.

Палитра выводится из `id`: приглушённый чернильный фон, бумажный текст,
один акцент. Серия получается разнообразной, но остаётся одной «печатной»
школой — рядом с фото товаров обложки не выглядят другой игрой.

## Чего нет намеренно

- персонажей, мультяшных сцен, нарисованных инструментов;
- фальшивых фотографий и «чехлов» с вымышленными артистами;
- анимации переворота: смена стороны мгновенная, `prefers-reduced-motion`
  отключает только эквалайзер прослушивания.

## Где используется

- `src/ui/screens/ShopScreen.tsx` — карточки витрины, лист трека и лист набора,
  герой «Следующая цель», карточки мечт, строки «Моих покупок»; крупный лист
  переключает стороны;
- `src/ui/screens/WorldScreen.tsx` — коллекция «Мой мир»: плитки, миниатюры
  карты и крупный кадр с оборотом;
- `src/ui/ShopDemo.tsx` — демо-витрина и лист трека.

Размеры: `mini` (36–84 px, только номер и спектр), `card` (ниша витрины,
читается название), `full` (лист с переключением сторон и счётчиком «1 / 2»).

## Доступность

- крупная обложка — кнопка с `aria-label` («Обложка «…»: лицевая сторона.
  Показать оборот…»), `aria-pressed` и счётчиком сторон в `aria-live`;
- маленькие обложки декоративны (`aria-hidden`): название уже есть текстом
  рядом;
- фокус виден, размеры текста не уменьшаются ниже читаемых, переключение не
  требует движения.

## Проверки

- `npm run test:smoke` — у всех 12 треков и 6 наборов есть обложка; лист
  открывается лицом, тап показывает оборот, на обороте трека читаются
  оригинальное название, ISRC и лицензия, на обороте набора — две партитуры;
  у трека три стороны: лицо → иллюстрация (`.dc-art-svg`) → оборот, счётчик
  «1 / 3», «2 / 3», «3 / 3»; у набора звуков две стороны, счётчик «1 / 2»;
- `tests/world-ui.test.tsx` (входит в смоук) — обложки в коллекции, крупный
  кадр и оборот в «Моём мире»;
- `npm run typecheck`, `npm run build`.

## Что можно улучшить дальше

- отдельная страница «Об авторах» с QR на источник записи — сейчас ссылка на
  incompetech.com живёт в тексте лицензий;
- печатная серия для мерча (`docs/merch`) может переиспользовать те же номера
  `SLOVO–NN`;
- если появится генератор изображений, обложки всё равно остаются
  редакционными: фотореалистичная «съёмка» цифрового товара противоречит
  правилу каталога.
