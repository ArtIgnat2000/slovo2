## 1. Коротко

* «Школа России» (Канакина–Горецкий) заканчивается **4 классом**; это НОО.
  5 класс — средняя школа, другая программа и другой учебник.
* **Источник словаря (зафиксировано владельцем, 2026-11-09):** В. В. Баранов,
  Л. Т. Григорян, Т. А. Ладыженская, Л. А. Тростенцова и др.
  **«Русский язык. 5 класс» (Просвещение)**, издания 2025/2026 —
  учебник включён в федеральный перечень и соответствует ФГОС ООО.
* **Модель приложения не меняется:** один банк `WORDS`, `grades: ClassId[]`,
  класс — фильтр (`Profile.activeClass`), один прогресс на слово, уроки
  `GradeLesson` с `grade: 5`. Уроки 1–4 классов и их `id` не трогаем.
* **Ожидаемый объём** не фиксируем в этом документе до получения списка:
  подборки «словарные слова 5 класса» в интернете расходятся на десятки слов,
  а состав орфографического минимума учебника Баранова не совпадает
  с веб-подборками. Фиксируем **только приложенный список** после сверки
  с учебником (точность — как для 3–4 класса: ±3 слова).
* **Картинки:** выходим на эмодзи (решение владельца, §7.6 PROJECT-RULES);
  генерация — партиями ≤3 кадра **после** релиза класса, цель — 100 %
  отдельным циклом как в 0.52.0.
* **Объём работ:** контент-этап ~1–2 дня (сборка строк, вычитка, сверка),
  кодовый этап ~0,5–1 дня (типы, экспорты, тесты, тексты, релиз).

## 2. Источник и точность

### 2.1. Почему именно Баранов–Ладыженская

| Критерий | Баранов (Просвещение) | Альтернативы |
|---|---|---|
| Массовость | самый ходовой УМК в 5 классе РФ | Разумовская (Дрофа), Бабайцева (Дрофа) — уже |
| Формат | списки словарных слов по § в конце каждого раздела + словарь в конце учебника | аналогично |
| Перечень | ФГОС ООО, федеральный перечень 2025/2026 | — |

Решение владельца получено 2026-11-09: **Баранов–Ладыженская**. Если при
сверке окажется, что приложенный список составлен по другому УМК — состав
сохраняем (источник — слово владельца), а в документе отмечаем фактическое
расхождение с Барановым.

### 2.2. Правила сверки

1. **Приложенный список первичен.** Мы не добавляем и не удаляем слова
   «потому что в интернете так».
2. Каждое слово сверяется с **печатным** учебником издания 2025/2026
   (наличие в словаре, написание, ударение). Онлайн-подборки — только
   как подсказка для проверки, не как источник.
3. Производные формы: если форма стоит в учебнике **отдельным словарным
   словом** — отдельная карточка (как «инженеры», «пассажирский» в 4 классе);
   иначе — нет.
4. Фразы: поддерживаются движком (как «до свидания», «Красная площадь»),
   без «собери из букв»; включать только если они отдельные словарные
   единицы учебника и приложены владельцем.
5. Термины с нестандартным ударением и грамматические термины: ударение —
   через `tests/stress-snapshot.ts` и (для слов вне банка)
   `src/content/stress-dict.ts` по образцу «подлежАщее — 6» (0.61.1).
   Проверять по словарю (Викисловарь / Грамота.ру / МАС), не на слух.

### 2.3. Что делать с пересечениями

Слова 5 класса, которые уже есть в банке 1–4 (вероятные: «путешествие»,
«расстояние», «инженер», «серебряный» и т. п. — зависит от состава списка),
получают в `GRADES_OF` класс 5 в дополнение к текущим — **одна карточка,
один прогресс**. Ничего не дублируется (§4.11 PROJECT-RULES).

## 4. Как заводим слова (пошагово)

1. **Получить список** (приложит владелец в следующем сообщении). Сразу
   сверить с учебником Баранова 2025/2026 по §2.2. Зафиксировать в этом
   документе (§10): источник, издание, дата сверки, точный состав.
2. Черновик: `node scripts/words-from-text.mjs words5.txt > words5.draft.txt`.
3. Ручная разметка каждой строки: `stress`, `syll`, `danger` (о/е/я/э всегда!),
   `dangerKind`, `emoji`, `sentence` (словарная форма, один `____`),
   `hint`, `mnemonic` (по возможности). Правила — PROJECT-RULES §4.
4. Строка в `GRADES_OF` (новые — `[5]`, пересечения — дописать `5`).
5. Уроки (§5): сгруппировать слова в тематические блоки 4–8 слов,
   `G5_LESSONS`, проверить через `test:content`.
6. Снимок ударений (`tests/stress-snapshot.ts`).
7. `npm run content:check` — зелёный; разобрать `⚠ К вычитке вручную`.
8. Вычитка взрослым (значение, падежи, естественность, отсутствие ответа,
   возраст 11–13 лет); вторая вычитка — по печатному учебнику.
9. Релиз (§7). Картинки — после релиза (§8).


## 5. Уроки 5 класса (заполнится после получения списка)

Принципы (не меняются): 4–8 слов в уроке; тематические блоки по смыслу
учебника; название и эмодзи урока; `order` 1..N; `id` = `g5_<slug>`; слово
входит ровно в один урок; пересечения остаются в одном уроке (общая
карточка).

Черновая сетка (уточняется по составу списка; по образцу 3/4 класса
ожидается 12–18 уроков):

| № | Урок (рабочее название) | Слов |
|---|---|---|
| 1–N | заполняется после §10 | 4–8 |

Правило: сначала закрыть **содержательные** блоки учебника (лексика),
грамматические темы в уроки словарных слов не мешаем (глаголы, падежи —
не словарные слова).

## 8. Картинки (строго после релиза класса)

1. **Не рисуем до релиза**: контент первичен; эмодзи-плита — штатный вид.
2. Партия = ≤3 кадра за подход; шаблон промпта — PROJECT-RULES §7.4;
   приёмка — §7.3; слаги — транслитом, словосочетания через `_`.
3. Порядок: сначала слова, где эмодзи не различает (одна иконка у разных
   слов — тот же анализ, что в `word-images-priority.md` §3), затем
   конкретные предметы, затем отвлечённые (сценой; если не читается —
   оставляем эмодзи).
4. Бюджет уточняется по N: ориентир ≈ 5,3 КБ на картинку; precache растёт
   только на величину пака; 12 МБ на файл — жёсткий потолок не приближаем.
5. После каждой партии: кадр → `make-word-image.mjs` → RAW → `content:check` →
   `images:report`. По закрытии — `images:report -- --strict` и заметка.
6. Новые файлы картинок **не** увеличивают precache неожиданно: `public/words/*.webp`
   покрыты globPatterns — просто становятся частью офлайна.

## 9. Риски и краевые случаи

| Риск | Как закрываем |
|---|---|
| Состав списка ≠ Баранов | сохраняем приложенное; факт расхождения фиксируем в §10 и в RELEASE; карточки не переделываем |
| Слов больше, чем уроков влезает по 6–8 | несколько уроков на тему; дробление по учебнику, а не по алфавиту |
| Слова с дефисами/ё/-ия после «е» вместо «ё» | правила письма как в §6.4 PROJECT-RULES; «е»/«ё» при письме засчитывается |
| Длинные слова (>12 букв) ломают карточку на 320 px | замер на карточке; при переливе — уменьшение кегля на этом классе (токен, не хардкод) |
| Термин невозможен в картинке («местоимение») | эмодзи по смыслу; картинку не форсируем (уровень C) |
| Пересечение с 4 классом массовое | `grades` дополняются, `id` не меняется, прогресс общий — ничего не дублируется |
| Ударения в терминологии Баранова спорные | сверка по словарю; снимок ударений — источник истины в приложении |
| Предложения с неподходящим падежом | `check-content.mjs` + вычитка; «на заводе»-граблей избегаем заранее |
| Прогресс детей при выходе 5 класса | без миграций: `normalizeProfile` не меняется, новые профили могут выбрать 5 |
