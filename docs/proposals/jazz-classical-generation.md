# Предложение «джаз/классика офлайн»: конспект и решения

Пользователь передал внешний документ «Генерация джазовой и классической музыки
офлайн на телефоне» (три подхода: алгоритм, сэмплер, ML). Полный текст в чате
16.10.2026; здесь — конспект и решения по каждому блоку. Точка возврата до
внедрения: тег `snap/standards-v1` (коммит `0add9ab`).

## Подход 1 — алгоритмический: ПРИНЯТ частично

| Блок документа | Решение |
| --- | --- |
| `SCALES` (dorian/mixolydian/lydian/altered/wholetone/diminished/bebop/blues) | взяты dorian/mixolydian/major/bebop/blues для импровиза над `changes` |
| `CHORD_TYPES` (maj7…dom13, sus) | взяты расширенные состава для M/m/7 с 9-й ступенью как краской |
| Прогрессии ii-V-I, I-vi-ii-V, blues-12, coltrane, pachelbel, baroque-circle | ii-V-I и pachelbel вынесены в лабораторные грувы (`beboplab`, `baroquelab`); блюз-12 уже в каталоге; coltrane отклонён как слишком плотный для детского фона |
| Генератор джазовой мелодии (chord tones на доле, approach/enclosure, swing-offset, grace/bend) | внедрён как импровиз-хорус на нечётных кругах (seeded, детерминированно) |
| Генератор классической мелодии (контур arch/wave, квантизация в лад, барочные мелизмы, рубато) | внедрён `improvStyle: 'classical'` для лабораторного барокко |
| Ритм-секция: ride с триольной «пропуской» 0.67, brushes, bossaNova, компинг-бомбы | внедрены тембры ride/brush/crossstick и паттерны `jazzKit: 'swing' | 'bossa'` |
| Walking bass с approach ±1 и passing-тонами | апгрейд шагающего баса дуэта |
| Компинг: voicing с переносом голоса, ритмы Чарльстона | босса получила синкопированные подклады; помпе оставлен ровным (идиома) |
| Синтезатор: аддитивное фортепиано 8 гармоник с детуном | отклонено: наш PeriodicWave-рояль дешевле по CPU на телефоне; детун ансамбля уже есть у струнных |

## Подход 2 — сэмплерный: ОТКЛОНЁН

Правило каталога (стоит с волны 1 и подтверждено пользователем): **только
оригинальный синтез кодом, без внешних аудиофайлов**. Сэмпл-паки (даже CC0)
ломают офлайн-бюджет PWA (5–10 МБ), юридическую чистоту детского магазина и
единый движок «лаборатория = приложение». Возврат возможен только отдельным
решением пользователя с изменением правила каталога.

## Подход 3 — ML (ONNX Runtime Web): ОТКЛОНЁН сейчас

Обучение мелодической модели требует корпуса чужих транскрипций (права),
весов > 1 МБ и недетерминированна между устройствами — против наших проверок
(`test:demo`, адаптивные тесты слышат конкретный луп). Кандидат на отдалённое
будущее: крошечная марковская/transformer-модель над нашими же PD-темами,
обученная на синтетических данных.

## Фаза внедрения (эта сессия)

1. Теория и прогрессии → `changes` ведут весь ансамбль (уже с `standards-v1`).
2. Ride/brush/crossstick + jazzKit swing/bossa.
3. Импровиз-хорус над changes (head → improv → head).
4. Лабораторные грувы beboplab/baroquelab как витрина подхода 1.
5. Гейты, снимок-коммит, пуш.
