# Четыре игры витрины: «Колесо букв», «Хитрая буква», «Цветок слова», «Слоговая мозаика»

Черновик UX до кода (правило №8 `PLAN.md`). Владелец 2026-11-13 поручил
выполнить очередь плана: **0.103.0** → **0.104.0** → **0.105.0** → **0.106.0**
(план — [`games-development.md`](./games-development.md) §11,
[`games-catalog-detail.md`](./games-catalog-detail.md) §7).

Документ описывает **что именно увидит ребёнок** в каждой из четырёх игр и
какие правила рамки они соблюдают. Это не техническое задание на файлы —
файлы названы только там, где важно не сломать существующее.

---

## 0. Общее для всех четырёх

**Рамка «Игры» не меняется.** Игры не пишут в SRS, дают малый XP с суточным
потолком, закрытое слово идёт в задания дня половинным весом
(`engine/game-awards.ts`). Ничего не сгорает, ошибка ничего не отнимает,
таймеров нет, БУКа вне урока нет (решение владельца «пока не надо»).

**Один экран, без новых маршрутов.** Каждая игра — ещё одна карточка в
существующей витрине и ещё одна сцена внутри `games-stage`. Никаких новых
вкладок, экранов и «хабов».

**Порядок в витрине = порядок открытия.** `GAMES` в
`src/ui/screens/GamesScreen.tsx` — это и есть шкала доступа: индекс 0 открыт
всегда, дальше по ключам. Новые игры встают так:

| # | Игра | Группа | Ключей нужно | Версия |
|---|---|---|---|---|
| 0 | 🧵 Собери слово | ⚡ Быстро | 0 (всегда) | 0.96.0 |
| 1 | 🎡 Колесо букв | ⚡ Быстро | 1 | **0.103.0** |
| 2 | 🔎 Филворд | 🧠 Подумать | 1 | 0.96.0 |
| 3 | ✏️ Кроссворд | 🧠 Подумать | 2 | 0.96.0 |
| 4 | 🧠 Мемори | 🧠 Подумать | 3 | 0.101.0 |
| 5 | 🪄 Хитрая буква | 🧠 Подумать | 3 | **0.103.0** |
| 6 | 🌸 Цветок слова | 🧠 Подумать | 3 | **0.105.0** |
| 7 | 🧩 Слоговая мозаика | 🧵? → ⚡ Быстро | 1 | **0.106.0** |

### 0.1. Почему шкала доступа — не «ещё три ключа»

Сейчас `GAME_GATE_KEYS = [0, 1, 2, 3]` читается как «3 ключа = 4 игры».
Если добавлять по ключу на игру, к 0.106.0 понадобилось бы 7 ключей, а в дне
их максимум 3 — то есть последние игры не открылись бы **никогда**. Это
прямое нарушение правила «игры открываются, а не копятся недостижимыми».

Решение (рекомендация из `games-catalog-detail.md` §7, подтверждается здесь):
порог остаётся лестницей из трёх шагов, а игры **добираются внутрь шагов**.

```
ключей: 0        1              2           3
игр:    1        3              4           7
        Собери   + Колесо       + Кроссворд + Мемори
        слово      Филворд                   Хитрая буква
                                              Цветок
                                              Мозаика
```

Формула шкалы не меняется — «3 ключа открывают всё» остаётся правдой, и
фраза владельца «3 ключа = 4 игры» превращается в «3 ключа = все игры».

Проверка текстов: `nextHint` («Открыто 2 игры · ещё одна за урок») и
`lockHint` («Откроется за урок») продолжают работать без правок, потому что
они говорят про **шаг**, а не про игру.

### 0.2. Вёрстка: где живёт восьмая карточка

Правило витрины — карточки 2×2 внутри группы. Восемь игр на 360 px — это
4 ряда карточек, они не помещаются над полем игры.

Поэтому: **группы остаются две, но карточка показывает не все игры группы, а
только «полку» до 4 карточек с горизонтальной прокруткой**, если игр в группе
больше четырёх. Полка — тот же приём, что лента слов в «Собери слово»
(одна строка, палец ведёт вбок), и он уже проверен на 360 px.

Раскладка по группам после 0.106.0:

* **⚡ Быстро** (1–2 минуты): Собери слово, Колесо букв, Слоговая мозаика.
* **🧠 Подумать** (3–5 минут): Филворд, Кроссворд, Мемори, Хитрая буква,
  Цветок слова.

Пять карточек в «Подумать» — это 2×2 плюс одна во второй строке; на 360 px
пятая карточка уходит в горизонтальную прокрутку полки, а не ломает сетку.
Альтернатива — третья группа — отклонена: три подписи в ряд на 360 px уже
проверялись и читаются хуже (§4 плана).

## 1. 🎡 «Колесо букв» (0.103.0, для 1–2 класса)

**Простым языком.** Буквы слова стоят по кругу. Ребёнок ведёт пальцем по
кругу по порядку букв — и слово собирается само. Как будто обводишь слово
пальцем.

### 1.1. Что на экране

```
        ┌──────────────────────────┐
        │  Собери слово по кругу   │
        │         о                │
        │    к         р           │
        │   (  •  •  •  •  )       │  ← 4 точки-буквы уже пройдены
        │    а         о           │
        │         ш                │
        │   «корова» — 6 букв      │
        └──────────────────────────┘
```

* Круг: буквы слова по окружности, по часовой стрелке, начиная сверху.
  Порядок букв **не совпадает** с порядком в слове — иначе игра сводилась бы
  к «прочитай по кругу». Буквы расставлены по кругу в правильной
  последовательности, но ребёнок должен вести по ним подряд.
* Пройденные буквы подсвечиваются (`--primary-soft`), под кругом
  выкладывается собранная часть слова — так видно прогресс и ошибку.
* Наверху — образ слова: картинка 64 px + `hint` (как в «Собери слово»,
  тот же компонент `WordArt`).

### 1.2. Как играть

1. Палец касается любой буквы. Если это **первая** буква слова — она
   загорается; если нет — мягкий `sfx.tap()`, касание ничего не ломает.
2. Ведём палец к следующей букве — она загорается. Отпустить палец можно в
   любой момент: прогресс сохраняется, продолжить можно с той же буквы.
3. Собрано всё слово — «Слово собрано!», `sfx.correct()`, `haptic.correct()`,
   один раз конфетти (если система не просит «меньше движения»).
4. Тап работает как полная замена ведению: тап по букве = шаг. Это не
   «режим для слабых», это доступность — так же сделано в филворде
   (клавиатура и тап там равноправны).

### 1.3. Чего в игре нет

* Нет таймера, нет «попыток», нет проигрыша. Ошибка = «эта буква не
  следующая», и мы просто не двигаемся.
* Нет штрафа за подсказку: подсказка ставит следующую букву, слово
  засчитывается как обычно.

### 1.4. Данные и класс

`text` — без картинок и эмодзи, поэтому игра технически работает в любом
классе. Но круг читается только на коротких словах: **1–2 класс** (≤ 8 букв).
Для 3–5 классов карточка остаётся открытой, но в подписи честно: «круг из
10+ букв читать тяжело — попробуй «Хитрую букву»». Слова длиннее 8 букв в
пул колеса не попадают.

### 1.5. Награда

Одно собранное слово = `playGame(1)`, как в «Собери слово».

### 1.6. Файлы

`engine/ring.ts` (чистая логика: раскладка по кругу, шаг, проверка «следующая
буква»), `ui/LetterRingGame.tsx`, стили `.ring-*`.

## 2. 🪄 «Хитрая буква» (0.103.0)

**Простым языком.** В слове спрятана одна «хитрая» буква — та, в которой
чаще всего ошибаются. Нужно выбрать её из четырёх вариантов. Ошибся — не
наказание, а подсказка: сначала картинка и значение, потом мнемоника, потом
слово откроется целиком.

Это замена Wordle и виселицы из комплекта — без словаря и без «попыток».

### 2.1. Что на экране

```
┌────────────────────────────────────────┐
│  Выбери хитрую букву                   │
│                                        │
│      к _ р о в а                       │  ← буква закрыта (danger)
│      🐄 «домашнее животное, даёт молоко»│
│                                        │
│      [ а ]  [ о ]  [ ы ]  [ у ]        │  ← 4 варианта
│                                        │
│  Верных: 3 из 6   •  💡 Подсказка       │
└────────────────────────────────────────┘
```

* Слово показано с **одной** закрытой буквой — это буква из `danger`
  (та же, что в задании `gap`/`fix` урока, выбирает её `pickDanger` из
  `engine/scheduler.ts`).
* Под словом — эмодзи и `hint`. Это не подсказка ответа: значение слова
  ребёнок и так узнаёт в каждом задании.

### 2.2. Лестница подсказок при ошибке

Ровно то, что было в плане (§6-E), и не больше:

| Ошибка | Что появляется |
|---|---|
| 1-я | `mnemonic`, если у слова есть (24 карточки 1–2 класса) — иначе сразу следующая ступень |
| 2-я | предложение с пропуском (`sentence`), с уже открытой опасной буквой |
| 3-я | буква открывается, слово читается целиком, строка «Запомни: кОрова» |
| дальше | выбор продолжается с **оставшимися** буквами — попытки не кончаются |

Ошибки не отнимают ни доступ, ни награду: слово засчитывается всегда, просто
«с подсказкой». Никакого «проигрыша» и «сердечек».

### 2.3. Варианты букв

4 варианта: верная + 3 «соседки» из `CONFUSE` (о↔а, е↔и↔я, д↔т …) — те же
типичные детские ошибки, что в задании «Исправь робота». Если соседок не
хватает, добираем буквами того же типа (гласные/согласные). Варианты **не
подсказывают** ответ формой слова: они не «вырезаны» из него и стоят в
случайном порядке.

### 2.4. Прогресс и победа

Серия из 6 слов — полный «раунд»:

* счётчик «Верных: 3 из 6»;
* после 6-го слова — плашка победы с наградой `playGame(6)`, `sfx.finish`,
  конфетти, кнопка «Ещё шесть»;
* «Новое слово» доступно всегда — можно уйти с середины, ничего не сгорает.

### 2.5. Данные и класс

`danger`, `hint`, `mnemonic`, `sentence` — есть у 367 карточек; мнемоника
только у части (ступень опциональна). Слова с `danger.length === 0` не
попадают в пул (у них нет «хитрой» буквы). Фразы (пробел) не попадают.

### 2.6. Файлы

`engine/tricky-letter.ts`, `ui/TrickyLetterGame.tsx`, стили `.tl-*`.

## 3. 🌸 «Цветок слова» (0.105.0)

**Простым языком.** Слово открывается по одной букве, как распускается
цветок: стебель — слово, лепестки — его буквы. На каждом шаге снизу четыре
карточки-буквы, одна из них следующая.

Это переделка «виселицы» из каталога: **цветок не умирает**, попытки не
кончаются.

### 3.1. Что на экране

```
┌────────────────────────────────────────┐
│   🌸                                   │
│   ( ▪ ▪ ▪ ▪ ▪ ▪ )   ← лепестки-буквы  │
│   р  о  м  _  ш  к  а                  │  ← открытые буквы
│                                        │
│   «растение с колючими листьями»       │
│                                        │
│   [ ш ]  [ ж ]  [ с ]  [ щ ]           │
└────────────────────────────────────────┘
```

* Лепестки по числу букв: открытый лепесток — акцентный, закрытый —
  нейтральный. Это не таймер и не «жизни», а просто состояние буквы.
* Буквы открываются **слева направо**: ребёнок каждый раз видит, какая буква
  следующая, — это ближе к чтению, чем к сборке целого слова.

### 3.2. Ошибка

Неверная буква красит лепесток в `--orange-soft`, звучит `sfx.wrong()`, а
строка подсказки **сразу** становится подробнее (эмодзи → `hint` → часть
`sentence` с пропуском). Выбор продолжается с оставшимися карточками: буква
не «теряется» и попытки не кончаются.

### 3.3. Победа

Слово открыто целиком — «Цветок распустился!», `sfx.finish()`, конфетти,
`playGame(1)`, кнопка «Новое слово».

### 3.4. Данные и класс

`text`, `hint`, `emoji`, `sentence` — у всех; картинка 1–4 классов — как
дополнительная подсказка. Фразы (пробел) не попадают. Класс любой.

### 3.5. Файлы

`engine/word-flower.ts`, `ui/WordFlowerGame.tsx`, стили `.flower-*`.

## 4. 🧩 «Слоговая мозаика» (0.106.0)

**Простым языком.** Слово разрезано на слоги, слоги перемешаны. Ребёнок
выкладывает слово из слогов-плиток: «мо-ло-ко».

Отличие от «Собери слово»: там единица — буква, здесь — **слог**. Поэтому в
игру попадают длинные слова (до 17 букв), которые в буквальных играх
нечитаемы, и она тренирует слоговое чтение и перенос.

### 4.1. Что на экране

```
┌────────────────────────────────────────┐
│  Выложи слово из слогов                │
│                                        │
│   [ мо ] [ ло ] [ ко ]                 │  ← слоты (пустые рамки)
│                                        │
│   🥛 «белая жидкость от коровы»        │
│                                        │
│   [ ко ]  [ мо ]  [ ло ]               │  ← плитки-слоги
└────────────────────────────────────────┘
```

* Слоги берутся из `syllables` (есть у всех 367 карточек, 354 — из 2+ слогов).
* Плитки шире букв (слог = 2–3 буквы), поэтому сетка своя, а не `word-board`.
* Тап по плитке ставит слог в первый пустой слот, тап по слоту — возвращает.
  Ошибка в порядке = слоты мягко краснеют и возвращаются в лоток (как в
  «Собери слово»), ничего не сгорает.
* Слова из **одного** слога в пул не попадают: там нечего перемешивать.

### 4.2. Победа

«Слово собрано!», `playGame(1)`, кнопка «Другое слово» — ровно как в
«Собери слово», чтобы два похожих экрана не учили ребёнка двум разным
правилам.

### 4.3. Чем не дублирует урок

В уроке задание `syllables` — «сколько слогов в слове», ответ числом. Здесь
ребёнок **выкладывает** слово слогами. Разные действия, разный результат;
проверка на телефоне должна подтвердить, что ребёнок не путает.

### 4.4. Файлы

`engine/syllable-board.ts`, `ui/SyllableBoard.tsx`, стили `.syl-*`.

| Место | Что меняется | Версия |
|---|---|---|

значит менять смысл уже показанной цифры.

## 6. Проверки (что будет в тестах)

Для каждой игры — движок отдельным тестом и один сценарий в смоуке:

* «Колесо букв»: круг содержит ровно буквы слова; шаг принимает только
  следующую букву; тап-путь равен путь-ведению; слово длиннее 8 букв в пул
  не попадает.
* «Хитрая буква»: опасная буква всегда есть в вариантах; 3 ошибки открывают
  слово, но не блокируют выбор; мнемоника подставляется только если есть;
  слова без `danger` в пул не попадают.
* «Цветок слова»: следующая буква одна; неверная не отнимает попытку;
  ошибочная буква остаётся доступной; победа = все буквы открыты.
* «Слоговая мозаика»: слоги собираются ровно в `text`; односложные слова
  отсеиваются; порядок слогов проверяется.
* Общие: шкала доступа при 7 играх открывает **все** на 3 ключах; пустой
  день по-прежнему оставляет ровно одну игру.

## 7. Стоп-лист (не делаем даже «раз это игра»)

* Таймеры, «успей», жизни, сердечки, «проиграл» — ни в одной из четырёх.
* Озвучка и аудиофайлы; звук — только синтез `platform/sound.ts`.
* БУК, реакции БУКа вне урока — «пока не надо».
* Новые валюты, лутбоксы, ежедневные награды за игру.
* Внешние шрифты и картинки; офлайн-работа без сети.
* Шестая и последующая игра без отдельного решения по витрине (§0.2).
