# 0.82.0 — фотополка телефонов: снимки вместо 3D-спинок

Третья партия фотореализма подряд. После машин дошла очередь до электроники:
семь телефонов пересняты в студии, всего в магазине 64 снимка.

## Что изменилось

- **Семь телефонов — фотографии.** «iPhone Air», 17, 17 Pro Max, 17 Pro, 18,
  18 Air и 18 Pro показаны как настоящие аппараты на глянцевом полу: матовое
  стекло, полированные грани, реальные блики, объективы в блоке камер.
  Цвета прежние — серебро, лаванда, оранжевый, синий и бордовая линейка.
- **Три пересъёмки после приёмки.** У «Розовой звезды» на капот наконец легла
  звезда, с брони «Розового танка» убраны надписи (никаких опознаваемых
  markings в товарных кадрах), у «Лунохода» три колеса на борт.
- **Телефон в кадре крупно.** Вытянутый аппарат в широком кадре занимал
  десятую часть ширины, и в карточке от него оставалась былинка. Поэтому
  сборщик сначала берёт у телефонов центральную полосу кадра, а уже потом
  раскладывает её на 4:3.
- **Шов между снимком и продолженной студией убран.** Резкий кадр теперь
  растворяется в размытом заднике по краям, иначе на карточке была видна
  вертикальная линейка — «склейка из двух картинок».

## Тексты

- У переснятых телефонов из описаний убраны обещания повернуть: кадр один,
  крутить нечего. Поворот остался только у «iPhone 18 Pro Max» — последней
  модели с 3D-артом.

## Проверки

- `tests/electronics-art.test.tsx`: модели со снимком проверяются как фото
  (`img.product-photo` и `products/<id>.webp`), остальные — как 3D-арт;
  вращение проверяется на модели, которую ещё не пересняли.
- `tests/smoke.test.tsx`: полка электроники считается как «арт + фото = 11»,
  а обещание поворота больше не висит над снимком.
- `npm run typecheck`, `npm run build`, `npm run test:smoke`, `test:boot`,
  `test:guard`, `test:contrast`, `test:release` — зелёные.

## Дальше

Осталось три позиции электроники: «iPhone 18 Pro Max» (последний с 3D-артом
и поворотом), «Домашний кинотеатр» и «Серебряный Max». После них поворот
телефонов уходит из кода совсем, а фотореализм закрывается целиком.
