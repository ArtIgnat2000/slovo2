# 0.85.2 — техника в трёх кадрах

Телефоны, корабли и самолёты в подробной карточке теперь раскрываются в три
кадра: товар на витрине, другой ракурс или иллюстрация, затем сцена-мечта.
Самолёт пролетает над облаками, корабль идёт по морю, а телефон показывает
космический экран. Переход — тапом по кадру; движения мягкие и отключаются при
системном запросе уменьшить анимацию.

Первый этап охватывает 19 моделей. Для «Титаника» добавлена отдельная схема,
чтобы и у него был собственный второй кадр. Рекомендации по количеству кадров и
дальнейшему распространению галерей описаны в
[`docs/proposals/product-galleries.md`](./proposals/product-galleries.md).

## Проверки

`npm run test:adaptive`, `npm run test:smoke`, `npm run build`,
