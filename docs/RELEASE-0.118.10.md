# 0.118.10 — Синхронизация документов с продом

Служебный релиз: документация приведена в соответствие с `main` после
0.118.9 (PR #233). Игровой код, контент, хранилище и сборка PWA не меняются.

## Что изменилось

* `docs/HANDOFF.md` — шапка пересобрана (путь 0.108.0 → 0.118.9); раздел
  «Состояние проекта» актуализирован (0.118.9, ветка сессии, 367 карточек /
  71 урок / 257 картинок, «Тропа слов» как отдельный вход над витриной,
  у 5 класса 0 из 110 собственных слов); «Что изменилось с прошлой
  передачи» дополнен блоками 0.98.0–0.109.2 и 0.110.0–0.118.9; «Открытая
  очередь» — на 2026-11-18 (закрыты очередь игр 0.104.0–0.106.0 и арт-аудит
  1–4; добавлен п. 10 «Загрузка списка слов 2 класса»); «Следующий шаг»
  переписан (принятой задачи нет, перечислены живые вопросы); актуализированы
  «Рабочая ветка» и «Ориентиры».
* `docs/PLAN.md` — шапка на 0.118.10; «Открытая очередь 2026-10-22» помечена
  как историческая; добавлена «Точка передачи 2026-11-18»; журнал — часть 149.
* `docs/next-chat-prompt.md` — полностью переписан под состояние 0.118.10.
* `README.md` — «План развития» дополнен вехами 0.112.0–0.118.9 («Тропа
  слов» и вся программа, пять биомов и 16 открыток, арт-волна 2 класса,
  последовательный урок, картинки без паспарту, Android-компоновки);
  «Полный каталог 20 игр» отмечен выполненным.
* Версия повышена до **0.118.10** (`package.json`, `package-lock.json`).

## Проверки

* `npm run typecheck`
* `npm run content:check`
* `npm run test:release`
* `PR_TITLE="v0.118.10 — Синхронизация документов с продом" npm run release:check -- origin/main`
* `npm run build`, `npm run test:boot`

Код не менялся, поэтому полный контур (smoke, audit:storage) прогоняется
для страховки; изменения касаются только `docs/` и `README.md`.
