# 0.59.0 — школьный список одной кнопкой

«Руками я ничего вставлять не буду» — принято. Список из школы теперь живёт
в приложении как **готовый**: его добавляют одним нажатием, без копирования
текста.

## Как теперь добавить ваш список

1. **Родителям** (нижнее меню) → решить пример-замок;
2. в «Обзоре» первая карточка — **«Списки к контрольной»**, в ней кнопка
   **«＋ Добавить готовый список (26 слов)»** ← одно нажатие, всё;
3. **Уроки** → над «Заданиями дня» появилась карточка
   **«🏫 Контрольная: слова из школы · 26 слов»** → «Тренировать».

Ничего вставлять, копировать и набирать не нужно. Внутри «Списков» та же
кнопка лежит отдельным блоком: **«＋ Добавить: список из класса · 26 слов»**.
Когда список уже добавлен, кнопка честно пишет «✓ Список уже добавлен».

## Что внутри пресета

Тот самый список, 26 слов в том же порядке, как в сообщении учителя:
хорошо, ученик, ученица, учитель, петух, заяц, воробей, ворона, весело,
спасибо, прощай, прощайте, город, родина, ветер, скоро, быстро, подлежащее,
сказуемое, яблоко, яблоня, берёза, лопата, ягода, осина, до свидания.

* **23 слова** берутся из банка — с картинкой, предложением и мнемоникой;
* **3 своих** (прощайте, подлежащее, сказуемое) приложение создаёт само:
  слоги `под-ле-жа-ще-е`, ударение, «опасные» буквы;
* пресет разбирается **тем же кодом**, что и вставка из чата, — поэтому он
  не может «разъехаться» с обычным списком, и ударение у своих слов потом
  правится в «Списках» одним тапом.

## Что ещё добавили для будущих списков

В форме своего списка появилась кнопка **«Вставить из буфера обмена»**:
скопировали сообщение из чата класса → одно нажатие. Если браузер не даёт
прочитать буфер, приложение честно говорит об этом и предлагает обычную
вставку, а не молчит.

## Как будет со следующими школьными списками

Вы присылаете текст — я добавляю его в `src/content/preset-lists.ts`
новым элементом массива (и версия релиза). Дальше он появляется у вас
кнопкой «Добавить: …» без вставки. Это дешевле, чем каждый раз просить
родителя копировать список, и не ломает правило «списки создаёт родитель».

## Проверки

Семь новых проверок в смоуке (по спискам теперь **46**):

* пресет существует и содержит ровно 26 слов;
* разбор даёт 23 из банка и 3 своих — тот же результат, что у вставки текста;
* у своих слов рабочие карточки (слоги, ударение, опасные буквы);
* в «Списках» есть кнопка добавления без вставки текста;
* **одно нажатие реально добавляет список из 26 слов** (проверяем настоящий
  клик по кнопке и состояние профиля);
* свои слова появляются в профиле;
* после добавления кнопка становится «✓ уже добавлен».

Полный контур: `typecheck`, `test:smoke`, `test:guard`, `test:icons`,
`test:content`, `test:adaptive`, `audit:storage`, `demo:check`,
`content:check`, `images:report -- --strict` (257/257),
`release:check` (0.58.1 → 0.59.0), `build`, `test:boot` — зелёные.

## Если карточки всё равно нет

`?diag=1` → «Скопировать сводку» → строка «Списки к контрольной: 1 · своих
слов: 3». Если там «нет» — список не добавился (нажатие не дошло), если
«1 · своих слов: 3», а карточки на «Уроках» нет — это уже ошибка
отображения, и по строке видно, что чинить.
