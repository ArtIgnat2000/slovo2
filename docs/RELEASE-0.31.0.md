# 0.31.0 — «Класс пройден» и полировка

Финальная полировка после 4 класса: программа 1–4 классов уже полная, поэтому
этот релиз про то, чтобы ребёнок видел финиш класса, родитель — весь путь, а
слова без картинок не выглядели недоделанными.

## Что добавилось

### Класс пройден — и сразу дальше

Класс считается пройденным, когда **все уроки его программы закрыты до 5 уровня**
(пять корон на «Моём пути»). Правило живёт в одном месте —
`src/engine/classes.ts` (`classProgress`, `classComplete`, `nextClass`), — и его
используют все экраны.

* **Экран результатов последнего урока.** Раньше после финального урока класса
  была только кнопка «К урокам 🗺️». Теперь появляется карточка **«N класс
  пройден!»**: сколько уроков позади и сколько слов освоено, кнопка
  «Дальше — N+1 класс» (профиль переключается сразу, прогресс, кристаллы и
  покупки остаются) и подпись «Опыт, кристаллы и покупки остаются с тобой».
  Для 4 класса — «Вся программа позади — к урокам 🗺️».
* **Карточка появляется ровно один раз** — тем уроком, который закрыл класс.
  Условие считается переходом «было → стало»: если просто открыть результаты
  уже пройденного класса, карточки не будет.
* **Герой на главной** больше не пишет «дальше 2 класс» мелким шрифтом: кнопка
  сразу называется «2 класс ▶», а метрика показывает «N уроков позади · X из Y
  слов освоено».
* **Лист «Какой класс учим?»**: пройденный класс помечен «✓ пройден · все N
  уроков», у остальных — «пройдено X из N · слов освоено M». Если активный класс
  пройден, внизу листа есть подсказка о переходе дальше.

### Таблица классов в «Родителям → Обзор»

Под карточкой слов — блок **«Классы 1–4»**: одна строка на класс с полоской
освоения, «X / Y слов», процентом и «N из M уроков». Текущий класс подсвечен,
пройденные помечены «✓ пройден». Родитель видит весь путь, не переключая
программу ребёнка. Проценты считаются по словам класса (`s ≥ 90`), а «пройден» —
по урокам: это разные вещи, и подпись в карточке это объясняет.

### Тексты «1–4 класс»

`share.ts` и манифест уже говорили «1–4 класс». Приведён в порядок README:
секция «Картинки к словам» больше не обещает картинки у всех слов и не
дублирует абзац; добавлен раздел про «класс пройден» и переход дальше.

### Картинки: решение по 163 словам

Картинки есть у 94 слов 2 класса. У 28 слов 1 класса — 2 без картинки, у 3 и
4 классов — по одному слову. Остальные **163 карточки** живут на эмодзи.

Решение 0.31.0 — **гибрид очередями**, а не «нарисовать всё сразу»:

* эмодзи-карточка доведена до аккуратного вида: крупнее (0,54 плиты) и с мягкой
  тенью, на той же плите и рамке, что и рисунки, — пустых рамок нет;
* покрытие измеряется, а не обсуждается: `npm run images:report` печатает
  таблицу по классам и вес файлов, `--strict` падает, если у класса остались
  слова без картинки;
* порядок следующих партий и критерии приёмки — в
  [`docs/proposals/word-images-1-4.md`](./proposals/word-images-1-4.md).
