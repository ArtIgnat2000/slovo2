# 0.96.5 — Игры: слова наконец меняются (и на маленьком пуле тоже)

Третье замечание владельца подряд: «Слова так и не меняется. Постоянно
телефон. И в кроссворде тоже слова не меняются». Две предыдущие попытки
(0.96.3, 0.96.4) правили выбор слов в движке — и не помогли, потому что
причина была не в движке.

## Что было на самом деле

**1. Пул «Игр» состоял только из встреченных слов.** У ребёнка в начале пути
их три: `беседа`, `телефон`, `человек` — ровно те, что на скриншотах. Из трёх
слов нельзя показать «другие слова»: сколько ни перемешивай, набор тот же.
Любая ротация на таком пуле бессмысленна, а кроссворд вообще строился из
всех трёх.

**2. Выбор слов был эвристикой.** «Передай слова прошлой сетки — движок
возьмёт другие» не работает, когда игр две: обе берут слова из одного пула, и
как только «Кроссворд» отодвигает свои, «Филворд» начинает с начала. Плюс
курсор, который двигался по полному пулу, тогда как движок крутит только
пригодные для поля слова: шаги расходились, и одна и та же порция
возвращалась снова.

## Что сделано

- **Добор пула для сеточных игр.** «Филворд» и «Кроссворд» берут слова
  класса, если знакомых меньше `GAMES_MIN_POOL = 12`: сперва все встреченные,
  потом слова своей программы (это те, что скоро встретятся в уроках).
  «Собери слово» по-прежнему работает только со встреченными словами — там
  это принципиально.
- **Выбор слов — курсор по кругу, а не эвристика** (`engine/pool-cursor.ts`):
  - пул один раз перемешивается стабильно (порядок зависит от самих слов, а
    не от `seed`), поэтому круг одинаков во всех сетках и после перезагрузки;
  - сетка берёт первые N слов круга, курсор сдвигается ровно на N;
  - `nextCursor` считает сам движок — по той выборке, из которой брал слова
    (длинные «телепередача» и «библиотекарь» отсеиваются по длине), так что
    шаги больше не расходятся;
  - слово возвращается только после полного обхода пула.
- **«Лестница» кроссворда** больше не добирает слова сверх лимита, а
  `nextCursor` учитывает и те слова, что не легли в сетку.
- **Обе игры сбрасываются при смене пула** (`key` по длине пула): когда
  ребёнок проходит урок, игра начинается с первой сетки нового пула.

Побочный эффект на большом пуле: две соседние сетки вообще не пересекаются
словами, а одна и та же сетка не может повториться один в один.

## Проверки

`npm run typecheck`, `npm run test:smoke`, `npm run build`, `npm run test:boot`,
`npm run test:contrast`, `npm run release:check`.

Новые проверки:
- «Собери слово» показывает только встреченные слова, а филворд и кроссворд
  при **трёх** встреченных словах всё равно меняют набор (живой UI, ровно
  сценарий со скриншота);
- три нажатия «Ещё сетку» / «Ещё кроссворд» подряд дают четыре разных набора
  (ловим «залипшие» слова);
- на пулах 6/8/12/30 слов новая сетка не повторяет слова прошлой, а за 8
  сеток показывается почти весь пул;
- `nextCursor` действительно ведёт вперёд: два шага подряд — разные наборы.

## Дальше

  об этом.
- Приоритет словам с ошибками (`profile.words[id].wrong`) вместо ровного круга.
