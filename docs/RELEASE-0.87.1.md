# 0.87.1 — добровольная поддержка разработчика (релиз PR #158)

## Почему этот релиз

PR #158 «Добавить добровольную поддержку разработчика» был слит в `main`
без повышения версии: его `Release checks` упали на шаге «Require a new
release for every PR» (`Каждый PR должен увеличивать версию: main 0.86.3,
PR 0.86.3`), а релизная заметка и заголовок вида «vX.Y.Z — …» отсутствовали.
Сама фича в `main` исправна (деплой прошёл), но правило «каждый PR —
релиз» осталось невыполненным. Эта версия закрывает процесс.

Версия **0.87.1**, а не 0.87.0: 0.87.0 уже занята открытым PR #159
(«чат „Спроси БУКа“»), и идемпотентное у числений не должно пересекаться.

## Что изменилось

- Раздел «Поддержать разработчика» на экране для родителей (PR #158):
  сворачиваемый блок с сердцем, QR-кодом `public/images/support-qr.png`
  и ссылкой на реквизиты Сбера (`src/ui/SupportDeveloper.tsx`).
- Перевод добровольный: приложение не обрабатывает платёж самостоятельно,
  сумма и получатель проверяются пользователем перед переводом.
- `package.json` и `package-lock.json` (включая `packages[""]`) подняты
  с 0.86.3 до 0.87.1, добавлена эта заметка — `release:check` снова
  проходит для состояния `main`.

## Проверки

На слитом состоянии `main` (после #158) полный контур CI зелёный:
`audio:check`, `typecheck`, `content:check`, `test:content`,
`test:adaptive`, `server:test`, `test:smoke`, `test:guard`, `test:icons`,
`test:contrast`, `build`, `test:boot`.
Релизный чек: `main 0.86.3 → 0.87.1`, lock и заметка согласованы,
заголовок PR в формате «v0.87.1 — …».
