# 0.75.0 — «Мой мир»: карта полной коллекции

**Согласовано:** «Мой мир» — это всё, чем владеет ученик, а не сцена, которую нужно строить или заполнять. Ангарная техника становится частью общей коллекции; название «Ангар» убрано из пользовательских входов.

## Что изменилось

- **Единая карта коллекции внутри БУКа.** Верхний переключатель БУКа теперь содержит «Витрина», «Мои покупки» и «Мой мир». Нижнее меню приложения не меняется.
- **Три уровня просмотра:** общая карта областей с миниатюрами всех предметов; увеличенная область; крупная карточка отдельной покупки.
- **В коллекции собраны** наряды и костюмы, техника, базы, музыкальные треки, звуковые наборы и оформления приложения. НААШ-идеи, которые не являются товарами, в личную коллекцию не попадают; купленная форма НААШ входит в «Образы». Составляющие наборов показываются как отдельные принадлежащие вещи, без дублирования карточкой набора.
- **Снимок для друзей.** Кнопка создаёт PNG текущего уровня просмотра: всей карты, области или отдельной вещи. Поддерживаемое системное меню позволяет отправить изображение; иначе файл сохраняется для отправки вручную. Имя профиля и публичная ссылка не добавляются.
- **Явный возврат «Назад в БУК».** Возвращает к исходному виду и полке магазина; текущая позиция прокрутки восстанавливается. Вход «Мой мир» добавлен и в меню главной.
- Технические покупки после приобретения сразу появляются на карте. Просмотр коллекции не зависит от старых трёх слотов сцены; сохранённые данные профилей не мигрируются и не удаляются.
