# 0.88.2 — первые пять пар фотосерии нарядов

## Что сделано

- Генератор изображений восстановился: сделаны полные пары для `crown`,
  `glasses-heart`, `choker` (приоритет 1) и `cap`, `bow` (приоритет 2).
- Каждая пара — самостоятельные кадры: главный вид и другой ракурс или
  полезная деталь. Короны — вид сзади-три четверти с замком и изнанкой;
  очков-сердечек — профиль с шарниром и дужкой; ленты — застёжка и изнанка
  бархата; кепки — регулировка и шов козырька; банта — узел и изнаночные
  сгибы. Увеличенных кропов нет.
- Файлы лежат в `public/products/<id>.webp` и
  `public/products/gallery/<id>-alt.webp`, собраны штатным
  `scripts/make-product-images.mjs`.
- На витрину фото **не подключены**: правило серии требует показывать фото
  только целиком, а не рядом с векторным артом.

## Как проверено

- `npm run test:galleries` — 12 проверок: пары полные, второй кадр не копия
  главного, размеры 1200×900, файлов без ссылки в `gallery/` нет.
- Пары просмотрены на контакт-листах: свет, задник, масштаб и материалы
  совпадают, ракурсы разные.
- `npm run typecheck`, `npm run build`.

## Ограничение

Сервис генерации отдаёт не больше 10 изображений за ход. Следующий заход:
`scarf`, `glasses`, `medal`, `grad`, затем `clips-stars`, `wreath`,
`hat-ribbon`.
