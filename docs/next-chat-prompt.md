## Грабли песочницы и тестов

- Vite заменяет `import.meta.env` целиком. В `scripts/smoke.mjs` и `scripts/prod-boot-check.mjs` задавать одним объектом `JSON.stringify({...})`, а не по ключам: иначе `Cannot read properties of undefined` (ловится test:boot).
- `test:qr` вне контура, разово `npm i --no-save qrcode jsqr`; не добавлять в package.json/рантайм (как resvg для промо).
- jsdom не имеет `navigator.share`/`navigator.clipboard`: `shareApp()`/`copyAppLink()` законно возвращают `'manual'`.
- React-ключи по миллисекундам могут совпадать — добавлять индекс (корзина профилей).
- QR-таблицы/формат сверены с эталоном; при правках проверять `test:qr` и снимок матрицы `tests/qr.test.ts`.
- Клон пересоздаётся на точке форка, история shallow, незапушенное и node_modules могут пропасть: первый шаг всегда `npm run pickup`.
- `artignat2000.github.io` из песочницы закрыт: проверять workflow/deployment через `gh` и локальный бандл, не заявлять проверку страницы.
- После merge платформа закрывает удалённые операции слитой ветки; продолжать в новой сессии, это не сетевая поломка.
