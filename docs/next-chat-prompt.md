## Открытые продуктовые вопросы и запреты

- **Недельные награды `+5/+10/+15 💎`** — временные, владелец их не
  утверждал. Без согласования не менять.
- **Родительский ПИН** отложен: не реализовывать, пока владелец не выберет
  сценарий (4 цифры с кодом восстановления или без; первичная настройка —
  взрослым).
- Не добавлять без отдельного согласования: озвучку и аудиофайлы, checkpoint
  (этап 3 размера урока), бросок БУКа с инерцией, подглядывание в уроке,
  реакции вне урока, резерв места на результатах, свободный числовой слайдер,
  жизни/сердечки, стресс-таймеры, публичные лидерборды, случайные и платные
  лутбоксы, узоры как вторую ось тюнинга.
- Не менять без отдельного релиза: контент 1–4 классов, `id` слов, модель
  профиля и правила смены класса (см. `PROJECT-RULES.md` §2).

## Проверки и правила PR

- Каждый PR в `main` повышает версию и добавляет `docs/RELEASE-<версия>.md`;
  заголовок — `v<версия> — краткое описание`; описание — по
  `.github/pull_request_template.md`.
- Перед PR: `test:release`, `PR_TITLE="vX.Y.Z — …" npm run release:check --
  origin/main`, `typecheck`, `content:check`, `test:content`, `test:adaptive`,
  `test:smoke`, `audit:storage`, `build`, `test:boot` (полный список —
  `docs/HANDOFF.md`, «Контур проверок»).
- Коммит, push, PR и слияние — только с разрешения пользователя. Рабочая
  ветка — та, что назначена сессии; PR открывается из неё в `main`.
