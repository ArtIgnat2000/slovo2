## Проверки и правила PR

- Каждый PR в `main` повышает версию и добавляет `docs/RELEASE-<версия>.md`;
  заголовок — `v<версия> — краткое описание`; описание — по
  `.github/pull_request_template.md`.
- Перед PR: `test:release`, `PR_TITLE="vX.Y.Z — …" npm run release:check --
  origin/main`, `typecheck`, `content:check`, `test:content`, `test:adaptive`,
  `test:smoke`, `audit:storage`, `build`, `test:boot` (полный список —
  `docs/HANDOFF.md`, «Контур проверок»).
- Коммит, push, PR и слияние — только с разрешения пользователя. Рабочая
  ветка — та, что назначена сессии; PR открывается из неё в `main`.
