## Открытые продуктовые вопросы и запреты

- **Недельные награды `+5/+10/+15 💎`** — временные, пользователь не
  утверждал. Единственный явно ожидающий решения денежный пункт; без
  согласования не менять.
- Родительский ПИН отложен пользователем. Не реализовывать, пока
  пользователь явно не выберет сценарий (4 цифры + код восстановления или
  без восстановления; первичная настройка — взрослым; локальный ПИН —
  бытовой барьер, а за гейтом лежит выгрузка прогресса).
- Не добавлять без согласования: озвучку/аудиофайлы, checkpoint (этап 3
  размера урока), бросок БУКа с инерцией, подглядывание в уроке, реакции
  вне урока, резерв места на результатах, свободный числовой слайдер,
  жизни/сердечки, стресс-таймеры, публичные лидерборды, случайные/платные
  лутбоксы, плату за базовый цвет, полку «Звуки» как товар.
- Большие UX-изменения сначала предлагать 2–4 вариантами с плюсами/минусами
  (решение 8 плана).
- Коммиты, push, слияние и публикация — только с разрешения. Каждый PR
  увеличивает версию (без исключения для docs), заголовок
  `v<версия> — …`, заметка `docs/RELEASE-<версия>.md`, версия согласована
  в `package.json`/`package-lock.json` (bump — `npm version <версия>
  --no-git-tag-version`; урок 0.15.1).

## Грабли

- Клон песочницы пересоздаётся на точке форка, история shallow,
  `node_modules` стираются: первый шаг всегда `npm run pickup`.
- Vite заменяет `import.meta.env` целиком — в смоуке/boot задавать одним
  объектом, иначе `test:boot` ловит пустой экран.
- `test:qr` вне контура: разово `npm i --no-save qrcode jsqr`; не добавлять
  в `package.json`/рантайм.
- Вычисленный CSS — не пиксели: Samsung Internet перекрашивает страницу без
  изменения `getComputedStyle`; живую проверку темы не заявлять без
  устройства. Прогресс ради проверки темы/браузера не удалять.
- `artignat2000.github.io` из песочницы закрыт: деплой проверять через `gh`
  (workflow/deployment) и локальный бандл.
- После merge платформа закрывает удалённые операции слитой ветки;
  продолжать в новой сессии — это не сетевая поломка.
