## Изменения (поверх 0.8.0)

Релиз целиком про **понятность и надёжность уже существующих экранов** — новых механик нет.
Основание: обратная связь детей и родителя (29.09.2026) плюс закрытие проверок этапа 2.

### 1. Задания дня: «Повтори N слов» было непонятным и невыполнимым

Что видел ребёнок: карточка задания, по нажатию ничего не происходит, отдельного блока для
выполнения нет, задание «висит» и блокирует сундук (он открывается по всем трём ключам).

Причины (воспроизведены на коде): карточка — `div` без обработчика; «Повтори N слов» у нового
профиля невыполнимо (повторять нечего); после удачного дня слова уходят по SRS на 1–2–4 дня
вперёд, и блок «Пора повторить» пропадал; прогресс считался по верным ответам (ошибся — счётчик
«замер»); главная и урок повторения считали слова по разным правилам.

Исправлено:
* у каждого незакрытого задания — подпись «где выполнять» и кнопка **«Начать ▸»** (повторение
  открывает режим 🔁, остальные — текущий урок);
* невыполнимое задание не выдаётся: меньше двух пройденных слов — вместо повторения другой вид
  дня; слов мало — цель опускается до их числа (2..5). План дня фиксируется в `profile.daily.plan`;
* прогресс считает **потренированные слова** (`DayStat.reviewWords`), ошибка его не «замораживает»;
* «Пора повторить» показывается всегда, когда есть что тренировать: сначала просроченные слова,
  затем самые слабые пройденные. Правило выбора одно на главную и урок (`pickReviewWords`),
  тексты честные: «N слов готовы забыться» против «Потренируем N слов — станут крепче».

### 2. «Понятно» в подсказке установки закрывает блок

Было: `markInstallHintShown()` писал флаг в `localStorage`, а блок рендерился по чтению того же
ключа во время рендера — React не знал об изменении, подсказка оставалась на экране до случайного
события. Теперь флаг живёт в состоянии и гасится мгновенно.

### 3. Показ в песочнице (для разработки, не для пользователей)

`npm run preview:build` собирает приложение с базой `/`, `npm run preview:show` раздаёт `preview/`.
Нужно, чтобы проверять правки в превью-прокси: прод-сборка собрана с базой `/slovo2/`, и её ассеты
по корневому адресу превью отдавались в 404 (белый экран).

### 4. Тесты (защита от повторения этих багов)

* `tests/quests.test.ts` + `tests/quests-ui.test.tsx` — правила дня и сценарий ребёнка (17 проверок);
* `tests/install-hint.test.tsx` — подсказка установки гасится сразу и не возвращается;
* `tests/adaptive-ui.test.tsx` — интеграционные проверки адаптации (35 проверок), плюс регрессии
  scheduler §13 в `tests/adaptive.test.ts`;
* всё это входит в `npm run test:smoke` (124 проверки) и `npm run test:adaptive`.

Итого с 0.8.0 добавлено ~65 автопроверок. Каждая фича проверена мутациями: тесты падают, если
вернуть сломанное поведение.

Checkpoint, озвучка, слайдер и другие новые механики не входят.

## Проверки и ограничения

Локально: `typecheck`, `content:check`, `test:adaptive`, `test:smoke`, `build`, `test:boot` — зелёные.
PR `Release checks` гоняет тот же набор без деплоя. Мобильные замеры производительности A+B
(Android/iOS, холодный/тёплый/офлайн) и проверка двойного тапа по «✕» — по-прежнему впереди,
протокол в `docs/perf-audit.md`.

## Публикация и проверка версии

1. Дождаться зелёного `Release checks` в PR ветки `arena/01a0ee48-slovo2` → `main`, слить PR.
2. Дождаться успешного **Deploy to GitHub Pages** для коммита слияния.
3. Открыть https://artignat2000.github.io/slovo2/ → «Родителям» → «Версия».
4. Ожидается **v0.8.1 · <SHA опубликованного коммита>**. SHA сверять с успешным запуском Deploy.
5. Перед обновлением закончить урок. При старой версии — закрыть/открыть с сетью, применить
   предложенное обновление. Не очищать данные сайта (прогресс локальный).

**Что проверить руками после деплоя (обратная связь):**

* в блоке «Задания дня» у каждого задания видна подпись и кнопка «Начать ▸»;
* у нового профиля нет задания «Повтори N слов» (вместо него другой вид);
* после урока появляется «Пора повторить», по тапу открывается повторение (не «Повторять нечего!»);
* прогресс «Повтори N слов» растёт и при ошибке в слове;
* «📲 Добавь приложение на экран» → «Понятно» исчезает сразу, без перезагрузки.
