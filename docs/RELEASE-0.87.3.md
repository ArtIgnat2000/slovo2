# 0.87.3 — 3D-пайплайн БУКа: Blender → атласы WebP

Итерация 3, этап 1 по `docs/buk-companion-3d.md` §6.3–6.6: пайплайн
предрендера для будущего `ui/Buk3D.tsx` (этап 2 — сам плеер). CI без
Blender остаётся честным: коммитятся готовые атласы, рендер локальный.

## Что сделано

- **`scripts/make-buk-art.py`** — Blender headless: процедурная low-poly
  сова (< 5 тыс. треугольников, проверяется при рендере), toon-шейдинг
  Cycles CPU, палитра и морфы повторяют `src/ui/Mascot.tsx`. Ступени роста
  как `growthStage`: птенец (пух вместо ушек), ученик (ушки), знаток (одно
  перо-хвост), магистр (два, полоски на груди). Лицо — таблицы из SVG:
  белки, зрачки с бликами, роты, поворот головы для «поворота-любопытства»
  и наклон для «спит». Кадры на ступень: `idle` 16 углов (шаг 22,5°) +
  эмоции `face/happy/excited/sad/think/dance/sleep/curious` × 4 фронта
  (±45/±15) = 48, бюджет §6.4.
- **`scripts/make-buk-3d.mjs`** — montage+convert (прецедент сундуков) →
  `public/buk3d/<ступень>/<клип>.webp` (ячейка 256 px, quality 80) +
  `public/buk3d/manifest.json`: клипы, сетки, углы, честные байты на
  ступень. Фактически: 140/148/151/152 кБ — все ≤ 500 кБ, всего 592 кБ.
- **`npm run buk:art`** — цепочка «рендер → атласы» (нужен Blender
  headless локально); `npm run buk:check` — контролька по образцу
  `audio:check`.
- **Вне precache** (§6.4): `globIgnores` получил `buk3d/**` — в `dist/sw.js`
  атласы не попали, их положит в кэш `slovo2-buk3d` плеер этапа 2.

## Как проверено

- **`tests/buk-3d.test.ts`** (в адаптивном контуре): манифест цел — все
  клипы и 4 ступени, ровно 48 кадров, атласы существуют на диске, бюджеты
  ≤ 500 кБ честно посчитаны, `buk3d` в globIgnores vite.config.ts.
- **`npm run buk:check`** — плюс габариты WebP = сетке манифеста.
- Контур зелёный: `typecheck`, `content:check`, `test:adaptive`,
  `test:smoke`, `build`, `buk:check`; в `dist/sw.js` ни одного упоминания
  `buk3d`.
- Окружение песочницы: bpy 5.0.1 подняли без системных X/GL-либ
  (пустышечные `.so` + заглушечные символы) и отрендерили 192 кадра за
  3,7 минуты — к скрипту это не привязано.
