# 0.56.0 — кристалл перерисован третий раз: крупный и «дорогой»

Отклик после 0.55.0: **«алмаз слишком маленького размера — плохо видно,
выглядит неубедительно»**. Оба замечания — про разное, и оба справедливые.

## Что было не так

| Проблема | Причина в 0.55.0 |
|---|---|
| «слишком маленький» | камень занимал 18 из 24 клеток: поля по краям, а рядом цифра того же роста |
| «плохо видно» | в шапке стоял фиксированный 18 px, хотя число — 20 px, то есть **иконка была мельче цифры** |
| «неубедительно» | грани почти одного тона (`#7fd6f8` / `#38a3e0` при контуре `#2a7fb8`) — камень выглядел плоским |

## Что сделано

### 1. Новая форма — классический бриллиант

Как у эмодзи `💎`, к которому дети привыкли: стол, корона и шатёр, сходящийся
в одну точку снизу. Камень теперь занимает **87 % высоты сетки** (от `y=1,6`
до `y=22,4` вместо прежних `4,6…21,6`).

### 2. Контрастные грани вместо ровного тона

Пять граней шатра чередуются: тёмная `#1f7fc4` → светлая `#63cdf2` → тёмная,
по краям ледяные `#a9e6ff`, стол `#dff4ff`, контур `#0f5f92`. Камень читается
объёмным, а не залитым одним цветом.

### 3. Крупнее в интерфейсе

* `<Gem>` по умолчанию **`1.15em`** — иконка растёт вместе с кеглем места,
  а не фиксированные 18 px. В шапке (число 20 px) камень теперь **26 px**;
* в магазине счётчик — 22 px, цены на карточках — 18 px (было 16);
* в заданиях дня награда — 18 px;
* на 320 px шапка не ломается: для этого случая камень 22 px.

## Проверки

`npm run test:icons` — **23 проверки**, три новые появились именно из этого
отклика:

* **«кристалл занимает почти всю сетку»** — поля ≤ 1,8 по бокам и ≤ 3,4 сверху,
  размах ≥ 20 × 18. Старое «сидит в середине» тест больше не пропустит;
* **«чередуются светлые и тёмные грани»** — минимум 4 оттенка у камня;
* **«в шапке кристалл крупный (≥ 24 px)»** и **«`Gem` растёт с кеглем»**
  (`1.15em`, а не фиксированные 18).

Плюс прежние правила: заливка есть, чёрного контура нет, контур ≤ 1,6,
палитра ≤ 48 цветов в `Icon.tsx`, `aria-hidden`/`role="img"`, бюджет 32 КБ.

Остальной контур: `typecheck`, `test:smoke`, `test:guard`, `test:content`,
`test:adaptive`, `audit:storage`, `demo:check`, `images:report -- --strict`
(257/257), `content:check`, `release:check` (0.55.0 → 0.56.0), `build`,
`test:boot` — зелёные.

## Дальше

Если камень всё ещё «не тот» — следующий шаг по разбору: вариант
**с искрой** (жёлтая звёздочка в углу, как у коллекционных предметов) или
**более гладкий «самоцвет»** без граней. Обе заготовки уже отрисованы
и лежат в истории решения; менять одну иконку теперь дешево — она описана
списком залитых граней.
