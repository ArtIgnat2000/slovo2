# Релиз 0.22.0 — «Ангар БУКа»: техника переехала с маскота в отдельную сцену

**Статус (2026-10-20):** PR #69 из ветки `arena/23b6451f-slovo2` (коммит
`1f79144` поверх нового `main` = `71fd3e3`, merge PR #68), CI `check`
пройден, ждёт слияния с разрешения пользователя. Порядок подтверждён
пользователем 2026-10-20: сначала слит PR #68 (0.21.2 опубликована,
деплой GitHub Pages успешен), затем ветка переустановлена на новый `main`
и 0.22.0 закоммичена и открыта как новый PR.
Реализация предложения `docs/proposals/large-items-scene.md`, принятого
пользователем 2026-10-19; журнал — часть 46 `docs/PLAN.md`.

## Жалоба

«Купленные машины и другие крупные товары не следует отображать на БУКе.
Следует придумать способ как отображать крупные товары — может, сделать
отдельную сцену, на которой будет реализовано отображение.»

Причина: рисунок машины 720×480 на маскоте сжимался до 17–38 px и
превращался в цветную кашу, корабль наползал на лапы, а слот `equipped.toy`
один — коллекция из десятка машин была невидима: ребёнок видел только
последнюю покупку.

## Решения пользователя (§7 предложения, 2026-10-19)

1. **Вся техника уходит в сцену — телефоны тоже** (вариант «телефон
   остаётся в крыле» отменён): на маскоте не рисуется ни одна вещь слота
   `toy`.
2. **Название сцены — «Ангар»**: «Ангар БУКа» («Гараж» в тексте предложения
   — историческое название рекомендованного варианта).
3. **Слова статуса — схема «место + действие»**, слово места согласовано
   с названием: «В ангаре ✓» / «На подиум» / «С подиума».
4. **Вход с главной — нужен**: значок 🚗 в шапке; герой «Сегодня» и путь
   на первом экране не тронуты.
5. **Версия 0.22.0.**

## Что изменилось

### Правило «техника — не на БУКе» (движок)

* `src/engine/shop.ts`: `showsOnBuk(item) = item.kind !== 'toy'` — правило
  живёт в движке: будущие товары с `kind: 'toy'` попадают в ангар
  автоматически, без правки картинок. Поле `ToySize` из предложения не
  понадобилось — телефоны тоже уехали в сцену.
* `MascotToy` удалён из `src/ui/ToyArt.tsx` и `src/ui/Mascot.tsx`: техника
  больше не рисуется внутри SVG совы нигде — главная, урок (помощник
  40 px), сундук, примерочная, сцена техники.
* Профиль НЕ мигрируется: `equipped.toy` остаётся, но меняет смысл —
  «любимая вещь на главном подиуме ангара». Машина у старых профилей
  просто встаёт на подиум и уходит с совы. Выгрузка и импорт не меняются.

### Сцена «Ангар БУКа» (`src/ui/HangarScene.tsx`, новый файл)

* Язык — витрина техники `TechScene` (0.19.0): `TechScene.tsx` экспортирует
  `Tone` и `BayDecor`, панели в токенах `--case-*`/`--stage-*`/`--tag-*` —
  сцена наследует все пять оформлений приложения.
* Любимая вещь — крупно (арт 118 px, машина `min(56vw, 230px)`) на главном
  подиуме с биркой «★ На подиуме»: рисунок 720×480 наконец видно целиком.
* Остальная коллекция — полки в порядке витрины: авто → телефоны → корабли
  (`TOY_SHELVES`), каждая вещь на своём подиуме (арт 58 px) с бумажной
  биркой; любимая помечена «★ Название».
* Тап по вещи — «на подиум» / «с подиума» (прежний `toggleEquip`, звезда
  одна, переключение бесплатно) + тост: ««X» — на подиуме! ★» / ««X» —
  с подиума»; подсказка «Тапни по вещи — встанет на главный подиум ★».
* БУК стоит на коврике рядом (`Mascot` 88 px без `look`) — хозяин
  коллекции, а не подставка; подпись: «БУК любуется коллекцией: техника
  стоит в ангаре, а не на нём».
* Пусто — честная пустота: «Пока пусто. Витрина ➜ полка «Техника» — там
  авто, телефоны и корабли.»
* Закрытие: ✕ (aria-label «Закрыть ангар»), тап по фону, Escape; начало
  урока закрывает сцену (`App.tsx`).

### Входы (три)

1. **Витрина ➜ «Техника»:** «🚗 Мой ангар — вся твоя техника крупным
   планом ➜» под сценой полки (виден при хотя бы одной купленной вещи);
   подпись полки: «Три полки: авто, телефоны и корабли. Купленное встаёт
   в ангаре БУКа — на большой сцене коллекции.»
2. **Гардероб ➜ «Моя техника»:** «Открыть ангар ➜» в шапке секции (тоже
   только при купленной технике).
3. **Главная:** значок 🚗 в шапке (`button.stat-pill.hangar-btn`, aria-label
   «Ангар БУКа», title «Ангар БУКа — твоя техника») — между 💎 и 🎁.
   Overlay рисует `App.tsx` (`hangarOpen`) — ангар открывается с любой
   вкладки.

### Слова (старое → новое)

| Где | Было | Стало |

| Плашка цены купленной техники | «Твоя ✓» | «В ангаре ✓» |
| Состояние карточки | «У БУКа ✓» | «На подиуме ✓» |
| Действие карточки | «Забрать» | «На подиум» |
| Статус в sheet | «Уже в коллекции» | «Уже в ангаре» |

| Подпись sheet | «БУК заберёт покупку с собой — её будет видно на главной и в уроках.» | «Встанет в ангаре БУКа — там её видно крупно и целиком.» |
| Тост покупки | «Покупка уже у БУКа — она рядом с ним» | «Поставим в ангаре — зайди посмотреть!» |
| Строки гардероба | «Убрать» / «Забрать» | «С подиума» / «На подиум» |

Краски 🎨 (тюнинг) остались в подробной карточке магазина — в ангаре
палитры нет: сцена любуется коллекцией, а не продаёт оттенки. Наряды не
тронуты: носятся на БУКе («Надето ✓» / «Надеть» / «Снять»).

### CSS

* `src/styles/app.css`: блок `.hangar-*` — veil (z-40), лист сцены, панели
  авто/корабли/телефоны, главный подиум, ряды полок, бирки
  (`.hangar-tag-star`), `.hangar-item.star`.
* `.hangar-buk .mascot` — сброс плавающего маскота (`position: static;
  inset: auto; z-index: 1; animation: none`): без него БУК улетает в правый
  нижний угол экрана (грабли 0.21.2); страж — в `tests/puzzles-ui.test.tsx`.
* `.topbar .grow { min-width: 0 }` + эллипсис `.topbar-name`: новый значок
  не ломает шапку на 320 px.
