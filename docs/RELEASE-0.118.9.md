# 0.118.9 — Android: компоновка урока и «Колеса букв»

Небольшое обновление мобильной раскладки и иллюстрации.

## Что изменилось

* В задании «Напиши слово» при открытой подсказке иллюстрация становится
  компактнее, чтобы на коротком экране помещались поле ответа и все ряды
  экранной клавиатуры.
* В победном состоянии «Колеса букв» сцена сжимается, повторяющиеся строки
  результата убраны; прокрутка остаётся запасным вариантом для низких экранов.
* Иллюстрация «Родина» заменена на новую семейную сцену с прозрачными краями.
* Добавлены UI-регрессии для мобильных состояний.
