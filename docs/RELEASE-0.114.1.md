# 0.114.1 — урок: знакомство сразу закрепляется тем же словом

Небольшой релиз-починка, собранный из «зависшего» PR #206. Его проверки не
могли пройти: ветка шла от 0.109.2 без нового релиза, а CI требует, чтобы
каждый PR поднимал версию. Изменения перенесены на текущий `main` и выпущены
как 0.114.1; сам PR #206 закрыт как заменённый.

## 1. Порядок заданий

Раньше урок открывался подряд всеми карточками знакомства, и только потом
начинались задания. Ребёнок успевал забыть слово, которое только что видел.
Теперь:

1. карточка знакомства;
2. сразу первое задание на **то же слово**;
3. следующая карточка знакомства и её закрепление;
4. остальные задания в перемешанном порядке;
5. повторение прежних уроков — в конце.

Правило вынесено в `orderLessonTasks()` (`src/engine/scheduler.ts`) и
используется в `LessonScreen`. Каждое задание остаётся ровно один раз:
функция не создаёт и не теряет задачи, только переставляет.

## 2. Тесты

* `tests/adaptive.test.ts` — на паре «топор / лопата»: после карточки идёт
  первое задание именно этого слова при `maxCards` 8, 12, 16 и 20; все `uid`
  сохраняются; повторение остаётся в конце; выученное слово не получает
  новую карточку знакомства.
* `tests/adaptive-ui.test.tsx` — проверка в реальном прохождении урока:
  после «Запомнил» следующее задание — о том же слове; счётчик последнего
  вердикта сохраняется до перехода к результатам.

## 3. Ревью предложения студии

В `docs/proposals/games-studio-response-review.md` сохранено ревью
премиального дизайна игр: текущая сетка против карусели, 257 картинок на
367 слов, контраст вычисленных цветов, существующие звуки/вибрация, стоп-лист
и вопросы, которые остаются за владельцем. Это документ для обсуждения, код
игр не менялся.
