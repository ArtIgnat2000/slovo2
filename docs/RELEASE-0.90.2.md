# 0.90.2 — свод правил проекта и план словаря 5 класса

Документационный релиз: ничего в приложении не меняется. По итогам полного
аудита проекта (три прохода: контент → карточки и картинки → процесс) составлен
единый справочник правил и рабочий план 5 класса.

## Что добавлено

**`docs/PROJECT-RULES.md`** — свод правил проекта, «исчерпывающая памятка»
для любой задачи в репозитории:

* **процесс:** ветки (работа только в `arena/…`), версионирование (каждый PR
  повышает версию; lock совпадает в обеих точках; заголовок PR `vX.Y.Z — …`),
  CI `.github/workflows/check.yml`, полный локальный контур из 10 шагов;
* **контент:** формат строки RAW (9–10 полей) с разбором каждого поля; правила
  «опасных» букв (безударные о/е/я/э — всегда; а/и — только словарные; у/ы/ю —
  никогда; ударная никогда, «ё» — всегда); предложение в словарной форме и
  стражи падежей; мнемоника («две С», заглавные = ударение/опасные);
  снимок ударений и `stress-dict`; импорт черновика и вычитка;
* **карточки:** вариант B «Фотокарточка» — плита `--art-hero clamp(…)`,
  зазор плита → слово 20 px, шкала `--sp-1…--sp-7`, чип опасной буквы
  (`--orange-ink`, контраст ≈ 4,5 : 1), тёмная тема и 320 px;
* **методика:** цикл LOOK–SAY, SRS, интерливинг, экран разбора после ответа,
  «ё» ≈ «е» при письме, глобальное повторение, «класс пройден» (уроки уровня 5);
* **картинки:** спецификация (WebP 256×256, ≤ 20 КБ, кремовый фон `#FAF4E1`,
  один предмет, без букв и цифр), пайплайн (`images-src/gen/` →
  `make-word-image.mjs` → поле RAW), правило «≤ 3 кадра в подходе»,
  шаблон промпта, precache и `images:report`;
* **классы:** архитектура «один банк — класс-фильтр», чек-лист добавления
  класса (типы → контент → экспорты → стор → UI → тексты → тесты → релиз),
  инварианты и все точки «1–4» в коде;
* нерушимые правила (стабильные `id`, смена класса меняет ровно два поля,
  без озвучки и лутбоксов), словарь терминов, карта документов, приложения
  (как добавить слово / картинку / чек-лист контент-PR).

**`docs/proposals/slova-5-klass.md`** — план словаря 5 класса:

* источник зафиксирован владельцем: Баранов, Ладыженская, Тростенцова и др.
  «Русский язык. 5 класс» (Просвещение), издания 2025/2026; «Школа России»
  покрывает только 1–4 класс;
* модель не меняется (общий банк, `ClassId = 1|…|5`, префикс `g5_`, уроки
  `g5_<slug>`, 4–8 слов, эмодзи-класс `🏫` на вычитку);
* состав словника **не фиксируется до получения приложенного списка**
  (в следующем сообщении): web-подборки «словарные слова 5 класса» расходятся
  на десятки слов; работа по списку + сверка с печатным учебником;
* картинки — эмодзи на релизе, генерация партиями после (§7.6 сводa правил);
* пошаговые планы: изменения в `types.ts` / `words.ts` / сторе / UI / тестах /
  текстах (все места «1–4» перечислены таблицей), этапы, риски, чек-лист
  релиза класса, секция «Фактическое состояние работы» для заполнения
  после поступления словника.

**`README.md`** — в раздел «Классы 1–4» добавлены ссылки на оба документа.
