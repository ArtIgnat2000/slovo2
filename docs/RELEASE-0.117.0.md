# 0.117.0 — волна B: сад закрыт, «фамилия» на месте, начало города

Десять новых картинок 2 класса в тёплом 3D-storybook: **фамилия, малина,
щавель, яблоко, яблоня, ягода, город, улица, магазин, машина**.

## Что стало

| Слово | Сцена |
|---|---|
| фамилия | семейный портрет: бабушка, мама, папа и мальчик-школьник |
| малина | ветка садовой малины с ягодами и листьями |
| щавель | пучок широких зелёных листьев на влажной земле |
| яблоко | красное яблоко с листиком и второе в мягкой глубине |
| яблоня | молодая яблоня с красными яблоками и травой у корней |
| ягода | плетёная корзинка с лесными ягодами: малина, черника, смородина, земляника |
| город | тёплый силуэт города из округлых домов и башен на холме |
| улица | узкая мощёная улица с домами, фонарём, деревьями и велосипедом |
| магазин | маленькая лавка с полосатым навесом, витриной и ящиком яблок |
| машина | округлый жёлтый городской автомобиль без номеров и надписей |

Все кадры: 256×256 WebP, q82, без текста, вывесок, логотипов и номеров.
Вес — **82 КБ на десять** (старые файлы весили 46 КБ). Пак `public/words` —
**1 440 КБ**.
