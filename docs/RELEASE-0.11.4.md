# Релиз 0.11.4 — фотокарточка в повторении

* Дата: **2026-10-07**
* Ветка: `arena/52aa014a-slovo2` → `main`
* Предыдущий релиз: [`0.11.3`](./RELEASE-0.11.3.md)
* Диагностика после деплоя: `?diag=1` должна показать **v0.11.4**

Патч-релиз по замечанию с iPhone (v0.11.3, слово «ученик», запуск через блок
задания дня «Повтори 5 слов»): «видно, что композиция старая и рисунок маленький».

## Диагноз

Режим «Повторение» строит очередь отдельно от обычного урока: на каждое слово —
«Напиши слово» или «Исправь робота» плюс «Слоги», без карточки-знакомства. Слова
с чётным номером открывались заданием «Напиши слово» — единственным, где по
решению 0.11.3 осталась компактная горизонтальная подсказка (плита ~110–135 px).
Половина слов встречала ребёнка старой композицией; релизы 0.11.2/0.11.3 очередь
повторения не трогали.

## Что изменилось

1. **Повторение открывается фотокарточкой-напоминанием.** На каждое слово:
   крупная карточка (снимок во всю ширину, до ~334 px на iPhone, слово, слоги,
   пример) с кнопкой **«Вспомнил! 👍»** → «Напиши слово» или «Исправь робота».
   Композиция теперь та же, что в знакомстве урока: сначала образ — потом письмо.
2. **Карточек на слово по-прежнему две**: напоминание занимает слот прежней
   карточки «Слоги» (слоги видны на самой карточке; упражнение «Прочитай по
   слогам» остаётся в обычных уроках). Поэтому не изменились:
   * бюджет повторения — не выше выбранного размера урока (стражи смоука
     и адаптации на месте и зелёные);
   * закрываемость «Повтори N слов» за один заход;
   * SRS-математика и адаптация объёма урока.
3. **Напоминание неоцениваемое** (`onSolve(null)`): не считается
   «потренированным словом», не даёт XP и не влияет на статистику.
4. CSS не менялся: напоминание переиспользует проверенный `lesson-intro-card`
   (снимок сжимается сам, экран урока по-прежнему без прокрутки).

## Проверки

Перед публикацией прошли полный контур:

* `npm run typecheck`;
* `npm run content:check` (94/94);
* `npm run test:adaptive`;
* `npm run test:smoke` (включая новые стражи повторения);
* `npm run build`;
* `npm run test:boot`;
* `npm run audit:storage`;
* `git diff --check`.

Новые проверки: напоминание — та же «фотокарточка», кнопка «Вспомнил», а не
«Запомнил», слоги и пример на месте; живое повторение открывается карточкой и
после неё даёт оцениваемое задание; хелперы тестов пролистывают напоминания.

## Проверить после деплоя

1. Открыть `?diag=1` и проверить версию **v0.11.4**.
2. Запустить повторение (блок «Пора повторить» или задание дня «Повтори N
   слов»): первое, что видно, — крупная карточка слова с кнопкой «Вспомнил! 👍».
3. После кнопки — «Напиши слово» или «Исправь робота»; счётчик карточек в шапке
   не превышает выбранного размера урока.
4. Прогресс задания дня «Повтори N слов» растёт по оцениваемым ответам, как
   раньше; за одно повторение задание закрывается.
5. Тёмная тема и горизонтальная ориентация — карточка читается, прокрутки нет.
