# 0.116.0 — волна B: ещё девять слов 2 класса в стиле storybook

Продолжение арт-волны после 0.115.1. Девять слов второго класса получили
новые картинки 256×256 в тёплом 3D-storybook: сорока, собака, обезьяна,
капуста, молоко, морковь, обед, сахар, земляника.

## Что стало

| Слово | Сцена |
|---|---|
| сорока | чёрно-белая птица на мшистой ветке, рядом гнездо и блестящая ложка |
| собака | золотистый щенок сидит, красный ошейник с жетоном |
| обезьяна | маленькая обезьяна на ветке с бананом |
| капуста | кочан на влажной земле, капли росы |
| молоко | бутылка и стакан молока на деревянном столе |
| морковь | две моркови с ботвой на грядке |
| обед | миска горячего супа с паром, хлеб, ложка и салфетка |
| сахар | сахарница с кубиками и чайная ложка |
| земляника | лесные ягоды, листья и белый цветок на мху |

Все кадры: 256×256 WebP, q82, без текста и логотипов, фон и свет совпадают
с паком 0.115.0. Вес — **75 КБ на девять картинок** (старые файлы весили
29 КБ). Пак `public/words` — **1 404 КБ**; precache — **593 файла /
24 596.78 KiB** (+46.75 KiB к 0.115.1).

## Чего нет в этой партии

«Фамилия» осталась в прежнем плоском стиле: групповой семейный портрет
требует квадратного кадра, а генератор в этой партии отдал широкий. Слово
не потерялось — картинка на месте, просто старая. Новый квадратный кадр
пойдёт следующей партией вместе с едой и садом.

## Покрытие

Картинки есть у всех 367 слов 1–4 классов и у 17 слов 5 класса; всего
**257 из 367 (70 %)**. В новом стиле — **29 слов** (20 из 0.115.0 и 9 здесь):
«Школа» 8/8, «В школе» 4/5, «Птицы» 5/5, «Звери» 6/6, «Еда» 5/5, «Сад и
ягоды» 1/6. «В школе» и «Сад и ягоды» закроются, когда в стиль войдут
«фамилия», «малина», «щавель», «яблоко», «яблоня» и «ягода».

Превью девяти карточек: [`docs/promo/0.116.0/waveB-preview.webp`](./promo/0.116.0/waveB-preview.webp).

## Проверки

* `npm run content:check` — 367 слов, 257 картинок;
* `npm run images:report` — пак 260 файлов / 1 404 КБ;
* `npm run build` — precache без ошибок, рост в пределах бюджета;
* `npm run test:smoke`, `test:content`, `test:adaptive`, `test:contrast`,
  `test:guard` — зелёные.
