## Как разведены близкие пары

* **`passazhirskiy` против `passazhir`** (из 0.43.0): слово-признак нарисовано
  целым составом — локомотив и два вагона, в окнах силуэты людей; а `passazhir`
  — один человек с чемоданом у двери. Так видно разницу «признак» / «кто».
* **`korabl` против `vagon` и `passazhirskiy`**: корабль узнаётся по трубе,
  иллюминаторам и волне под корпусом, а не по «транспорту вообще».
* **`bagazh` / `puteshestvie` / `puteshestvennik`** — три слова одного урока
  и одна тема, поэтому развели по главному предмету: чемодан → карта с
  компасом и чемоданом → человек с рюкзаком и картой. Тот же приём, что
  с `interesnyy`/`interesno`.
* **`adres`** — конверт с сургучной печатью и пунктир к домику: адрес как
  «куда письмо», без единой буквы на конверте и марке.

## Сельская тема начата

* **`ovtsa`** — кудрявая овца с тёмной мордочкой (шерсть из круглых клочков,
  чтобы не путалась с собакой);
* **`semena`** — пакет без надписей и три крупных полосатых семечка: надписи
  на пакете были бы подсказкой написания;
* **`seyalka`** — прицеп-сеялка с дисками и бункером, **без трактора**:
  трактор уже занят словом `traktor` из 3 класса, дублировать нельзя.
