# 0.91.0 — 5 класс: 127 слов и 22 урока

Программа «Школа России» заканчивается 4 классом; начиная с этого релиза в
приложении есть **5 класс** — словарный минимум УМК Баранов–Ладыженская,
«Русский язык. 5 класс» (Просвещение). Состав перенесён с приложенного
владельцем скана словаря учебника (с. 214–215), без домыслов и интернет-подборок.

## Что добавлено

**Контент** (`src/content/words.ts`, один общий банк — класс остаётся свойством
профиля):

* **367 карточек** в банке (было 257): **110 новых** слов 5 класса (префикс
  `g5_`) и **17 пересечений** с 1–4 классами, которым дописан класс 5 в
  `GRADES_OF` — «беседовать», «вагон», «вокзал», «здесь», «издалека»,
  «календарь», «костюм», «налево», «направо», «салют», «слева», «справа»,
  «телефон», «шофёр» (4 класс), «компьютер», «помидор», «шоссе» (3 класс).
  Id не менялись: один прогресс на слово, ничего не дублируется;
* **фраза «Великая Отечественная война»** — отдельная карточка (движок
  поддерживает фразы как «Красная площадь»): одно ударение («Вели́кая»),
  предложение без ответа, слоги двумя репликами в чате БУКа; включена по
  решению владельца 2026-11-09;
* **имена собственные «Жостово» и «жостовский»** — включены по решению владельца
  (жостовские подносы — словарная лексика учебника);
* опасные буквы по правилам проекта: все безударные о/е/я/э помечены,
  словарные а/и — по факту орфограммы, «у/ы/ю» не помечаются; ударение никогда
  не «опасная» (кроме «ё»); падежи проверены скриптом (`content:check`);
* снимок ударений расширен до 367 записей (`tests/stress-snapshot.ts`).

**Уроки 5 класса** — тематические блоки по 4–8 слов, ровно один урок на слово,

Класс доступен в листе «Какой класс учим?» (эмодзи **🏫**), в адаптивном
окно, в таблице «Родителям → Обзор», в словарике (новый фильтр класса) и в
словарном раскладе БУКа.

**Исправления попутно** (потребовались новым словам):

* виртуальная клавиатура получила клавишу **«ъ»** («необъятный») —
  инвариант «все буквы банка есть в раскладке» теперь зелёный;
* ответ БУКа на вопрос про слово для длинных слов показывается двумя
  репликами ≤ 70 знаков («повествовательный», «Великая Отечественная война»);
* запасная реплика БУКа переписана без слова «внизу» — оно вошло в банк 5 класса
  (фолбэк больше не называет слов пака, проверяется тестом);
* тексты «1–4» → «1–5»: share/манифест/мета-страница/README/манифест PWA,
  строки «вся программа 1–5», «таблица классов 1–5».

## Картинки

По решению владельца картинки на релизе **не генерируем**: 5 класс показывается
эмодзи на плите. Покрытие `images:report` — 257 из 367 (70 %); 1–4 классы как
были (100 %). Партии ≤3 кадра — отдельным циклом после релиза
(`docs/proposals/slova-5-klass.md` §8).

## Как это выглядит для ребёнка и родителя

Ребёнок с профилем в 4 классе видит в «Моём пути» новый узел после последнего
урока 4 класса; переключение на 5 класс — из того же листа «Какой класс учим?»
или из «Родителям → Настройки». Опыт, кристаллы, серия, покупки и прогресс по
словам остаются; уроки 4 класса просто скрываются; прогресс по словам общий
для слов, которые встречаются в нескольких словариках.

  (как и все фразы банка — ограничение движка заданий).
