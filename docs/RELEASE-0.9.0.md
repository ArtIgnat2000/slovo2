# Релиз 0.9.0 — костюмные пазлы

**Статус (2026-10-01):** версия поднята до `0.9.0` (`arena/01a0f32e-slovo2` → `main`),
опубликована на GitHub Pages. Проверка на устройстве:
https://artignat2000.github.io/slovo2/ → «Родителям» → версия `v0.9.0 · <SHA>`.

## Состав релиза (поверх 0.8.2)

1. **Костюмные пазлы** (идея из родительского чата, «как в Дуолинго»): за каждый реально
   завершённый урок — 1 фрагмент пазла; 9/9 — БУК получает новый костюм и сразу его надевает.
   Движок и палитра — `src/engine/puzzles.ts` (единственный источник правил: 10 костюмов,
   `awardLessonPiece`, `chooseCollecting`, `toggleWorn`, `normalizePuzzle`); состояние —
   `Profile.puzzle?` в `src/state/store.ts` (фрагменты хранятся по каждому костюму, смена
   цели ничего не теряет); надеть можно один костюм (хук `useWornCostume`).
2. **Вся коллекция собрана → перелив:** каждый следующий урок даёт +2 💎 (`OVERFLOW_GEMS`);
   награда не может «сгореть». «Повторение» (`REVIEW.id`) фрагментов не даёт — guard в
   `LessonScreen`, зафиксирован тестом-сканом исходника.
3. **Рендер костюмов:** `Mascot.tsx` перекрашивает тело/крылья/брюшко/лапки по палитре
   костюма (prop `costumeId`: `undefined` — из магазина, `null` — без костюма, `id` — превью);
   `MascotLook.tsx` — слои `CostumeCape`/`CostumeHead`/`CostumeProp` и типы шлемов
   `mask | lord-mask | visor | hood | bubble | dome | plate | buns | ears`.
4. **Магазин БУКа — секция «Костюмы · пазлы»:** сетка 2×5, серый силуэт и 9 точек прогресса
   у несобранных, «Собирать / Продолжить · N/9 / Собираю · N/9», примерка «Надеть / Надето ✓».
5. **Экран результатов урока:** строка «Фрагмент пазла 🧩 N из 9 / Пазл собран / Коллекция
   собрана», праздничный блок `.puzzle-win` с танцующим БУКом (без отдельного окна, без
   озвучки).
6. **Узнаваемость «ближе к кино»** (итерации 2026-10-01, после ревью превью):
   «Тёмный лорд» — полный шлем по мотивам оригинала (колоколообразный купол с раструбами,
   гребень-«мохавк», V-бровка над глазами, серебро носа, два ротовых вентиля с решёткой,
   «клыки», ворот, нагрудная панель); «Белый воин» — Т-визор под полупрозрачным стеклом +
   коммуникаторы на висках; «Стальной страж» — нос-трубка и щель рта. Имена и описания
   остались нейтральными («космическая сага»), без товарных знаков.
7. **Промо-материалы для родительского чата** (слайды поверх 0.8.2): `docs/promo/2026-09-30/`
   (5 PNG 4:5 + PDF), генератор `scripts/promo/make_slides.py`; превью-карточки костюмов —
   `docs/promo/2026-10-01/`, генератор `scripts/promo/make_costumes.mjs` (нужен
   `npm i --no-save @resvg/resvg-js`).

## Тесты

* `tests/puzzles.test.ts` — правила движка (входит в `test:adaptive`): фрагменты,
  автонадевание, смена цели без потерь, guard примерки, перелив, санитайзер импорта.
* `tests/puzzles-ui.test.tsx` — 21 интеграционная проверка через настоящий UI в смоуке:
  реальный прогон урока даёт фрагмент; 9-й собирает костюм; магазин (сетка/точки/примерка);
  перелив ровно +2 💎; guard «Повторение» (скан исходника).
* Зелёные: `typecheck`, `content:check` (94 слова), `test:adaptive`, `test:smoke`, `build`
  (precache 112 записей, ~1156 KiB), `test:boot` (0 ошибок консоли), CI `Release checks`.

## Что не вошло (осознанно)

Звуки/озвучка фрагментов, анимация «выпадения» кусочка, дневные лимиты, редкие фрагменты —
всё это противоречит принципам «без стресса и без фарма» (PLAN). Рандомизация наград — нет:
награда детерминирована (урок → фрагмент).
