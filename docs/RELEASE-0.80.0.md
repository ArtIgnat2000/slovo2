# 0.80.0 — фотореализм: автомобили, первая десятка

Продолжение 0.77–0.79. В студии уже стояли питомцы, спорт, вкусняшки,
самолёты, корабли и базы. Теперь начат самый крупный раздел — авто.

## Что изменилось

- **Десять машин сняты в студии.** Болид, Скалолаз, Жёлтый кэб, Звезда,
  Стрела, Кубик, Адмирал, Лорд, Бык и Молния получили фотореалистичные
  снимки вместо карандашных рисунков: объёмные блики по лаку, настоящая
  резина, хром, отражения на глянцевом полу. Машина входит в кадр целиком —
  ни крыши, ни колёс не срезает.
- **Формат тот же, что у остальных товаров:** 1200×900, ниша 4:3 карточки,
  `object-fit: contain`. Один снимок работает и в витрине, и в подробной
  карточке, и в сравнении.
- **Остальные девять машин и электроника** пока показывают прежний векторный
  арт: `hasProductPhoto` пропускает к нему, пока снимка нет. Ничего не
  сломалось и не опустело — раздел дорисовывается следующей партией.

## Исправлено

- **Трейд-ин у фототоваров.** Кнопка «Сдать обратно · +N 💎» лежала внутри
  блока перекраски (`owned_ && supportsTint(item.id)`). А `supportsTint`
  отключается ровно у тех вещей, которые получили снимок — перекрашивать
  фотографию нечем. В итоге у любого фототовара продать вещь из подробной
  карточки было нельзя. Теперь перекраска и сдача живут раздельно: сдать
  можно всё купленное, перекрасить — только то, у чего есть палитра.
  Правило на будущее: действия карточки не вешаем на условия оформления.

## Проверки

- `tests/smoke.test.tsx`: проверка арта машины принимает и `/products/`,
  и прежние `/cars/`; добавлен отдельный чек — переснятые машины показывают
  студийный снимок, а розовый танк обязан иметь хоть какой-то арт.
- `tests/smoke.test.tsx`: трейд-ин снова проверяется на фототоваре — это и
  поймало регрессию.
- `npm run typecheck`, `npm run build`, `npm run test:smoke`, `test:boot`,
  `test:guard`, `test:contrast` — зелёные.
