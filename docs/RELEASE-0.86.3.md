# 0.86.3 — единая тёмная тема в стиле Maybach

## Что изменилось

- Общий фон, панели и карточки классической тёмной темы используют тёплую обсидиановую палитру, согласованную с витриной товаров.
- Акценты, навигация, рамки и подсветка оформлены в оттенках шампань вместо сине-фиолетовых цветов.
- Цвет системной панели и стартовый скрипт темы синхронизированы с фоном приложения.
- Текст акцентных кнопок и их тени используют токены темы.
- Добавлены регрессионные проверки палитры Maybach.

## Проверки

До повышения версии успешно выполнены `npm run build`, `npm run test:smoke`
и `npm run test:contrast` (16 тем, 288 пар, WCAG AA).
