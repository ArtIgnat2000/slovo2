# Релиз 0.7.0 — подготовлен к публикации

## Изменения

* Адаптивный объём урока: минимум 8 базовых карточек, максимум — выбранный
  родителем потолок 12/16/20. Изменяется только между уроками, отдельно для профиля.
* Метрика нагрузки учитывает первичные попытки, ошибки сборки и подсказки;
  успешные отработки не завышают оценку. XP и SRS не менялись.
* Картинки: эмодзи до загрузки и при ошибке, плавное появление, приоритет текущей
  карточки, lazy-миниатюры и ограниченный прогрев следующих изображений.
* Сохранён полный офлайн-кэш всех 94 изображений.
* Исправлены знакомство со словами-фразами и отмена таймеров после выхода.

Checkpoint, озвучка и числовой слайдер не входят в релиз.

## Проверки и ограничения

Локально: typecheck, content:check, test:adaptive, test:smoke, build, test:boot.
Тот же набор запускается в PR workflow `Release checks` без публикации сайта.
Реальных мобильных измерений ускорения пока нет; перед/после публикации пройти
холодный, повторный и офлайн-запуски Android/iOS по `perf-audit.md`.

## Публикация и проверка версии

1. Дождаться зелёного `Release checks` в PR, просмотреть изменения, слить PR в main.
2. Дождаться успешного **Deploy to GitHub Pages** для коммита слияния.
3. Открыть https://artignat2000.github.io/slovo2/ → «Родителям» → «Версия».
4. Ожидается **v0.7.0 · <SHA опубликованного коммита>**. SHA сверять с успешным
   запуском Deploy, а не обязательно с последним коммитом рабочей ветки.
5. Закончить урок перед обновлением. Если осталась старая версия, закрыть и
   открыть приложение с сетью, применить предложенное обновление и проверить снова.
   Не очищать данные сайта: прогресс локальный. Перед опасными действиями — экспорт.

Создание PR не публикует сайт. GitHub Release/tag отдельно не создаётся.
