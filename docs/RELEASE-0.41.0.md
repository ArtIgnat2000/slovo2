## Главное решение: дни недели — по примете, а не по листку календаря

В §4 приоритета было записано: если «листки календаря» получатся
неразличимыми — рисовать примету дня. Так и вышло, листки не рисовали
вообще:

| День | Кадр |
|---|---|
| понедельник | восходящее солнце + рюкзак со книжками |
| вторник | раскрытая книга и карандаш на столике |
| среда | пирог, разрезанный **ровно пополам** — половина недели |
| четверг | туча с каплями и раскрытый зонт |
| воскресенье | велосипед, корзина для пикника, солнце |

На каждом кадре есть маленькая карточка с точками (1, 2, 3, 4, 6 точек) —
это не цифры и не подсказка написания, а порядковый «счётчик дня»: он
помогает, когда картинку смотрят в списке слов подряд.

## Отбракованный кадр

**`пятница`** (ранец + флажок + шарик) **не подключена**: ранец уже занят
понедельником, в списке слов эти два кадра читались бы как одно и то же.
Файл удалён из `public/words`, слаг остаётся в волне 8 со статусом `↻`.
Следующим подходом пятницу перерисуем без ранца (мяч + флажок «ура,
каникулы») — правило «брак не подключаем, эмодзи лучше плохой картинки».

## Спорный кадр

**`однажды`** — карточка с одной точкой и стрелка по кругу, обозначающая
«один раз». Слово отвлечённое (уровень C), в §4 прямо допускался исход
«оставили эмодзи». Подключили, потому что кадр читается как «однажды,
один раз»; если на ребёнке не сработает — вернём эмодзи `🕰️` одной правкой.

## Мелочи

* **`gramm` / `kilogramm`** — весы: маленькая гирька против щепотки соли
  и большая гиря против мешка крупы. Гири без надписей.
* **`kalendar`** — настенный календарь с пустыми клетками и одной жёлтой
  подсветкой: **ни одной цифры**, как и договорились для часов Кремля.
* В скрипт проводки слагов добавлена проверка «10-е поле должно быть пустым»
  — после инцидента с `geroygeroy` в 0.40.0.
