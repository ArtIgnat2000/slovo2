# Релиз 0.16.2 — синхронизация документов с опубликованной 0.16.1

**Статус (2026-10-18):** документационный релиз, подготовлен в ветке
`arena/95eb0aa7-slovo2`. Игровой код, контент, экономика и хранилище
прогресса не меняются. Слияние и публикация — только с отдельного
разрешения пользователя; до слияния на сайте остаётся 0.16.1
(`?diag=1` → `v0.16.1 · d112a95`).

## Зачем

`docs/PLAN.md` и `docs/HANDOFF.md` остановились на 0.12.1 (2026-10-15), а
`docs/next-chat-prompt.md` — на 0.11.8, хотя после этого вышло девять
релизов (0.12.2–0.16.1, PR #48–#61). Новая сессия, стартующая с этих
документов, получала неверную картину — вплоть до «PR для 0.12.1 не
открыт» при опубликованной 0.16.1. В README «План развития» картинки к
словам числились невыполненными, хотя они есть у всех 94 слов.

## Состав

* `docs/PLAN.md`: шапка и таблица приоритетов приведены к 0.16.1
  (добавлены пункты 17–25, включая ожидающие фазу 2 магазина и этап 3
  дневного отчёта); журнал дополнен ретроспективными частями 32–37 по
  релизам 0.12.2–0.16.1 и частью 38 об этой синхронизации; добавлена
  актуальная «Точка передачи работы в новый чат — 2026-10-18» (после
  таблицы приоритетов и в конце журнала — последнюю печатает
  `scripts/pickup.mjs`).
* `docs/HANDOFF.md`: переписан под 0.16.1/0.16.2 — состояние по релизам,
  открытые действия (фаза 2 магазина, этап 3 отчёта, дубль PR #59,
  недельные награды), непроверенное живьём, урок package-lock из 0.15.1.
  Правила работы, решения по тюнингу, стоп-лист и контур проверок сохранены.
* `docs/next-chat-prompt.md`: состояние на 2026-10-18, текущая задача —
  0.16.2, следующие кандидаты и запреты; исторические задачи 0.11.7/0.11.8
  больше не подаются как текущие.
* `README.md`, «План развития»: картинки к словам отмечены выполненными
  (94/94), добавлены строки 0.12.2–0.16.1; «Статистика по типам ошибок»
  разнесена на сделанные этапы 1–2 дневного отчёта (0.16.1) и ожидающий
  этап 3.
* Версия: `0.16.1` → `0.16.2` в `package.json` и обоих полях
  `package-lock.json` (`npm version 0.16.2 --no-git-tag-version`) — по
  правилу «каждый PR увеличивает версию», без исключения для docs.

## Проверки

`npm run pickup` на чистом `main` 0.16.1 перед правками — зелёный
(typecheck, content:check, test:adaptive, audit:storage, test:smoke,
test:boot). Перед PR прогнать полный контур:
`test:release`, `release:check`, `typecheck`, `content:check`,
`test:adaptive`, `test:smoke`, `build`, `test:boot`, `audit:storage`,
`git diff --check`. Фактические результаты — в описании PR.
