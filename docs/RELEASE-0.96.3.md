# 0.96.3 — «Игры»: без повторов слов и с новым набором в кроссворде

Патч по скриншоту владельца: в филворде одна и та же сетка показывала
**три «телефон», три «беседа» и три «человек»**, а в списке целей было
шесть чипов с тремя уникальными словами. Плюс просьба: «меняй набор слов и
в кроссворде».

## Почему появились повторы

Гонка двух правок. В 0.96.2 движок научился отодвигать слова прошлой сетки
(`avoidIds`), но «свежих» слов проверялось по **всему пулу**, а не по
пригодным для поля. На маленьком пуле (6 изученных слов) движок считал, что
свежих «достаточно», отсекал все прошлые — и оставалось меньше трёх
пригодных. Тогда срабатывало «страховочное» окно со всем пулом, где прошлые
слова уже стоят в начале списка, а порядок в движке = приоритет размещения.
Отсюда три копии одного слова в одной сетке.

## Что изменено

- **Одно слово — одна позиция.** `buildWordSearch` убирает дубликаты из
  входного пула (`uniqueById`) и физически не кладёт слово дважды
  (`placedIds`). Даже если вызывающий код передаст список с повторами, поле
  останется корректным. Это главная защита — она не зависит от эвристик.
- **Пул на поле — только пригодные слова.** Отсев прошлой сетки идёт по тем
  словам, которые реально влезают в поле, а не по всему пулу. Больше нет
  сценария «свежих достаточно → отсекли всех → осталось два слова».
- **Прошлые слова не накапливаются.** Экран передаёт в `avoidIds` слова
  ровно прошлой сетки (с дедупликацией), а не всю историю за сессию.
- **Кроссворд меняет набор слов.** `buildCrossword` получил `avoidIds` и
  перемешивает свежие слова — «🔄 Новая сетка» / «Ещё кроссворд» показывает
  другие слова, а не только другую решётку из тех же. Дубликаты во входном
  пуле тоже отсекаются: одно слово — один слот (иначе пул букв задваивался).
- Правило «сначала свежие, прошлые — только если свежих не хватает»
  сохраняется в обеих играх: на пуле из 5–6 слов повтор возможен и честен —
  пустая сетка хуже повтора.

## Проверки

`npm run typecheck`, `npm run test:smoke`, `npm run build`, `npm run test:boot`,
`npm run release:check`.

Новые проверки (движок и UI):
- филворд: одно слово не появляется в сетке дважды на малом пуле (12 сидов);
- филворд: дубликаты во входном пуле не дают повторов на поле;
- филворд (UI): чипы на поле уникальны по тексту — та самая ошибка со скриншота;
- кроссворд: разные seed → разные наборы; одно слово не занимает два слота;
  дубликаты пула не дают двойных слотов; новая сетка не повторяет прошлую;
- кроссворд (UI): «Ещё кроссворд» меняет слова, в решётке нет повторов.
