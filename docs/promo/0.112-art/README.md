# Пилот арта 0.112.0

`trail-hero-pilot.webp` — 1280×720, 118 КБ. Единственный кадр-эталон стиля
«тёплый 3D-storybook»: Буквёнок идёт по каменной тропе к школе, кремовое небо,
мягкий контровой свет сверху-слева, округлые формы. Сгенерирован специально
для проекта как оригинальная иллюстрация; это не кадр из чужого мультфильма и
не копия персонажа известной студии.

В игру кадр не входит: см. [`../../proposals/art-plan-pixar.md`](../../proposals/art-plan-pixar.md),
волна A. Текущие 257 WebP в `public/words` остаются фолбэком.
