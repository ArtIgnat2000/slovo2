# Демо-файл прогресса

`slovo2-demo-progress.json` — готовая выгрузка для загрузки в **пустую базу**
(свежая установка или экран «Прогресс не удалось открыть» → «Загрузить копию
из файла»). Формат совпадает с файлом родительского раздела
(«Родителям» → «Прогресс» → «Сохранить файл»):

```json
{ "profiles": [Profile, ...], "activeId": "p_demo_sonya", "settings": { ... } }
```

## Как загрузить

1. Открыть приложение с пустой базой.
2. **Родителям → Прогресс → Загрузить файл** (или кнопку загрузки на экране
   сбоя хранилища) и выбрать `slovo2-demo-progress.json`.
3. Подтвердить замену: пустые профили уходят в корзину, демо-профили становятся
   активными. Откат возможен тем же разделом — копии не удаляются.

## Что внутри

Два правдоподобных ученика с разной историей. Точные цифры в файле зависят
от даты генерации (таймлайн привязан к календарю) и печатаются в консоли
командой `npm run demo:progress`; структура стабильна:

| | Соня (2 класс) | Миша (3 класс) |
|---|---|---|
| История | ~43 учебных дня за 54 календарных, длинная серия дней | ~40 учебных дней за 50, серия короче |
| Слова | бóльшая часть освоена, несколько слов «в работе», ~четверть не тронута | то же, доля не тронутых выше |
| Уроки | 12 из 16, короны до 5-го уровня | 8 из 13 |
| Кристаллы | положительный баланс (~150–250 💎), видно на главном экране | положительный баланс (~150–200 💎) |
| База | электронная научная база + машина и костюм в её стиле | электронная база |
| Магазин | по 20–27% каждого раздела: наряды, авто, самолёты, корабли, телефоны, питомцы, спорт, вкусняшки | то же, более дешёвые позиции |
| Прочее | музыка, наборы звуков, оттенки, «Мой мир», мечты, костюмы-пазлы (часть собрана, один в работе), облики сундука | музыка, звуки, оттенки, «Мой мир», костюмы-пазлы, облики сундука |

Покупки занимают **20–45% каждого раздела** магазина — витрина выглядит
наполовину собранной, но в ней остаётся к чему стремиться. Баланс кристаллов
положительный: алмазы видно на главном экране и в магазине.

Правдоподобность достигается не ручной разметкой, а симуляцией: SRS-состояния
слов посчитаны через `engine/srs`, серия дней и заморозки — по правилам
`touchDay`, фрагменты пазлов — через `awardLessonPiece`, недельные награды —
через `settleWeeklyRewards`, задания и сундуки — через `buildDayPlan` и
`rollChest`. Временные метки растянуты по реальным календарным дням, XP профиля
равен сумме дневного XP, а учебные сессии живут только последние 30 дней.

## Перегенерация

```bash
npm run demo:progress
# свой путь к файлу:
DEMO_OUT=/tmp/slovo-demo.json npm run demo:progress
```

Команда собирает генератор (`scripts/demo/*.ts`) через esbuild, пишет JSON и
сразу прогоняет его через настоящий стор в jsdom (`replaceAll` + все санитайзеры
импорта): если хоть одно поле не переживает загрузку в пустую базу, команда
падает. RNG детерминированный — повторный запуск в тот же день даёт байт-в-байт
тот же файл.
