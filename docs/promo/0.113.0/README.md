# Биомы и первые открытки 0.113.0

`biomes-preview.webp` — все пять фонов в одном кадре, по порядку:

1. школьный двор — `school`;
2. лес — `forest`;
3. тёплый дом — `home`;
4. зима — `winter`;
5. город — `city`.

`postcards-preview.webp` — первые десять открыток 2 класса: «Школа», «В школе»,
«Птицы», «Звери», «Еда», «Сад и ягоды», «Город», «Наша страна», «Дом и вещи»,
«Труд». Оставшиеся шесть — волна A2.

Игровые файлы лежат в `src/assets/trail/*.webp` (960×360) и
`src/assets/postcards/*.webp` (640×360). Превью — только для просмотра и не
входит в precache. Исходные 16:9-кадры — в `images-src/` (папка вне Git).
