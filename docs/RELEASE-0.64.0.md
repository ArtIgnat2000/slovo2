# 0.64.0 — «е» вместо «ё» при письме

Отклик с телефона: **«на ряде слов с буквой Ё выяснилось, что этой буквы нет
на виртуальной клавиатуре. Поэтому, видимо, нужно считать правильным букву Е»**.

## Что оказалось на самом деле

Клавиша **«ё» в раскладке есть** — она стоит первой в третьей строке, как на
стандартной мобильной русской клавиатуре (это проверяет новый тест по всем
словам банка). Но ребёнок её не находит: на системных клавиатурах «ё» часто
спрятана под долгим нажатием на «е», а в нижней строке из одиннадцати клавиш
она теряется. В результате слово «берёза» становится нерешаемым именно на
письме, хотя ребёнок знает, как оно пишется.

## Решение

В заданиях **«Напиши слово»** и **«Зрительный диктант»** буква **«е» вместо
«ё» засчитывается как верный ответ**. Правило живёт в одном месте —
`sameTypedWord()` в `src/engine/word-facts.ts`:

```ts
sameTypedWord('береза', 'берёза') // true
sameTypedWord('Берёза', 'берёза') // true
sameTypedWord('учёник', 'ученик') // false — лишняя «ё» остаётся ошибкой
```

Обратной замены нет: «учёник» — это не прихоть раскладки, а другая буква,
поэтому ошибка. Регистр и пробелы по краям, как и раньше, не важны.

## Что при этом не изменилось

* В заданиях **с выбором буквы** («окошко», «исправь робота») ё остаётся
  единственно верной: там ребёнок видит варианты и учится различать е/ё, а не
  борется с клавиатурой.
* После ответа полоса вердикта по-прежнему показывает **правильное написание**
  (`берёза`) с подсвеченной опасной буквой — даже если ребёнок набрал «береза».
  Так он видит образец, а не только «✓».
* Клавиша «ё» остаётся в раскладке: кому удобно — тот ей пользуется.

## Проверки

`tests/typing-ui.test.tsx` (входит в `npm run test:smoke`, 8 проверок):

* все буквы **всех 257 слов банка** есть на экранной клавиатуре — страж от
  повторной потери «ё»;
* клавиша «ё» есть в раскладке;
* «береза» → «берёза» — верно, «Берёза» с пробелами — верно,
  «ученик» — верно, «учёник» — ошибка;
* живое задание «Напиши слово» с вводом «береза» получает `✓` и полный балл 5.

Контур: `typecheck`, `test:smoke`, `test:guard`, `test:icons`, `test:content`,
`test:adaptive`, `audit:storage`, `demo:check`, `content:check`,
`images:report -- --strict`, `release:check`, `build`, `test:boot`,
`test:release`.
