# 0.88.5 — четыре пары фотосерии, старт приоритета 3

## Что сделано

- Четыре новые полные пары: `glasses-round` (пересъёмка после брака 0.88.4),
  `beads`, `bag`, `brooch-flower`. Итого **16 из 38** нарядов с фото.
- Кадры самостоятельные, без увеличенных кропов:
  - круглые очки — фронт три четверти на подставке, дужки за линзами;
    второй кадр — честный профиль: ободья ребром, шарнир с винтами,
    изгиб дужки и круглые наконечники;
  - бусы — вся нитка на Т-подставке, застёжка сверху; второй кадр — плоская
    раскладка широкой дугой, открытая застёжка-бочонок и узлы шнура
    в фокусе на переднем плане;
  - сумочка — фронт три четверти, замок-сердечко; второй кадр — сверху
    с открытым и отвёрнутым клапаном: подкладка, кармашек, изнанка замка;
  - брошь-цветок — лепестки и тычинки в фокусе; второй кадр — оборот:
    фетровая основа, булавка с замком, пучок проволок тычинок.
- Одна студия: нейтральный тёпло-серый задник, мягкий свет сверху-слева,
  4:3, предмет целиком в кадре с полями, без надписей и логотипов.
- Сборка штатная: `node scripts/make-product-images.mjs` → 1200×900 WebP.
  В `public/products/` теперь 83 фото, в `public/products/gallery/` — 32.

## Забраковано

`badge-cat`: главный кадр хорош (эмалевый значок с котиком), а на втором
кадре вместо одного значка ребром и оборотом вышли две накладки, стоящие
рядом с зазором. Это нарушает правило «один предмет в кадре», поэтому пара
не пошла в репозиторий и лежит в `images-src/products-pending/`.

## Как проверено

- `npm run test:galleries` — 12/12: пары полные, второй кадр не байтовая
  копия главного, размеры 1200×900, лишних файлов в `gallery/` нет.
- Все пары просмотрены на контакт-листе до конвертации: один свет, один
  задник, один масштаб, разные ракурсы, предметы не обрезаны рамкой.
- `npm run typecheck`, `npm run build`, `npm run release:check`.
