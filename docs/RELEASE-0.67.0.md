# 0.67.0 — главная в один экран: «Дальше» и раскрывающийся путь (вариант B)

Реализован **вариант B** из аудита
[`docs/proposals/ui-cleanliness.md`](./proposals/ui-cleanliness.md): главная
перестала быть длинной лентой уроков.

## Что было

Под героем лежали **все уроки класса** — 13–16 одинаковых строк, два с лишним
экрана прокрутки. Ребёнок видел «начни здесь», а дальше — стену. Замер из
аудита: 28 кнопок на главной, путь ≈ 1,5 тыс. px.

## Что стало

```
🦊 Маша                      💎 64   ☰
Задания дня · 2 из 3                 →
СЕГОДНЯ
📚 Школа · 4 из 8 слов
[            Начать ▶            ]
Мой путь · 2 класс
📚 Школа          4 / 8 слов     ▶
👩‍🏫 В школе        0 / 5 слов     ▸
🐦 Птицы          2 / 5 слов     ▸
[      Весь путь · 16 уроков ⌄      ]
🤝 Позови друга
```

* **«Дальше» — три ближайших урока**, первый из них текущий (`.node-btn.current`).
  Если ребёнок в конце программы, показываются последние три — «дальше» не
  бывает пустым;
* **«Весь путь · N уроков»** раскрывает все уроки класса ровно один раз, без
  дублей; повторный тап сворачивает. `aria-expanded` и `aria-controls` честные,
  зона кнопки 48 px;
* состояние **не запоминается**: новый день — снова короткая главная;
* **«Позови друга»** осталось на главной в один тап (решение 0.32.1), но ушло
  ниже пути: приглашение — не ежедневное действие и рядом с «Начать ▶» спорило
  за внимание.

## Чего в этом релизе нет

В разборе у варианта B были ещё два пункта, которые **не** вошли в релиз:

* кнопки режимов на карточке списка к контрольной (свернуть в «Ещё…») — это
  трогает путь контрольной, к нему вернёмся отдельно;
* перенос «Заданий дня» — строка и так одна.

## Проверки

Новый `tests/home-path.test.tsx` — 16 проверок в смоуке:

* кнопка «Весь путь · N уроков» есть и называет число уроков класса;
* свёрнуто — не больше **трёх** уроков, и первый из них текущий;
* свёрнутый список короче программы (иначе экономии нет);
* раскрытие показывает **все** уроки класса без дублей, `aria-expanded="true"`,
  кнопка предлагает свернуть;
* повторный тап возвращает свёрнутое состояние;
* «Позови друга» осталось на главной и стоит **ниже** пути;
* раскрытие пути не меняет профиль.

Тестам, которые считают уроки класса, добавлен хелпер `expandPath()`
(`tests/ui-helpers.ts`) — он идемпотентно раскрывает путь. Обновлены
`tests/classes.test.ts` (путь 1/2/3/4 класса) и `tests/adaptive-ui.test.tsx`
(перебор уроков в поисках сборки).

Контур: `typecheck`, `test:contrast`, `test:smoke` (864 проверки), `test:guard`,
`test:icons`, `test:content`, `test:adaptive`, `audit:storage`, `demo:check`,
`content:check`, `images:report -- --strict`, `release:check`, `build`,
