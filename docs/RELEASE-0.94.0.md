# 0.94.0 — «Филворд» в «Играх»

Первая из буквенных механик из proposal §5 (этап «Сначала простое»): жанр,
который ребёнок уже встречал (Учи.ру «Хранители слов»), прямой тренажёр
орфографии-распознавания. «Кроссворд дня» остаётся «скоро».

## Что добавлено

- **Новая игра «Филворд»** во вкладке «Игры», под «Собери слово»: поле из
  изученных слов класса (та же выборка, что у «Собери слово»).
- **Поле 8×8** (1–3 класс) или **9×9** (4–5 класс, диагонали разрешены);
  если в срезе почти нет коротких слов, поле честно вырастает до 12×12 —
  вместо пустого экрана.
- Движок `src/engine/word-search.ts` (без DOM): детерминированное поле из
  `seed`; спрятаны до 7 слов (сначала длинные), пересечения по общим буквам,
  добивка свободных клеток по частотам русских букв; фразы в сетку не берутся.
- Управление: **ведём пальцем** (прямые линии: горизонталь/вертикаль,
  5 класс — ещё диагонали) или **двумя тапами** (первая и последняя клетка).
  Промах ничем не наказывается: линия мягко краснеет и отпускается.
- Каждое слово показано **чипом**: emoji + само слово, **опасные буквы
  оранжевым**; найденное слово зеленеет с ✓. Это тот же «крючок орфограммы»,
  что в уроках.
- Клавиатура и скринридер: клетка — кнопка, Enter ставит якорь и завершает
  линию; счётчик «Найдено: N из M» с `aria-live`.
- **Без XP и без SRS** — рамка «Игры» сохранилась: чистое повторение,
  ничего не сгорает и ничего не считается.
- «Новая сетка» (🔄) — новый seed и чистое поле; после победы — «Ещё сетку».
- Если изученных слов не хватает (< 3): честная заглушка с кнопкой «К урокам».

## Известные ограничения

- 4–5 класс ищет по диагонали, 1–4 — только горизонтали и вертикали (так
  задумано в proposal §5-C; для младших диагонали сложнее чтения).
- Очень длинные слова (> размера поля) не прячутся; поле вырастает до 12×12.
- Фрагменты словарных фраз на поле не идут.
- Проверка на детях ещё не проводилась — механика включена как свободная
  игра; «Кроссворд» остаётся «скоро — проверяем на детях».
