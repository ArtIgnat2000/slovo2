# 0.75.2 — починка после слияния #141: проверки магазина и деплой

## Что изменилось

- После слияния PR #141 (`main` → 3118898) смоук-тест падал на первом же обращении к снятому чипу «Костюмы», поэтому сборка GitHub Pages не собиралась. Проверки приведены в соответствие с новой структурой полок, ничего в поведении приложения не менялось.
- UI-проверки пазлов открывают костюмы на полке «Наряды»: полки нарядов и костюмов объединены, отдельного чипа «Костюмы» больше нет.
- Проверка порядка цен в «Нарядах» смотрит на витрину нарядов, а не на всю секцию: рядом с ней теперь живут витрины «Костюмы · пазлы» и «Костюмы за кристаллы», каждая со своим возрастающим порядком цен.
- Вкладки техники проверяются без питомцев, спорта и вкусняшек; добавлены проверки, что эти три категории стали самостоятельными полками магазина, показывают только свои товары и сортируют их по возрастанию цены.
- Версия поднята до 0.75.2, чтобы пройти обязательную проверку релиза, которую PR #141 не прошёл.

- `npm run typecheck`, `npm run build`, `npm run test:smoke`
- `npm run test:release`, `PR_TITLE='v0.75.2 — починка проверок магазина после слияния #141' npm run release:check -- origin/main`
