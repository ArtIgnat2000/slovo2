# 0.93.0 — «Слово с заглавной?» для родительских списков

Закрыт открытый вопрос из §10 `docs/proposals/mekhaniki-bukv.md`: свои слова
из списков к контрольной больше не теряют заглавную первую букву.

## Что было не так

Свои слова из чата класса («Пушкин», «Московская область», «Жостово») проходили
через `normalizeCustomText` и становились строчными, если заглавная только
первая. Банку это не мешало (матч по ключу находит карточку из банка), но вновь
созданное имя собственное ребёнок учил с маленькой — ровно та же дыра, что в
0.91.1, только на стороне родительских списков.

## Что сделано

* В **предпросмотре нового списка** у каждого своего слова появился
  переключатель **«С заглавной»** (по умолчанию выкл — регистр решает родитель,
  а не автоматика; так же нельзя отличить «Прощайте» от «Пушкина»);
* там же показано текущее состояние: «пишется с заглавной» / «все строчные»;
* то же переключение доступно **после сохранения** — в разделе «Свои слова»
  (тап ставит/снимает заглавную первой буквы);
* переключение **не меняет id слова** (слаг строится по нижнему регистру) —
  прогресс по слову в SRS не теряется;
* внутренние заглавные не трогаются («Иван Иванович» остаётся как ввели);
  имя из нескольких слов получает заглавную только у первого слова;
* снятие переключателя возвращает строчную первой буквы;
* ударение и «опасные» буквы переключение не сдвигает;
* банковские слова не затронуты: у них свой регистр, и он не переключается.

## Как это выглядит для ребёнка и родителя

Родитель вставляет список из чата класса, видит предпросмотр, тапает
ударение и — для имён собственных — переключатель «С заглавной». Ребёнок
получает карточку «Пушкин» и пишет его с большой буквы (для письменных
заданий действует механика 0.91.1 с клавишей «⇧»). Если о регистре вспомнили
позже — правится одним тапом в «Свои слова», прогресс не теряется.

## Проверки

`npm run release:check` (0.92.0 → 0.93.0), `npm run typecheck`, `npm run test:smoke`
(все проверки пройдены; новые: юнит-`withCapital` — стабильность id, ударения,
опасных букв и внутренних заглавных; UI — переключатель в предпросмотре и в
«Свои слова», сохранение и снятие регистра), `npm run test:release`,
`npm run test:content`, `npm run content:check`, `npm run build`, `npm run test:boot`.

## Известные ограничения

* Переключатель один на слово: «красная площадь» внутри списка получит
  заглавную только у первого слова. Фраз целиком с заглавной в письменные
  задания всё равно не идут (нет клавиши пробела), а банк с фразами
  («Красная площадь») регистр хранит сам.
* Уже сохранённые строчные «пушкин» в старых списках не переписываются
  автоматически: родитель переключает регистром в «Свои слова» осознанно.
