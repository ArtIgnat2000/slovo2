# 0.83.0 — фотореализм закрыт: электроника целиком

Последняя партия контентной работы, начатой в 0.77.0. Раздел электроники снят
целиком, поворот телефонов ушёл из кода. Всего в магазине **67 снимков**.

## Что изменилось

- **Последние три позиции раздела.** «iPhone 18 Pro Max» — тёмно-бордовый
  аппарат с широким плато камер и стеклянным окошком; «Домашний кинотеатр» —
  телевизор с тонкой рамкой, на экране живое горное озеро; «Серебряный Max» —
  наушники с сетчатым оголовьем, мягкими амбушюрами и полированными чашками.
- **Вращение телефонов удалено.** Снимок — один кадр, крутить нечего, поэтому
  из `ElectronicsArt` убраны `useState`, `isRotatingPhone`, двухсторонний
  `phone-turntable` и подсказка «нажми на телефон — он повернётся». Из CSS
  ушли правила поворота и рамки экрана; подпись под артом переименована в
  `.art-hint` — она осталась для машин («нажми на машину — рассмотри кузов
  ближе»).
- `public/electronics/phone-front.webp` (экран для второй стороны) удалён:
  он был нужен только повороту. Сами 3D-спинки остались в `public/electronics`
  запасным вариантом, если снимок у товара не найдётся.

## Проверки

- `tests/electronics-art.test.tsx`: у каждой позиции раздела есть снимок —
  тест падает, если хоть один товар вернётся к 3D-арту; отдельно проверяется,
  что поворотных телефонов в разметке больше нет, а `phone-front.webp` не
  вернулся.
- `tests/smoke.test.tsx`: вместо проверок поворота — «телефон больше не
  притворяется поворотным»; полка по-прежнему считается как «арт + фото = 11».
- `scripts/demo-render-check.mjs`: вместо четырёх поворотных телефонов
  проверяются четыре снимка на витрине.
- `npm run typecheck`, `npm run build`, `npm run test:smoke`, `test:boot`,
  `test:guard`, `test:contrast`, `test:release` — зелёные.
