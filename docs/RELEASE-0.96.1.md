# 0.96.1 — «Игры»: шапка без лишних слов, счётчик над полем

Патч по скриншоту владельца (iPhone, «Игры» → «Кроссворд»): «избыток слов в
шапке страницы, исправить эргономику». На снимке над игрой стояли четыре
этажа текста — заголовок, правило «ничего не сгорает» в две строки, сегмент
игр в две строки на кнопку, описание игры — и только после них начиналось
поле. Ниже поля, в свою очередь, уезжали под нижнее меню строка состояния
(«Собрано: 0 из N») и подсказки-вопросы.

## Что изменено

- **Шапка — одна строка.** Осталось «🧩 Игры». Правило «Играй сколько хочешь:
  ничего не сгорает и ничего не считается» переехало в `title` заголовка
  (взрослому доступно, у поля высоту не отнимает), описание игры — в
  скрытую подпись кнопки сегмента (`sr-only`), так что скринридер слышит
  «Собери слово. Выложи слово из карточек» как раньше. Абзац `.games-oneline`
  удалён.
- **Сегмент игр — в одну строку:** эмодзи и название рядом, а не в два
  этажа. Высота пункта 44–46 px, цель пальца сохранена.
- **Инструкции убраны из карточек филворда и кроссворда.** «Тапни букву — она
  встанет в выбранное слово…» и «Найди все слова…» больше не занимают две
  строки над полем: игра объясняет себя сама (выбранное слово подсвечено,
  буквы лежат в пуле). Это две строки чистого выигрыша по высоте.
- **Строка состояния — над полем.** «Найдено: N из M» / «Собрано: N из M» и
  кнопка «🔄 Новая сетка» переехали ПЕРЕД полем: под полем их съедало нижнее
  меню. Кнопка стала компактной (`.btn.ghost.sm`, 40 px).
- **Кроссворд, эргономика поля:** клетка больше не растягивается на всю
  карточку — потолок 42 px (38 px на узком телефоне, 48 px на планшете),
  решётка стоит по центру, кегль буквы считается от клетки. Раньше решётка
  8–9 клеток давала 60+ px на клетку и вытесняла пул букв и вопросы за экран.
- **Пул букв крупнее и ровнее:** плитка 36×42 px на телефоне (было 44×48 при
  432 px полезной ширины — пул переносился на две строки и обрезался).
- **Подсказки-вопросы — в два уровня:** эмодзи + (значение сверху, «N букв»
  тихо под ним). Раньше четыре колонки в сумме были шире карточки, и текст
  обрезался многоточием.
- **Одна прокрутка вместо двух:** у списка вопросов убрана собственная
  `overflow-y` (было `max-height: 168px` / `132px` при 44 px на чип — влезало
  три вопроса). Теперь список живёт в общей прокрутке сцены.

## Что НЕ трогали

- Движки (`crossword`, `word-search`, `word-board`), правила «ничего не
  считается», XP/SRS, контент слов — без изменений.
- Те же проверки, что и раньше: ничего не сгорает, «е» за «ё» и т. д.

## Проверки

`npm run typecheck`, `npm run test:smoke` (обновлены проверки шапки: правило
рамки доступно из `title`, абзаца-описания нет; новые: счётчик стоит над
полем у филворда и кроссворда, подсказка и длина слова — двухуровневый текст
чина), `npm run test:contrast` (16 тем, 288 пар), `npm run build`,
`npm run test:boot`.
