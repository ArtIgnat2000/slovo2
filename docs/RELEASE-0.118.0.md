# 0.118.0 — игры: витрина и игра больше не спорят за экран

Замечание владельца по скриншоту вкладки «Игры»: одновременно были видны
заголовок, баннер «Тропы», переключатель «Быстро / Подумать», шкала дня,
сетка карточек, рекорды и само поле игры. Кроссворд при этом обрезался, а
буквы уезжали под нижнее меню. «После выбора игры надо оставить только игру.
Остальное только мешает».

## Что стало

**Два режима вместо одной свалки.**

* **Витрина.** Все восемь игр на одном экране двумя секциями — «⚡ Быстро»
  и «🧠 Подумать». Переключателя групп больше нет: не нужно угадывать, в
  какой вкладке лежит игра, и ни одна карточка не прячется за краем.
  Счёт открытых — тихая цифра в шапке, условие дня — одна строка.
* **Карточка.** Одна строка «эмодзи + название», высота 50 px (цель для
  пальца). Условие замка больше не выводится обрезанным текстом в карточке:
  оно живёт в `aria-label` и всплывает спокойной плашкой при тапе. Замок —
  нейтральный, без «нельзя» и красного.
* **Рекорды.** Блок «Собери N из M» убран из-под ног: он стоит внизу
  витрины, а не над игровым полем.
* **Экран игры.** После выбора витрина уходит целиком. Остаются компактная
  шапка «← Игры · название игры» и поле на всю доступную высоту. Нижнее
  меню на время игры скрыто (`body.game-focus`), поэтому поле не уезжает под
  вкладки и не обрезается. Выход — «← Игры», фокус сразу на нём.
* **Тропа слов** осталась отдельным входом на витрине (не девятой карточкой)
  и тоже получает full-screen режим без нижнего меню.
