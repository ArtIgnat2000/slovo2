# Релиз 0.8.0 — подготовлен к публикации

## Изменения (поверх 0.7.0)

* **V-labs — внутренний раздел о школе:** промо-блоки на Главной («Слово2 сделали в V-labs») и в Родителям ведут на экран `VlabsScreen` внутри приложения (не внешняя ссылка). Scratch выделен первым (7–12 лет, с нуля, каждый урок — проект), остальные курсы — компактными чипами (Scratch Jr, Roblox Studio, Нейросети, Kodu, КОМПАС-3D, комп. грамотность/дизайн). CTA копирует `https://t.me/VLabsV` и открывает в новой вкладке, возврат — `← Назад в Слово2` (офлайн-first, без iframe).
* **Короткий урок по умолчанию:** `DEFAULT_LESSON_SIZE` `standard(16)` → `short(12)`; fallback 16→12; новые профили создаются с `short`. Адаптивный контроллер 8..потолок без изменений.
* **Фикс Android:** кнопка выхода `✕` в уроке — `48dp` `.lesson-exit`, `touch-action:manipulation`, расширенная хит-зона, дублирование `onTouchEnd`/`onClick` (проверено смоук-тестом диалога выхода).

Checkpoint, озвучка и числовой слайдер не входят.

## Проверки и ограничения

Локально: typecheck, content:check, test:adaptive, test:smoke, build, test:boot — всё зелёное. PR `Release checks` гоняет тот же набор без деплоя. Мобильные замеры A+B — по-прежнему после деплоя по протоколу `perf-audit.md`.

## Публикация и проверка версии

1. Дождаться зелёного `Release checks` в PR ветки `arena/01a0ecde-slovo2` → `main`, слить PR.
2. Дождаться успешного **Deploy to GitHub Pages** для коммита слияния.
3. Открыть https://artignat2000.github.io/slovo2/ → «Родителям» → «Версия».
4. Ожидается **v0.8.0 · <SHA опубликованного коммита>**. SHA сверять с успешным запуском Deploy.
5. Перед обновлением закончить урок. При старой версии — закрыть/открыть с сетью, применить предложенное обновление. Не очищать данные сайта (прогресс локальный).
