# 0.107.0 — быстрый вход во все игры для проверки

Мелочь для проверки игр на телефоне и в песочнице: чтобы открыть «Цветок
слова», приходилось закрывать весь план дня. Шкала доступа работает как
задумано, но разработчику она мешает смотреть игры.

## Где это теперь

Два места, **без нового кода в игровом экране**:

1. **Родителям → Настройки → «Игры за успехи» → «все открыты»** — это было и
   раньше (0.99.0), работает в любой сборке, в том числе на телефоне.
   Рекомендую именно этот путь: это настоящая настройка взрослого, и ребёнок
   потом видит ровно то, что должен.
2. **Родителям → Приложение → «🔓 Открыть все игры»** — новая кнопка одного
   тапа, рядом с версией и обновлениями. Включает ту же самую настройку
   (`gamesGates: 'open'`) и умеет вернуть шкалу обратно.

## Кому видна кнопка

Только там, где это нужно разработчику:

* `npm run dev` — всегда;
* любая сборка с `?dev=1` в адресе — так проверяют прод-бандл и песочницу.

В обычном установленном приложении на телефоне кнопки нет: это переключатель
доступа ребёнка к играм, и он не должен появляться случайным тапом. Ребёнок
адрес `?dev=1` не набирает.

## Быстрый вход в песочнице

Открыть превью с параметром `?dev=1` → «Родителям» → решить пример →
«Приложение» → «🔓 Открыть все игры» → «Игры»: все восемь игр доступны.

Можно и вовсе без этой кнопки: `npm run dev` показывает панель сразу.

## Что не менялось

Сама шкала доступа (`engine/game-access.ts`) и её тексты, экран игр, награды,
SRS, контент и хранилище. Новая панель только вызывает существующую настройку
`setSettings({ gamesGates })`.
