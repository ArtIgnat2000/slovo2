# 0.89.0 — фото нарядов наконец видно на витрине

## Зачем

Жалоба: «не нашёл в программе все выложенные товары и фото — очки, шляпа и
прочее». Фото лежали в `public/products/` и `public/products/gallery/`, но
витрина про них не знала: карточка наряда рисовала сову в этой вещи, а на
96 px корона, очки или брошь на сове почти не читаются — вещь выглядела
отсутствующей.

## Что сделано

- Новый файл `src/ui/PhotoPair.tsx`:
  - `OUTFIT_PAIRS` — 16 полных пар (id → второй кадр и подпись ракурса);
  - `hasOutfitPair`, `warmOutfitPair`, `OutfitPhoto` (главный кадр для ниши),
  - `OutfitPhotoTour` — просмотр пары: кадр, подпись, счётчик «1 / 2»,
    переключение тапом (тот же жест, что у `TechTour`).
- Витрина: в нише карточки наряда с парой — студийный снимок вместо совы.
  У вещей без пары остаётся прежний рисунок, сова в вещи никуда не делась
  (примерка в листе, гардероб, «Мой мир»).
- Подробная карточка: у наряда с парой вместо крупной совы — два кадра.
  Подпись кадра — название товара, счётчик показывает, что кадров два.
- Тёплый старт: оба кадра качаются в момент тапа по карточке, лист
  открывается без «сначала размыто».
- Перекрашивание: у наряда с фотопарой палитра «🎨 Цвет» скрыта — по
  готовому снимку краски не нарисовать, а брать 💎 за невидимый оттенок
  нельзя. То же правило уже действует для техники с фото. У остальных
  нарядов краски работают как раньше.

## Почему пары не добавлены в `PRODUCT_PHOTOS`

Тот список включает режим «фото вместо арта» целиком и заодно отключает
перекрашивание. Наряды красить по-прежнему можно (у 22 вещей без пары),
поэтому пары живут своим списком, а витрина спрашивает `hasOutfitPair`.

## Проверки

- `npm run test:galleries` — 13/13. Новый тест `каждая полная пара нарядов
  подключена к витрине`: список показа сверяется с файлами на диске, второй
  кадр не может вести на чужой файл, а витрина обязана пользоваться списком.
  Сгенерировали пару и забыли подключить — тест падает.
- `npm run test:smoke` — добавлены четыре проверки: снимок в нише карточки,
  пара кадров в листе, переключение тапом на второй ракурс со счётчиком
  «2 / 2», закрытие листа по затемнению. Прогон зелёный целиком.
- `npm run typecheck`, `npm run build`.

## Ограничение

Фото есть у 16 из 38 нарядов. Остальные 22 рисуются вектором, пока для них не
сгенерированы пары: смешивание фото и рисунков на полке «Наряды» — осознанный
компромисс, иначе 16 готовых снимков оставались бы невидимыми. Следующие пары
подключаются одной строкой в `OUTFIT_PAIRS`.
