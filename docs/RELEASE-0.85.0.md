# 0.85.0 — интерфейс без лишнего текста

Проведена ревизия текстов на основных детских, родительских и служебных
экранах. Повторные объяснения, очевидные инструкции и вторичные показатели
убраны; действия, цены, предупреждения и юридически важные сведения сохранены.

## Что изменилось

- **«Родителям» — главное сразу.** Первый экран показывает прогресс слов и
  повторные ошибки. Статистика дня и недели открывается по запросу; игровые
  достижения, таблица классов и повторные сводки больше не конкурируют с
  учебным результатом.
- **Сложное раскрывается постепенно.** В настройках расширенные параметры
  свёрнуты. В «Данных» сразу видны резервная копия и состояние сохранения, а
  восстановление, журнал и сбросы находятся в подписанных раскрываемых блоках.
  В «Приложении» технические сведения и информация о создателях также скрыты
  до запроса.
- **Короче детские экраны.** Словарик получил одну сводку «Знаю / Учу /
  Новые» без повторных процентов и итогов в каждой колонке. Итог урока,
  рейтинг, меню, выбор ученика, магазин и «Мой мир» очищены от пояснений,
  которые повторяли уже видимые цифры или действия.
- **Без дублирующих входов.** «Позови друга» остаётся на главной, но больше не
  повторяется на экране профилей. В обзоре родителей нет второй карточки входа
  в списки к контрольной — для них есть отдельная вкладка.
- **Редкие сведения не потеряны.** Лицензии музыки доступны по кнопке,
  предупреждения перед импортом, восстановлением и сбросом сохранены. Пустая
  полка «Мечты» не показывается до добавления товара.
- **Компактные служебные тексты.** Сокращены ответы проверки обновлений,
  уведомления звука, приглашение, выбор класса и страница V-labs.

## Проверки

Текстозависимые smoke/UI-проверки обновлены под новую иерархию и отдельно
фиксируют отсутствие прежних дублей. Выполнены `npm run typecheck`,
`npm run test:smoke` и `npm run build`.
