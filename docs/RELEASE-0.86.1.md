# 0.86.1 — единый стиль фотогалерей

Продолжена серия технических товаров: галереи телефонов, кораблей и самолётов
теперь используют только студийные фотографии и фотореалистичные рендеры. У
всех 19 моделей по два самостоятельных изображения в согласованной нейтральной
подаче; рисованные иллюстрации и SVG-сцены в подробных карточках техники удалены.

Добавлены ракурсы для пяти самолётов научных баз и «Титаника». Галерея листается
тапом; мягкая смена кадра отключается системной настройкой уменьшения анимации.
Рекомендации по распространению фото-стандарта на остальные товары описаны в
[`docs/proposals/product-galleries.md`](./proposals/product-galleries.md).

## Проверки

`npm run test:adaptive`, `npm run test:smoke`, `npm run build`,
`npm run test:boot` и `npm run audit:storage`.
