# 0.69.0 — «Словарик 📖»: четыре цветные колонки, кольцо прогресса и легенда

Запрос: **«структурировать раздел словарь. По цветам — по степени освоения
слова. По каждой колонке подводить итог по количеству слов. Возможно, что и
круговая диаграмма будет кстати. Ещё нужна легенда, чтобы было понятно, что
означают эти цвета»**. Адресат — ребёнок 1–4 класса (7–10 лет), поэтому главный
вопрос экрана простой: **сколько слов я уже знаю и сколько ещё впереди**.

## Что было и что стало

| Было | Стало (0.69.0) |
|---|---|
| один длинный список слов с цветной точкой | **четыре колонки по цветам**: «Знаю», «Учу», «Трудные», «Новые» |
| сколько слов в каждой группе — надо считать глазами | **итог под каждой колонкой**: «Итого: 28 слов · 30 %» |
| нет общей картины | **кольцевая диаграмма** в центре: число выученных и «из 94» |
| цвета нигде не объяснены | **легенда** с названием, описанием и счётчиком каждого цвета |
| поиск по словам отсутствовал | поиск понимает «е» вместо «ё» и ищет по всем классам |

## Как устроено для ребёнка

* **Главный блок сверху** отвечает на вопрос одним взглядом: кольцо, в центре
  крупное число выученных слов и подпись «из 94», рядом две плашки —
  «✓ Уже знаю: 28» и «Осталось выучить: 66». Дроби со слэшем («28/94») нет
  намеренно: решение №3 из `docs/PLAN.md` — только целые числа и слова.
* **Легенда — не картинка, а кнопка.** Тап по цвету фокусирует одну колонку,
  повторный тап или «Все 4 колонки» возвращает все. Так ребёнок сам сужает
  выбор, когда ищет «что мне ещё учить».
* **Итог по каждой колонке** продублирован в её подвале: «Итого: 40 слов · 43 %».
  Проценты считаются от всех слов выбранного класса (или темы урока), а не от
  числа в колонке, — иначе 100 % в колонке «Трудные» читались бы как успех.
* **Длинные колонки свёрнуты** до 18 слов с кнопкой «Показать все N» — иначе
  экран превращался в бесконечную прокрутку и итог уезжал далеко вниз.
* **Тап по слову** открывает карточку с цветным бейджем статуса, картинкой,
  слогоделением и предложением; закрывается крестиком и клавишей `Escape`.
* **Все зоны нажатия — не меньше 48 px** (легенда, поиск, «Показать все»):
  это закреплено тестом, а не только стилями.

## Четыре цвета и правило попадания в них

| Цвет | Название | Правило | Ребёнку |
|---|---|---|---|
| 🟢 `good` | Знаю | `s ≥ 90` | «Отвечаю без запинки» |
| 🟠 `mid` | Учу | всё остальное | «Помню, но путаюсь» |
| 🔴 `weak` | Трудные | `wrong > 0`, `s < 40` | «Здесь я ошибался» |
| ⚪ `new` | Новые | записи нет или все счётчики нулевые | «Ещё не встречал» |

Группы взаимоисключающие и покрывают все слова: `good + mid + weak + new`
всегда равно общему числу слов в выбранной теме — это проверяет тест.

Попутно закрыт слепой угол: слово со счётом 11–39 и **нулём** ошибок раньше
выглядело как «новое» (записи нет), хотя ребёнок его уже видел. Теперь оно
попадает в «Учу».

## Что под капотом

* `src/engine/dictionary.ts` — новый чистый модуль без React: `wordBucket`,
  `buildDictionarySummary`, `buildDonutSegments`, `matchesWordQuery`,
  `safePct`, `columnTotalLabel`. Всё считается в одном месте, поэтому экран и
  тесты видят одинаковые числа.
* `src/ui/screens/WordsScreen.tsx` — экран переписан: шапка с классом и темами,
  кольцо, легенда, поиск, четыре колонки, лист слова.
* `src/styles/app.css` — блок `.dict-*` (кольцо, легенда, колонки, подвалы,
  бейджи) на токенах темы: работает во всех 5 стилях и в тёмной теме.
* `public/docs/dictionary-demo.html` — автономная витрина раздела одним файлом:
  переключатель трёх профилей (обычный прогресс / только начали / всё выучено),
  светлая и тёмная тема, пять стилей. Собрана из настоящего `WordsScreen.tsx`,
  открывается без сети и без установки зависимостей.

## Как пересобрать автономную витрину

```bash
# 1. собрать React-экран в один IIFE-бандл (esbuild уже в devDependencies)
#    вход — временный entry.tsx, который рендерит <WordsScreen /> с подставленным
#    профилем; alias модуля state/store на заглушку без IndexedDB
# 2. вставить бандл и CSS в один HTML и положить в public/docs/dictionary-demo.html
```

Файл — сгенерированный артефакт: править руками не нужно, после изменения
экрана его надо пересобрать.
