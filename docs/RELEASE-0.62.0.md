# 0.62.0 — белого экрана больше нет, у контрольной есть отчёт и три режима

Отклик: **«чем заканчивается контрольная? у меня просто белый экран, это баг.
Надо видеть детально результаты. Хорошо бы тренироваться на проблемных словах —
тяжело всем списком. Может, разделить тренировку и полный контроль всех слов»**.

Всё четыре пункта сделаны.

## 1. Белый экран — был настоящий баг. Найден и закрыт

**Причина:** экран результатов брал название урока из `LESSON_BY_ID[lessonId]`.
У урока-списка (`list:…`, `check:…`, `err:…`) записи в программе нет — там
`undefined`, и обращение к `lesson.emoji` падало с `TypeError`. React
размонтировал дерево: белый экран после последней карточки.

**Исправлено:** заголовок берётся из списка (`🏫`/`📋` + название), а если
списка нет — из урока или запасного значения. Теперь белого экрана не будет
ни на одном режиме.

**Проверка живая, не «по коду»:** в смоук добавлен прогон контрольной до конца —
открываем `check:<id>`, отвечаем, жмём «Далее» и убеждаемся, что появился отчёт
`[data-check-report]`. На старой версии этот тест падал ровно на белом экране.

## 2. Детальный результат контрольной

На экране результатов для списка теперь карточка **«📋 Результат контрольной»**:

* «Проверено слов» и «Верно N из M»;
* **слово за словом**: зелёные ✓ и красные ✗ — видно, что именно провалилось;
* кнопки **«Тренировать ошибки · N»** и **«Пройти заново»**;
* честная подпись: «Контрольная проверяет, а не учит: подсказок и отработки
  здесь нет — ошибки лучше отдельно потренировать».

Итог сохраняется в список (`lastCheck`), поэтому он виден и в «Родителям →
🏫 Списки» («контрольная 18 из 26»), и на карточке на «Уроках».

## 3. Три режима вместо одного

| Режим | Что делает | Подсказки |
|---|---|---|
| **Тренировка** (`list:…`) | часть слов (по размеру урока), с отработкой ошибок | да |
| **📋 Полный контроль** (`check:…`) | **все** слова списка, по одному заданию, порядок как в списке | нет |
| **🔁 Ошибки** (`err:…`) | только слова, проваленные в последней контрольной | да |

На карточке списка на «Уроках»: главная кнопка — «Тренировка · 12», под ней
**«📋 Полный контроль · все 26»** и, если есть провалы, **«🔁 Ошибки · N»**.
Те же три кнопки — в «Родителям → 🏫 Списки».

В режиме контроля подсказки **не рендерятся вовсе** (а не прячутся стилями):
`<TaskView noHints>` не показывает ни кнопку «Подсказка», ни мнемонику, ни
баннер «опасные буквы». Отработка ошибок в процессе тоже отключена — иначе это
уже не проверка.

## 4. «Пройти заново» действительно перезапускает

Раньше повторный запуск того же урока не пересоздавал экран (тот же `key`), и
ребёнок оставался на результатах. Теперь у экрана есть номер запуска
(`lessonId#N`), поэтому «Пройти заново» и «Тренировать ошибки» открывают урок
с нуля.

## Проверки

**13 новых проверок** в смоуке (по спискам теперь **74**), из них главные:

* живой прогон контрольной: открывается `check:<id>`, есть класс `lesson-check`,
  подсказок нет в DOM;
* после последнего слова **есть отчёт**, слово за словом, с `✗`;
* итог сохранён в `lastCheck` профиля;
* кнопка «Тренировать ошибки» появляется после провала;
* «Пройти заново» снова открывает контрольную;
* кнопка «Ошибки» на «Уроках» открывает `err:<id>`, и подсказки там снова есть;
* плюс прежние: пресет 26 слов, картинки, подсказки, ударения.

Полный контур: `typecheck`, `test:smoke`, `test:guard`, `test:icons`,
`test:content` (257 ударений банка + 40 словаря), `test:adaptive`,
`audit:storage`, `demo:check`, `content:check` (257/257),
`images:report -- --strict`, `release:check` (0.61.1 → 0.62.0), `build`,
`test:boot` — зелёные.

## Как пользоваться

1. **Уроки** → карточка списка → **«📋 Полный контроль · все 26»**.
2. Проходите все слова (подсказок нет — это проверка).
3. В конце — отчёт по словам и кнопка **«Тренировать ошибки · N»**.
4. Потренировали — снова «Полный контроль». Список длиной 26 больше не нужно
   проходить целиком ради двух трудных слов.
