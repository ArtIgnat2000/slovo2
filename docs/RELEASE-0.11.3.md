# Релиз 0.11.3 — крупная картинка в упражнениях

* Дата: **2026-10-07**
* Ветка: `arena/6ef79b62-slovo2` → `main`
* Предыдущий релиз: [`0.11.2`](./RELEASE-0.11.2.md)
* Диагностика после деплоя: `?diag=1` должна показать **v0.11.3**

Патч-релиз по уточнению со скриншотом iPhone: маленькой оставалась картинка не
на знакомстве со словом, а внутри упражнения «Собери слово из букв».

## Что изменилось

1. **«Собери слово» и «Исправь робота» получили hero-компоновку.** Картинка
   расположена над предложением и увеличивается до 220 px вместо прежних 104 px.
2. **«Напиши слово» и зрительный диктант сохраняют компактную горизонтальную
   компоновку**, чтобы не вытеснять экранную клавиатуру, но картинка увеличена до
   144 px.
3. **На экранах высотой до 680 px** hero-карточка автоматически становится
   горизонтальной с картинкой 96 px. Слоты, буквы и действия остаются в пределах
   экрана урока без вертикальной прокрутки.
4. `WordClue` поддерживает явные варианты `inline` и `hero`; размеры вынесены в
   токены `--art-clue` и `--art-clue-hero`.
5. Смоук-тест отдельно рендерит упражнение `build` и защищает новую компоновку от
   случайного возврата к маленькой боковой иконке.

## Проверки

Перед публикацией прошли:

* `npm run typecheck`;
* `npm run test:smoke`;
* `npm run build`;
* `git diff --check`.

## Проверить после деплоя

1. Открыть `?diag=1` и проверить версию **v0.11.3**.
2. В упражнении «Собери слово» на обычном iPhone картинка должна находиться над
   примером и занимать заметную часть карточки.
3. На коротком экране карточка должна стать горизонтальной; слоты, буквы и кнопка
   подсказки не должны обрезаться.
4. В «Напиши слово» клавиатура должна полностью помещаться, а картинка — быть
   крупнее, чем в 0.11.2.
