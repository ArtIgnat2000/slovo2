# Релиз 0.26.1 — серверная часть: план, варианты и пилотный API

## Что изменилось

**Продукт почти не изменился.** Основное — документация и отдельный
пилотный сервер: приложение по-прежнему работает офлайн, без аккаунтов
и без сети. Единственная правка интерфейса — исправление старого дефекта
магазина (см. §3).

### 1. План серверной части и классных соревнований

[`docs/proposals/backend-social-plan.md`](./proposals/backend-social-plan.md) —
проработанный ответ на запрос «видеть результаты класса, соревноваться,
школа, аналитика для разработчиков, Synology или недорогое облако»:

* три плоскости (учёба локально, социум, анонимная телеметрия) и правило
  «ни один экран учёбы не ждёт сеть»;
* пересмотр решения №5: закрытые соревнования по согласию, без
  глобального рейтинга и публичного последнего места (предложение
  решения №5a, в PLAN пока не внесено);
* метрика «звёзды за освоенные слова» (уникальные слова с `s ≥ 90`,
  не больше 10 в день) и почему не XP/точность/серия;
* идентификация по коду класса и псевдониму, без имён и телефонов;
* согласие родителя как обязательный шлюз, таблица минимизации данных,
  сроки хранения;
* контракт API, схема данных, офлайн-очередь, обработка 401/410/429;
* телеметрия: 14 событий по белому списку, KPI, контур качества
  контента, дашборды и алерты;
* варианты размещения A–E (NAS, российский VPS, Yandex Cloud,
  зарубежные free-tier, «без сервера») с матрицей выбора, сметой
  по масштабам и чек-листом пилота;
* 152-ФЗ, модель угроз, план инцидента, документы;
* план работ по этапам 0–5 и решения, которые нужны от владельца.

### 2. Пилотный сервер `server/`

Референс-реализация контракта на встроенных модулях Node 22, без
npm-зависимостей: 10 маршрутов, SQLite (`node:sqlite`), токены,
лимиты, потолок звёзд, школьная таблица по среднему, телеметрия по
белому списку, удаление данных, ретенция, горячий бэкап.

```
server/src/app.mjs         маршруты, права, звёзды, телеметрия
server/src/db.mjs          схема SQLite, ретенция
server/src/util.mjs        токены, коды, дни, периоды
server/src/main.mjs        окружение, graceful shutdown
server/scripts/backup.mjs  бэкап через node:sqlite backup API
server/test/api.test.mjs   12 контрактных тестов
server/Dockerfile          node:22-alpine, non-root, read-only
server/docker-compose.example.yml, compose.env.example
server/README.md           быстрый старт, инварианты, границы
```

Тесты проверяют не «200 ОК», а инварианты: согласие до данных,
потолок 10 звёзд в день, идемпотентность повторной отправки,
отклонение событий «из будущего», школу по среднему (класс из 5
обгоняет класс из 30), отсутствие имён, удаление, CORS, ретенцию
и восстановление бэкапа.

* `npm run server:test` добавлен в `scripts/pickup.mjs` и в
  `.github/workflows/check.yml`.
* Новые корневые команды: `server:start`, `server:test`, `server:backup`.

### 3. Исправление магазина: бесплатный набор «Ксилофон»

Бесплатный набор звуков (`price: 0`) не попадал в `soundOwned`, поэтому
кнопка «Выбрать» на карточке молча ничего не делала: `setSoundPack`
отбрасывал id, которого нет в списке купленных. Теперь `price: 0`
считается доступным в `ShopScreen.tsx` и `store.ts`. Дефект был и на
`main`; его находил `test:smoke` двумя падениями, из-за которых CI
`main` был красным.

## Проверки

* `npm run server:test` — **12 из 12**.
* `node --check` для всех серверных файлов; живой сценарий
  `join → sync → board → metrics → backup` на временной базе и чтение
  полученного бэкапа.
* `npm run typecheck`, `content:check`, `test:adaptive`, `test:release`
  (6/6), `release:check` (0.26.0 → 0.26.1), `build`, `test:boot` — пройдены.
* `npm run test:smoke` — **все проверки пройдены**. Попутно исправлен
  найденный им старый дефект магазина: бесплатный набор «Ксилофон»
  (`price: 0`) не попадал в `soundOwned`, поэтому «Выбрать» молча
  ничего не делал (`setSoundPack` отбрасывал id). Теперь бесплатный
  набор считается доступным и выбирается без покупки —
  `ShopScreen.tsx` + `store.ts`. Дефект существовал и на `main`
  (воспроизведён на `git archive main`), к серверной части отношения
  не имеет, но чинится одной строкой и снимает красный CI.
* `npm run audit:storage` — 10 сценариев, безвозвратных потерь нет.

## Ограничения 0.26.1

* Это план и пилот, а не прод: нет кабинетов учителя/родителя, нет
  PostgreSQL, нет UI класса.
* `node:sqlite` в Node 22 экспериментален; в командах включён
  `--disable-warning=ExperimentalWarning`.
* Согласия и юридические тексты — черновики, требуют юриста.
* Docker-образ в этой песочнице не собирался (Docker недоступен):
  Dockerfile и Compose проверены по путям и командам, но первую сборку
  нужно сделать на NAS. Проверьте, что в выбранном теге `node:22-alpine`
  есть `node:sqlite` (`node -e "require('node:sqlite')"`).
