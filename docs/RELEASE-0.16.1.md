# Релиз 0.16.1 — дневной отчёт занятий для родителей

## Что изменилось

В «Родителям → Обзор» добавлена сводка за сегодня: примерное активное время в приложении, число занятий и заданий, ответы, точность дня, завершённые уроки, XP и слова с ошибками. Под каждой сессией можно раскрыть результат, ошибки по словам и формату задания, а также слова, которые ребёнок после ошибки повторил верно.

Активное время считается только в видимой вкладке, с ограничением хвоста бездействия и паузой в фоне. Это оценка времени взаимодействия, а не измерение концентрации. Детальная история сессий хранится локально за последние 30 дней; введённый ответ ребёнка не записывается. Старые профили совместимы.
