# 0.65.0 — версия программы в меню ☰

Запрос: **«добавь в гамбургер версию программы — чтобы дети могли знать
текущий релиз, так бывает полезно»**.

## Что сделано

Внизу меню ☰, под списком дел, появилась тихая подпись:

```
СЛОВО 2.0 · версия 0.65.0
```

* номер берётся из `package.json` при сборке
  (`import.meta.env.VITE_APP_VERSION`) — руками в разметке его не правим,
  поэтому подпись не может разойтись с релизом;
* это **не кнопка**, а подпись: тапнуть случайно нечего, меню не меняется;
* у подписи `data-menu-version` — по нему смоук проверяет, что строка есть
  и что в ней именно текущая версия.

Зачем ребёнку: если что-то ведёт себя не так, он может назвать взрослому
номер — «у меня 0.65.0». Родителю это сразу говорит, какая сборка открыта,
без `?diag=1` и без похода в «Родителям → Приложение».

## Где ещё видна версия

Ничего не убирали: номер по-прежнему есть в «Родителям → Приложение»
(там же SHA сборки и проверка обновлений) и в диагностике `?diag=1`.
В меню — самая короткая форма, без SHA: ребёнку нужен релиз, а не коммит.

  `import.meta.env.VITE_APP_VERSION` (в смоуке это `test`).
