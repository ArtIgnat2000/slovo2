# 0.118.7 — «Россия»: флаг и герб вместо физической карты

По просьбе владельца изображение слова «Россия» изменено: вместо физической
карты показаны российский триколор и золотой двуглавый орёл с красным щитом.
Композиция выполнена в тёплом объёмном storybook-стиле, на кремовом фоне,
без надписей и внешней рамки.

## Проверки

* `npm run content:check`
* `node scripts/image-coverage.mjs` — покрытие 1–4 классов остаётся 100%.
* Картинка — 256×256 WebP, вес меньше 20 КБ.
