# СЛОВО 2.0 — словарные слова, 2 класс

Мобильное обучающее приложение (PWA) для тренировки **словарных слов** русского языка.
Работает полностью **без интернета**, устанавливается на экран телефона как обычное приложение.

## Чем отличается от первой версии

| Было (v1) | Стало (v2) |
|---|---|
| «Сессия» из случайных слов | **Уроки-темы** с уровнями освоения (короны) |
| Слово спрашивают до показа | **Сначала знакомство**: ударение, слоги, «опасная» буква, мнемоника |
| Ошибка просто фиксируется | Ошибка **отрабатывается**: показываем правильное написание и возвращаем слово в урок |
| Нет работы с орфограммой | У каждого слова размечены **ударение, слоги и «опасное место»** |
| localStorage (5 МБ, вытесняется) | **IndexedDB** + запрос на постоянное хранение |
| Рукописный SW, без precache | **vite-plugin-pwa**: app-shell precache, офлайн, обновление |
| 510 kB JS | **~198 kB JS** (без framer-motion и иконочного пакета) |
| Один общий прогресс | **Профили детей** + раздел для родителей |

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # прод-сборка (dist/)
npm run preview    # посмотреть прод-сборку (база /slovo2/ — как на GitHub Pages)
npm run preview:build && npm run preview:show   # показ с корня (для превью в песочнице)
npm run content:check  # проверить разметку слов
npm run test:smoke     # смоук-тест в jsdom: пройти урок и получить награды
SMOKE_SEED=42 npm run test:smoke  # тот же тест на другой перестановке (по умолчанию сид 1)
npm run test:boot      # прод-бандл на первом запуске: не пустой ли экран
npm run images         # пересобрать картинки слов из images-src/ (нужен ImageMagick)
```

## Структура

```
src/
  content/   — контент-пак: слова (ударение, слоги, опасные буквы), уроки
  engine/    — SRS, планировщик урока, награды (чистая логика, без React)
  platform/  — IndexedDB, звук, вибрация, PWA
  state/     — zustand-сторы (прогресс, настройки, маскот)
  ui/        — экраны и компоненты
```

## Версии и релизы

* Номер релиза — поле `version` в `package.json`. Поднимайте его перед
  каждым релизом (0.1.0 → 0.2.0 → …).
* Каждая сборка помечается коротким SHA коммита, из которого она собрана.
  В приложении видно в **Настройках → Версия** (раздел «Родителям»):
  `v0.2.0 · cb8536f`. Если при сборке были незакоммиченные изменения —
  SHA получит суффикс `-dirty`.
* Сверка «что на сайте / что в разработке»: сравните SHA из настроек сайта
  с выводом `git rev-parse --short HEAD` на нужной ветке.
* На Pages деплоится только `main` после мерджа PR.

## Грабля: пустой экран на Pages

Если сайт открылся, а вместо приложения — пустота, почти наверняка это
бесконечный цикл перерисовок React: в консоли браузера будет
`Minified React error #185` («Maximum update depth exceeded»).

Причина — селектор zustand, который возвращает **новый объект на каждый вызов**
(`?? {}`, `?? []`, `.filter(...)`, литерал `{...}`). zustand 5 отдаёт селектор
прямо в `useSyncExternalStore` и сравнивает результат по ссылке, поэтому React
никогда не получает стабильного снимка. Такой баг коварен: на проде он ловится
только на первом запуске, пока профиля ещё нет, — то есть ровно на Pages,
а не в разработке.

Лечится выносом запасного значения в константу модуля (см. `NO_LOOK` в
`src/state/store.ts`). Проверки:

```bash
npm run test:smoke   # «виден экран выбора ученика, ошибок в консоли нет» — рендер БЕЗ профиля
npm run test:boot    # то же самое, но прод-бандлом: node scripts/prod-boot-check.mjs [--ref <коммит>]
```

`test:boot` со старым кодом (`--ref 8e62e13`) намеренно падает с `#185` — это
обратный тест: он доказывает, что проверка ловит именно этот баг.

## Как заменить список слов

Сейчас в паке **94 слова 2 класса** (орфографический словарь) — 16 уроков-тем.
Все слова лежат в `src/content/words.ts` в виде строчного блока:

```
слово|индекс_ударной_буквы|сло-ги|опасные_индексы|тип|эмодзи|предложение с ____|подсказка|мнемоника?
```

Пример:

```
карандаш|6|ка-ран-даш|1,3|vowel|✏️|Нарисуй домик цветным ____.|чем рисуют и пишут|карандАш — три А
```

После правки запустите `npm run content:check`. Проверка (и её же гоняет CI перед сборкой) следит, чтобы:

* ударение стояло на гласной, а слоги складывались в слово;
* опасной отмечено **только то, где написание расходится со звучанием**: все безударные
  о/е/я/э (они слышатся иначе) помечены — и только они, безударные а/и/у/ы/ю не подсвечиваются
  (иначе в заданиях подсвечивается не та буква; например, в «ученица» опасна только Е);
* тип `vowel | consonant | other` совпадал с отмеченными буквами
  (`other` — когда в слове есть и гласные, и согласные опасности: «Россия», «здравствуйте»);
* мнемоника не врала: «две С» — значит ровно две, заглавная буква внутри слова —
  это ударение или опасная буква, «мягкий знак на конце» — значит слово правда кончается на Ь;
* у каждого слова была подсказка, которая называет именно его (не «как?» и не «птица» у пяти птиц),
  и в предложении с пропуском не было видно сам ответ;
* **предложение подставлялось в словарной форме**: «Папа работает на ____» — ошибка,
  потому что получится «на завод» вместо «на заводе». Переписывайте такие фразы
  («Наш ____ выпускает машины»), а не выкручивайтесь падежами.

Дальше слова нужно распределить по урокам: в том же файле есть `THEME_OF` (тема каждого слова)
и список `LESSONS` (уроки = тематические блоки по 4–8 слов).

## Загрузка списка со скана

Если список прислан сканом или фото:

```bash
npm i --no-save tesseract.js            # движок распознавания
node scripts/ocr-words.mjs scan.png     # или URL картинки
node scripts/ocr-words.mjs scan.png | tail -n +3 > words.txt
node scripts/words-from-text.mjs words.txt > words.draft.txt
```

Дальше в черновике остаётся расставить ударения, эмодзи, предложения и пояснения —
это делается вручную, после чего блок переносится в `src/content/words.ts`
и проверяется `npm run content:check`.

## Ежедневные задания и награды

Каждый день приложение даёт **три задания из пула** («пройди 2 урока», «6 верных ответов
подряд», «12 верных ответов за день», «повтори 5 слов»). Набор дня выбирается по дате —
обновишь страницу, задания те же. За каждое задание — 3 💎 и один ключ. Когда собраны все
три ключа, открывается **сундук БУКа** с гарантированной наградой `💎15`.

Пустых сундуков нет: награда прозрачна и не зависит от случайности. После открытия на главной
остаётся чек с полученными предметами и новым балансом, а повторное открытие в тот же день
не выдаёт награду ещё раз.

Прогресс заданий считается из дневной статистики (`days[day]`), отдельно ключи не хранятся;
забранные награды и чек сундука отмечаются в `profile.daily`. Задания не наказывают: пропустил
день — просто придут новые.

Родитель может выбрать размер базового урока для каждого профиля: **короткий — 12**, **обычный — 16**
(по умолчанию) или **полный — 20** карточек. В лимит входят обязательное знакомство и первая
попытка вспомнить слово; отработка ошибки добавляется отдельно и не пропадает из-за выбранного
размера. Изменение действует со следующего запуска урока.

Следующий этап — **озвучка слов** (пункт 7 плана). Стиль картинок: простые плоские иллюстрации в палитре приложения, без текста и лишних деталей (картинка не должна выдавать написание слова). Как добавить или заменить изображение:

```bash
# 1. положить исходник в images-src/<имя>.png (эта папка не коммитится)

# 3. проверить
npm run content:check     # следит, что файл картинки существует
```

## Серия дней и рост БУКа

Под кольцом цели дня — **полоска последних 7 дней**: закрашенные квадратики — дни, когда
ребёнок занимался. Это «коллекция», а не укор: пропущенный день просто остаётся пустым,
никаких сообщений «ты потерял серию» нет.

**БУК растёт** по числу освоенных слов (12 → 30 → 60): птенец → ученик → знаток → магистр.
Рост читается сразу: размер, хохолок и ушки, перья на хвосте, полоски на груди.
Важно: рост только вперёд — сова никогда не «уменьшается» за пропуск.

## Магазин БУКа

Кристаллы 💎 (задания дня + сундук) тратятся на **аксессуары для совы БУКа**:
кепка, бантик, шарфик, умные очки, медаль, шапочка магистра. Купленное сразу
надевается, наряд видно и в уроках, и на главной. Вход — вкладка «БУК» внизу.

Цены устроены так, что день занятий (≈24 💎) даёт простой аксессуар, а шапочка
магистра — цель на пару дней. Аксессуары нарисованы кодом (SVG в `ui/MascotLook.tsx`):
ноль веса, работает офлайн, легко добавить новые.

## Методика

1. **Знакомство** (LOOK–SAY): слово целиком, ударение, слоги, «опасная» буква мигает.
2. **Орфографическое проговаривание**: читаем по слогам так, как пишется.
3. **Закрепление**: окошко, сборка слова из букв, выбор верного написания.
4. **Извлечение из памяти**: написать слово целиком (в т.ч. зрительный диктант).
5. **Интерливинг**: слова из прошлых уроков возвращаются по расписанию (SRS, упрощённый SM-2).
6. **Отработка ошибки**: правильное написание + мнемоника + слово возвращается в урок.
7. **Подсказка в каждом задании**: кнопка «💡» всегда внизу задания — 50:50 в окошке,
   подстановка буквы в сборке, контур слова при письме, подглядывание в диктанте,
   мнемоника/опасная буква в остальных. Ответ с подсказкой приносит чуть меньше XP
   (7 вместо 10), но остаётся правильным — помощь не наказывается жёстко.

Озвучка в этой версии **не используется** (по договорённости): вместо слухового диктанта —
зрительный (показать → закрыть → написать).
