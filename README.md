# СЛОВО 2.0 — словарные слова, 2 класс

Мобильное обучающее приложение (PWA) для тренировки **словарных слов** русского языка.
Работает полностью **без интернета**, устанавливается на экран телефона как обычное приложение.

## Чем отличается от первой версии

| Было (v1) | Стало (v2) |
|---|---|
| «Сессия» из случайных слов | **Уроки-темы** с уровнями освоения (короны) |
| Слово спрашивают до показа | **Сначала знакомство**: ударение, слоги, «опасная» буква, мнемоника |
| Ошибка просто фиксируется | Ошибка **отрабатывается**: показываем правильное написание и возвращаем слово в урок |
| Нет работы с орфограммой | У каждого слова размечены **ударение, слоги и «опасное место»** |
| localStorage (5 МБ, вытесняется) | **IndexedDB** + запрос на постоянное хранение |
| Рукописный SW, без precache | **vite-plugin-pwa**: app-shell precache, офлайн, обновление |
| 510 kB JS | **~198 kB JS** (без framer-motion и иконочного пакета) |
| Один общий прогресс | **Профили детей** + раздел для родителей |

## Запуск

```bash
npm install
npm run pickup     # «поднять сессию»: починить историю, npm ci, прогнать все проверки
npm run dev        # разработка
npm run build      # прод-сборка (dist/)
npm run preview    # посмотреть прод-сборку (база /slovo2/ — как на GitHub Pages)
npm run preview:build && npm run preview:show   # показ с корня (для превью в песочнице)
npm run content:check  # проверить разметку слов
npm run test:smoke     # смоук-тест в jsdom: пройти урок и получить награды
SMOKE_SEED=42 npm run test:smoke  # тот же тест на другой перестановке (по умолчанию сид 1)
npm run test:boot      # прод-бандл на первом запуске: не пустой ли экран
npm run audit:storage  # прогон сейфа прогресса: копии, корзина, сбой записи
npm run images         # пересобрать картинки слов из images-src/ (нужен ImageMagick)
npm run promo          # лист превью костюмов в docs/promo/<сегодня>/ (нужен @resvg/resvg-js)
```

## Версии и релизы

* Номер релиза — поле `version` в `package.json`. Поднимайте его перед
  каждым релизом (0.1.0 → 0.2.0 → …).
* Каждая сборка помечается коротким SHA коммита, из которого она собрана.
  В приложении видно в **Настройках → Версия** (раздел «Родителям»):
  `v0.2.0 · cb8536f`. Если при сборке были незакоммиченные изменения —
  SHA получит суффикс `-dirty`.
* Сверка «что на сайте / что в разработке»: сравните SHA из настроек сайта
  с выводом `git rev-parse --short HEAD` на нужной ветке.
* На Pages деплоится только `main` после мерджа PR.

## Грабля: пустой экран на Pages

Если сайт открылся, а вместо приложения — пустота, почти наверняка это
бесконечный цикл перерисовок React: в консоли браузера будет
`Minified React error #185` («Maximum update depth exceeded»).

Причина — селектор zustand, который возвращает **новый объект на каждый вызов**
(`?? {}`, `?? []`, `.filter(...)`, литерал `{...}`). zustand 5 отдаёт селектор
прямо в `useSyncExternalStore` и сравнивает результат по ссылке, поэтому React
никогда не получает стабильного снимка. Такой баг коварен: на проде он ловится
только на первом запуске, пока профиля ещё нет, — то есть ровно на Pages,
а не в разработке.

Лечится выносом запасного значения в константу модуля (см. `NO_LOOK` в
`src/state/store.ts`). Проверки:

```bash
npm run test:smoke   # «виден экран выбора ученика, ошибок в консоли нет» — рендер БЕЗ профиля
npm run test:boot    # то же самое, но прод-бандлом: node scripts/prod-boot-check.mjs [--ref <коммит>]
```

`test:boot` со старым кодом (`--ref 8e62e13`) намеренно падает с `#185` — это
обратный тест: он доказывает, что проверка ловит именно этот баг.

## Грабля: рабочая копия пересоздаётся

Песочница, в которой живёт этот клон, периодически строится заново от точки форка.
Признаки: `git log -1` показывает старый коммит, хотя работа сделана и запущена;
`node_modules` пустые (поэтому `tsc: not found`); история — `shallow`, один коммит.

Одна команда на все три беды — `npm run pickup` (`scripts/pickup.mjs`):

1. `git fetch` + `git reset --mixed origin/<ветка>`: история догоняет удалённую ветку,
   **рабочее дерево не трогается** (никаких `--hard`), перед сбросом остаётся запасная
   ссылка `refs/pickup-backup/<ветка>`;
2. `npm ci`, если `node_modules` стёрты; `--promo` дополнительно ставит `@resvg/resvg-js`
   (он нужен генератору превью и в `package.json` не попадает);
3. прогон контура: `typecheck`, `content:check`, `test:adaptive`, `audit:storage`,
   `test:smoke`, `test:boot` (флаг `--fast` — без двух последних).

Отдельно стоит, что `npm run audit:storage` сам по себе выходит с нулём всегда — он
описывает поведение сейфа. `pickup` читает его вывод и падает, если появляется строка
«ПОДТВЕРЖДЕНО» или если «потеря не подтверждена» прозвучала меньше 10 раз: иначе регрессия
в защите прогресса осталась бы незамеченной.

Флаги: `--git-only` (только история и состояние), `--no-checks`, `--fast`, `--promo`,
`--push` (запушить незапушенное), `--handoff` (напечатать черновик «Точки передачи…»
по фактам git — см. `docs/PLAN.md`). Незапушенные коммиты при таком сбросе теряются,
поэтому в конце скрипт всегда говорит, сколько коммитов ещё не на `origin`.

## Как заменить список слов

Сейчас в паке **94 слова 2 класса** (орфографический словарь) — 16 уроков-тем.
Все слова лежат в `src/content/words.ts` в виде строчного блока:

```
слово|индекс_ударной_буквы|сло-ги|опасные_индексы|тип|эмодзи|предложение с ____|подсказка|мнемоника?
```

Пример:

```
карандаш|6|ка-ран-даш|1,3|vowel|✏️|Нарисуй домик цветным ____.|чем рисуют и пишут|карандАш — три А
```

После правки запустите `npm run content:check`. Проверка (и её же гоняет CI перед сборкой) следит, чтобы:

* ударение стояло на гласной, а слоги складывались в слово;
* опасной отмечено **только то, где написание расходится со звучанием**: все безударные
  о/е/я/э (они слышатся иначе) помечены — и только они, безударные а/и/у/ы/ю не подсвечиваются
  (иначе в заданиях подсвечивается не та буква; например, в «ученица» опасна только Е);
* тип `vowel | consonant | other` совпадал с отмеченными буквами
  (`other` — когда в слове есть и гласные, и согласные опасности: «Россия», «здравствуйте»);
* мнемоника не врала: «две С» — значит ровно две, заглавная буква внутри слова —
  это ударение или опасная буква, «мягкий знак на конце» — значит слово правда кончается на Ь;
* у каждого слова была подсказка, которая называет именно его (не «как?» и не «птица» у пяти птиц),
  и в предложении с пропуском не было видно сам ответ;
* **предложение подставлялось в словарной форме**: «Папа работает на ____» — ошибка,
  потому что получится «на завод» вместо «на заводе». Переписывайте такие фразы
  («Наш ____ выпускает машины»), а не выкручивайтесь падежами.

Дальше слова нужно распределить по урокам: в том же файле есть `THEME_OF` (тема каждого слова)
и список `LESSONS` (уроки = тематические блоки по 4–8 слов).

## Загрузка списка со скана

Если список прислан сканом или фото:

```bash
npm i --no-save tesseract.js            # движок распознавания
node scripts/ocr-words.mjs scan.png     # или URL картинки
node scripts/ocr-words.mjs scan.png | tail -n +3 > words.txt
node scripts/words-from-text.mjs words.txt > words.draft.txt
```

Дальше в черновике остаётся расставить ударения, эмодзи, предложения и пояснения —
это делается вручную, после чего блок переносится в `src/content/words.ts`
и проверяется `npm run content:check`.

## Ежедневные задания и награды

Каждый день приложение даёт **три задания из пула** («пройди 2 урока», «6 верных ответов
подряд», «12 верных ответов за день», «повтори 5 слов»). Набор дня выбирается по дате —
обновишь страницу, задания те же. За каждое задание — 3 💎 и один ключ. Когда собраны все
три ключа, открывается **основной сундук БУКа** с гарантированной наградой `💎15` — он доступен
один раз в день.

**Бонусные сундуки за уроки не ограничены дневным лимитом:** каждый завершённый обычный урок
(не режим «Повторение») даёт ещё один сундук на `💎5`. Можно получить сколько угодно таких
сундуков за день; каждый из них привязан к одному завершённому уроку. Награда не случайная:
число готовых сундуков видно на главной, а открытие каждого один раз зачисляет кристаллы.

**Недельные награды:** за 3, 5 и 7 разных дней с завершённым уроком начисляется
награда в кристаллах за каждый порог. Неделя идёт с понедельника, дни не обязаны быть
подряд; награда добавляется автоматически при достижении порога, а полученные кристаллы
не пропадают.

Прогресс заданий и бонусных сундуков считается из дневной статистики (`days[day]`); забранные
награды и чек последнего сундука отмечаются в `profile.daily`, недельные пороги — в
`profile.weekly`. Задания не наказывают: пропустил день — просто придут новые.

Родитель может выбрать размер базового урока для каждого профиля: **короткий — 12**, **обычный — 16**
(по умолчанию) или **полный — 20** карточек. В лимит входят обязательное знакомство и первая
попытка вспомнить слово; отработка ошибки добавляется отдельно и не пропадает из-за выбранного
размера. Изменение действует со следующего запуска урока.

## Серия дней и рост БУКа

Под кольцом цели дня — **полоска последних 7 дней**: закрашенные квадратики — дни, когда
ребёнок занимался. Это «коллекция», а не укор: пропущенный день просто остаётся пустым,
никаких сообщений «ты потерял серию» нет.

**БУК растёт** по числу освоенных слов (12 → 30 → 60): птенец → ученик → знаток → магистр.
Рост читается сразу: размер, хохолок и ушки, перья на хвосте, полоски на груди.
Важно: рост только вперёд — сова никогда не «уменьшается» за пропуск.

## Плавающий БУК: перетаскивание, сворачивание, отклик

На главных вкладках (и на экране результатов урока) БУК висит поверх содержимого, и с
ним можно обращаться как с игрушкой, а не только смотреть на него:

* **перетаскивание** — взять сову пальцем или мышью и отнести в любое место экрана.
  Позиция запоминается на этом устройстве (`localStorage: slovo2-buk-pos`) и остаётся,
  пока ребёнок сам не перетащит БУКа снова; за пределы экрана уронить нельзя;
* **сворачивание** — круглая кнопка «−» над совой складывает её в маленький значок
  (тап по значку разворачивает обратно). Свёрнутость тоже запоминается
  (`slovo2-buk-folded`): так БУК не мешает, если мешает;
* **отклик на тап** — короткая реплика, звук и вибрация (всё уважает настройки звука и
  вибрации из родительского раздела). Каждый третий тап — реплика по делу: цель дня,
  серия, освоенные слова; пятый тап подряд — танец. Никаких наград за тапы нет:
  БУК не превращается в автомат с призами;
* **секрет на удержание** — если подержать палец на сове (≈полсекунды), она кружится и
  отвечает особой репликой. Это «пасхалка», приложение понятно и без неё;
* **«в угол»** — после перетаскивания рядом со сворачиванием появляется кнопка ⌂,
  которая возвращает БУКа в обычный угол и забывает прежнюю позицию;
* **автоскрытие при прокрутке** — когда ребёнок прокручивает страницу вниз, БУК уезжает
  за правый край и возвращается сам (или по тапу), чтобы не закрывать контент;
* **доброе утро и добрый вечер** — один раз за открытие БУК здоровается по времени
  суток. Без укоров вроде «поздно, пора спать»: режим дня — решение взрослого;
* **доступность** — у БУКа есть `role="button"` и подпись для скринридера, реакцию
  можно вызвать с клавиатуры (Enter/Пробел), анимация отключается при
  `prefers-reduced-motion`.

Позиция и «свёрнут» — удобство конкретного устройства, а не прогресс ребёнка, поэтому
они не попадают в файл выгрузки и в основную запись прогресса. А вот настройку
**«Сова БУК»** (везде / только на главной / не показывать) взрослый задаёт в
родительском разделе — она входит в выгрузку, потому что это осознанное решение, а не
мелочь телефона.

## Помощник БУК в уроке

В уроке БУК не летает поверх задания (плавающий БУК на карточках скрыт) — он живёт
маленькой спокойной совой в шапке урока и говорит только по делу:

* **вопрос вместо ответа** — тап по сове открывает панель с наводящим вопросом про
  слово («где опасное место? Проговори по слогам»). Вопрос **не раскрывает букв**:
  ребёнок продолжает вспоминать сам. Если нужно — вторая ступень «💡 Показать букву»
  показывает опасные буквы и мнемонику (то же, что даёт кнопка подсказки в задании);
* **тихое предложение помощи** — если ребёнок не действует 20 секунд, сова мягко
  пульсирует и появляется пузырь «Подсказать?». Без звука, без всплывающих окон,
  поверх полосы прогресса — задание не сдвигается под пальцем. Кнопка «Я сам» —
  и в этом уроке предложения больше не повторяются;
* **разбор ошибки** — в полосе вердикта БУК поддерживает и говорит, что будет
  дальше («это слово вернётся в уроке»); после верных ответов подряд — радуется серии.
  Раньше эти реплики пропадали: показывать их в уроке было негде;
* **честная цена помощи** — вопрос даёт качество 4 (XP как с подсказкой, в адаптации
  ответ не считается самостоятельным), показанная буква — 3, как и у кнопки «💡».
  Звёзды урока зависят только от доли верных ответов, поэтому помощь не рушит результат.
  Никаких наград за «спросил БУКа» нет;
* **настройка родителя** — «Подсказки в уроке»: с вопросом (по умолчанию) / сразу буква /
  выключены. Глобальное «Сова БУК: не показывать» отключает помощника автоматически.

Устройство и обоснование — в `docs/buk-in-lesson.md`.

## Магазин БУКа

Кристаллы 💎 (задания дня, сундуки и недельные награды) тратятся на **аксессуары для совы БУКа**:
кепка, бантик, шарфик, умные очки, медаль, шапочка магистра. Купленное сразу
надевается, наряд видно и в уроках, и на главной. Вход — вкладка «БУК» внизу.

Цены устроены так, что день занятий (≈24 💎) даёт простой аксессуар, а шапочка
магистра — цель на пару дней. Аксессуары нарисованы кодом (SVG в `ui/MascotLook.tsx`):
ноль веса, работает офлайн, легко добавить новые.

## Костюмные пазлы

Идея из родительского чата: ребёнку нужна длинная цель — «дособрать коллекцию»,
как в Дуолинго, но без гонки и без наказаний.

- за каждый реально завершённый урок — ровно **1 фрагмент** текущего пазла;
- **9 фрагментов — новый костюм БУКа** (всего 10 образов «космической саги»:
  Тёмный лорд, Белый воин, Мастер Света, Лесной мудрец…; названия нейтральные,
  без товарных знаков). Костюм надевается сразу и видно его на главной, в уроках
  и в магазине;
- цель сборки выбирает ребёнок («Собирать» в магазине); переключать можно
  свободно — прогресс каждого костюма хранится отдельно и не «сгорает»;
- надеть можно только один костюм: «Надеть» / «Надето ✓» в магазине БУКа;
- собрана вся коллекция — дальше каждый урок даёт **+2 💎**: награда находится
  всегда, пустых кликов не бывает;
- «Повторение» фрагментов **не даёт** — повторение тренирует память (SRS),
  а не коллекцию; тот же принцип, что и без XP за него.

Правила и палитра костюмов — один источник `src/engine/puzzles.ts` (рисует
Маскота, считает прогресс, выдаёт награды); слои шлема/атрибута/плаща —
`ui/MascotLook.tsx`. Никаких звуков и таймеров механика не добавляет.

## Методика

1. **Знакомство** (LOOK–SAY): слово целиком, ударение, слоги, «опасная» буква мигает.
2. **Орфографическое проговаривание**: читаем по слогам так, как пишется.
3. **Закрепление**: окошко, сборка слова из букв, выбор верного написания.
4. **Извлечение из памяти**: написать слово целиком (в т.ч. зрительный диктант).
5. **Интерливинг**: слова из прошлых уроков возвращаются по расписанию (SRS, упрощённый SM-2).
6. **Отработка ошибки**: правильное написание + мнемоника + слово возвращается в урок.
7. **Подсказка в каждом задании**: кнопка «💡» всегда внизу задания — 50:50 в окошке,
   подстановка буквы в сборке, контур слова при письме, подглядывание в диктанте,
   мнемоника/опасная буква в остальных. Ответ с подсказкой приносит чуть меньше XP
   (7 вместо 10), но остаётся правильным — помощь не наказывается жёстко.

Озвучка в этой версии **не используется** (по договорённости): вместо слухового диктанта —
зрительный (показать → закрыть → написать).
